# 自证收敛循环（align-check）

**权威手册**：`docs/playbooks/self-check.md`（owner 2026-07-29 拍板·101/102/103 复盘）。本 skill = 它的可执行摘要。

**一句话**：自证 = **我先查我**（复查是别人查我）。**每轮迭代**都做，不是最后补一次。

## 三步循环

### 1. 真渲染自玩（**不许用 CLI 测试代替目击**）
起真浏览器玩一遍（`/run` 技能，或 `node scripts/ui-walkthrough-probe.mjs --game <slug>`；Chromium 已装）。
截图序列至少覆盖：**开局 → 关键操作 ≥3 步 → 一次失败路径 → 终局 → 重开**。
存 `docs/design/<slug>/self-check/shots/`（≥5 张，S4/S5 机器门查存在性）。

> happy-dom 渲不出你要看的东西（faceArtSlice 白画事故为证）。**CLI 绿 ≠ 你看见了。**

### 2. 出对齐单 `docs/design/<slug>/self-check/<SN>-alignment.md`
从 GDD 逐条摘**玩家看得见的承诺**（屏与布局 / 交互反馈 / 数值表现 / 演出节点），一条一行。

**列契约（机读·别改）**——`scripts/align-count.mjs` 按它数：

| # | GDD 承诺 | 结论 | 证据 / 说明 |
|---|---|---|---|
| 1 | 【R-xx-01】六条蓄力槽常驻可读 | ✅ | `shots/S4-1-start.png` |
| 2 | 【R-xx-40】石板随改写当场重刻 | ⚠ **降格** | 只印静态文案；差在「凿改时重刻」这一半。**报 owner 裁**：S5 补还是现在补 |
| 3 | 【R-xx-31】tell = 立绘预备动作 | ❌ **缺** | 还没有立绘。属 S5/S6 面，**明记为缺不默降** |

- 表头必须有一列叫 **结论**；该格**首个非空白字符**必须是 `✅` / `⚠` / `❌`（写成「基本 ✅」数不到）。
- **⚠ 行必须写明裁决去向**（报谁 / 单号）——**不许默降**。没去向的 ⚠ 会被当默降判红。
- 样板：`docs/design/game108/self-check/S4-alignment.md`。

### 3. 修 → 再玩 → 更新对齐单
每轮在单尾追加一行迭代记录（第 N 轮 · 改了什么 · 剩几条）。

## 收敛判据（这是「做完了」的唯一定义·不是你的感觉）

```bash
node scripts/align-count.mjs --game <slug> --stage S4    # 退出码直接量·别经管道
```
- **0 = 已收敛**（❌ 归零 ∧ 每条 ⚠ 有去向）→ 可送复查门。
- **1 = 未收敛** → 回去再转一圈。
- **2 = 单不在档** → 你还没开始自证。「没写单」永远不等于「已对齐」。

**⚠ 那一列攒起来就是要问 owner 的清单** → 走 `/ask-owner` 一次问完，别逐条打断。

## ⛔ 终局出口必点（owner 2026-08-07 报 bug 后立·全库）

game108 复盘：owner 点「再来一局」**没反应**，而当时**所有机器门全绿**（30 条试玩断言 + 验收剧本 +
点击探针 + full 门禁）。三个原因，每个都会重演：

1. **走查在「分出胜负」就收工**——覆盖面正好在 bug 开始的地方结束。
2. **终局屏是另一屏**（对局键全收起、只剩一个出口）。出口点不动 = 玩家卡死，比对局里任何 bug 都严重。
3. `ui-inventory` 早先点名过这个动作「够不着」，UI 重构把键摆上屏后**检查从红转绿而 bug 一行没修**
   ——那把尺子量的是「够得着吗」不是「点下去有人管吗」。**检查转绿 ≠ 问题解决；先问它量的是不是同一件事。**

**硬要求**：① 试玩必须走过终局，终局屏每个键真点一次；② 点完断言**世界真的变了**
（重开 = 满血 + 回对局相位 + 槽清零 + **新局还能接着打**），不能只断言「屏刷新了」；
③ 任何**只有一个出口**的屏（终局 / 结算 / 弹窗），那个出口是最高优先级被测对象。

## 反面清单（出现即这轮自证不合格）
拿 CLI 绿当目击 · 截图只覆盖到胜负就收 · 终局屏没点过 · **⚠ 不写去向（默降）** ·
把 ❌ 悄悄改成 ⚠ 来凑收敛 · 单在档但一轮都没迭代（`align-count` 数得出，改不出来） ·
「我觉得差不多了」当收敛判据。

> **一句话**：**跑到 `align-count` 退出 0 才叫做完**；做不到就再转一圈，转不动的写清去向去问。
