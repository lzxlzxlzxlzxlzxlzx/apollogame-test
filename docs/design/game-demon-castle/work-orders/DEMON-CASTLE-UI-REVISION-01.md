## 六项验收

1. 左上羊皮纸追踪任务卡包含徽记、标题、下一目标，正常与长文两态可切换并完整可读。
2. 顶部居中地点、季节、第几天与时钟组成一条连续丝带；内容区域可读高度至少 56px，文字对比清晰。
3. 右上三枚 pill 只显示图标与动态数字；名称只用于 tooltip/无障碍解释，不能作为常驻标签。
4. J/I/C 为独立圆形或盾形图标按钮，图标上、键徽下，有默认/hover/pressed/disabled 展示。
5. 三个入口打开同套右侧大羊皮纸侧栏；任务/背包/档案内容、关闭/互斥/Escape、空态、长内容滚动均可操作。任务追踪更新左上，背包选择更新详情；原型数据变化提供可见反馈。
6. 地图始终可见，无常驻底部快捷栏；精确文字/数值/快捷键均为 DOM 文本。图标采用明确标注的矢量占位，不使用未批准图标候选。
