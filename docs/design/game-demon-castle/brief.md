# 魔王少女的月影城堡 · S1 生成简报

## 一句话

玩家操纵刚继承荒废魔王城的少女魔王，在月影山谷中采集、种植魔界作物、修复房间与招募居民；让城堡从废墟重新成为温暖而危险的家。

## 核心循环

1. 在城堡庭院、月影森林、地底工坊自由移动并采集材料。
2. 在庭院魔土种植月萝卜，推进日历取得稳定产出。
3. 在可修复房间附近按 `E` 打开小菜单，消耗材料完成建设。
4. 与管家幽灵、石像鬼工匠交流，提升关系、领取任务，解锁新的房间与区域。
5. 在每日结束前回到寝宫休息；剧情条件以任务、材料、关系和建设状态驱动。

## 第一版范围

- 3 个互通场景：庭院、月影森林、地底工坊。
- 1 名玩家、2 名 NPC、1 种作物、2 种可采资源、3 个建设项目。
- 剧情第一章：点亮王座厅 → 修复温室 → 邀请石像鬼工匠。
- 目标逻辑画布：1440×900；俯视像素风，32×32 地块，角色 32×48。

## 视觉方向

- 夜紫、月银、烛火金与苔藓绿；温柔童话感而非血腥恐怖。
- 建筑为大尺寸透明底精灵；瓦片与物品为严格尺寸的像素 PNG。
- HUD 只保留日期、灵魂晶石、建设目标；交互提示与递归选择菜单贴近角色出现。

## 明确不做

- 不做战斗、随机地牢、多人、复杂装饰自由摆放、恋爱分支结局。
- 不引入游戏专属脚本或规则解释器；所有条件只使用 Life 既有任务、关系、资源与建设动作。
