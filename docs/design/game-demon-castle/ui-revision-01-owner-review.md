# 月影魔王城 UI 修订候选 01 · Owner 复核

历史版本说明：本页只指2026-10-15旧批准版。2026-10-16的新目标请看[候选02目击说明](ui-revision-02-owner-review.md)，新入口尚未重新定稿。

打开 [旧定稿完整快照](demon-castle-ui-revision-01.approved-2026-10-15.dc.html)，使用浏览器完整窗口；先以 1440×900 或更大视口查看。它是独立本地 HTML，不需要启动 ZeroCraft。旧 [HUD demo](demon-castle-ui-demo.html) 原样保留。

这次请确认：左上任务卡是否易读、中心地点/季节/天数/时钟是否足够大、右上图标数字与 J/I/C 是否清楚，以及侧栏是否接近月影参考稿。

1. 先看默认 HUD。左上是当前追踪，中心是 104px 高的连续状态丝带；右上只显示三枚图标与数字，名称仅在 tooltip/无障碍描述中。
2. 点 J 或按 J，在任务列表中点“温室的裂纹 → 追踪任务”。左上目标同步更新并有 320ms 金边反馈。也请看“已完成”空态并点“返回正常示例”。
3. 点 I 或按 I，选择“影矿”格子，检查选中框与下方说明。点 C 或按 C，检查人物、关系、城堡三个页签。三个入口始终复用同一侧栏，地图不被全屏遮罩盖住。
4. 展开左下“原型评审 · 状态切换”，选择“空态”，依次检查 J/I/C；空态都能回到正常示例。选“长内容 / 滚动”，在面板内滚动，并检查左上长标题/下一目标是否完整可读。
5. 在控制台点“资源变化”“下一日”，确认数字、日期与时钟是动态文字。选择按钮“悬停 / 按下 / 禁用档案入口”可固定观察，也可以直接用鼠标按住入口；禁用后 C 不应打开档案。恢复“默认”即可。
6. 用 × 和 Escape 关闭，关闭后再开另一页；必要时点“重置原型”。缩到 1060px 宽时状态丝带占第一行，其他 HUD 分列下一行，所有内容仍在浏览器视口内。

左下控制台是评审工具，不是游戏常驻快捷栏。图标均为矢量占位；沿用的角色、地图与框皮只用于本地原型参考，本单没有新增或审批任何素材。原型展示三枚资源布局，不等于正式世界已有第三份资源账本。

Owner 已于 2026-10-15 在程序会话明确回复：**“挺好的，可以定稿”**；另在策划会话回复 **“原型通过、图标候选通过”**。两处判词来源、定稿文件及 SHA-256 见 [定稿记录](prototype-approval.md)；以上步骤保留作复核导航。正式共享 Host 实现另立工单，图标候选批准只针对已展示候选，其他素材审批与控制台 Owner 人门仍分别处理。
