# 《潜取》验收场景 v0.2

## 引擎规则

### AC-01：同种子同布局

- 同配置、同 seed 启动两次。
- 断言黑位、物品槽位和 RandomSeed 推进完全一致；不同 seed 至少在点名样例中产生不同布局。

### AC-02：黑位必空

- 断言黑位数量等于配置值、无重复、全部 `slotTargetIds[slot] === null`，且不可翻。

### AC-03：QTE 精准度

- 理想点及完美半径内惩罚为 0。
- 从完美边缘向外逐 tick 扫描，惩罚单调不降；最远点与 timeout 等于最大惩罚。

### AC-04：完美 QTE 存入开门机会

- 覆盖完美、偏移、timeout。
- 完美时仍保持 `qte` 且 `revealCredits` 加一；偏移与 timeout 不加机会。连续完美可累计机会。

### AC-05：翻格边界

- 越界、黑位、已翻位置拒收且不消耗翻格权。
- 合法隐藏位仅消费一次权利；空位与物品位都保持持续 QTE，且不重置正在运行的指针。

### AC-06：清空与保留所得

- 最后一件物品翻出后 `cleared`。
- 取得部分物品后撤退或暴露，回执仍包含已经取得的稳定 id。

### AC-07：风险优先

- 同 tick 被动风险达到上限且玩家发送 withdraw。
- 断言终局为 `exposed`，不是 `withdrew`。

### AC-08：确定性与快照

- 中途快照/恢复后继续同一输入。
- 断言会话、RNG 与回执逐字段一致，恢复时不重新洗牌。

### AC-09：非法数据 fail-closed

- 覆盖无 seed、环大小总和错误、黑位 + 物品超容量、重复目标 id、坏 QTE 参数、倒序 seq。
- 断言不凭空取得物品；启动失败形成 `aborted` 回执。

### AC-10：DebugTrace

- 开 trace 完成一局。
- 断言只读 trace 能重建布局、QTE 选择、翻格与终局；每 system/tick 不超过 3 条。

## UI

### AC-11：双环结构

- 真渲染中存在内环 4 个和外环 12 个位置；黑、隐藏、空、已取得四态可区分。
- 中央静态表盘与独立旋转指针、顶部暴露条、已取得列表与撤退按钮均不互相遮挡。

### AC-12：写路径

- QTE 按钮只发送 `theft.qte.press`。
- 只有 `qte` 阶段且存有开门机会时，合法隐藏位发送 `theft.reveal` + 槽位参数。
- 撤退发送 `theft.withdraw`；UI 不自行预算 QTE 精准度或物品结果。

### AC-13：透明嵌入与窄屏

- 背景透明，DokiWorld 场景可见。
- 检查 1280×720、1920×1080 与窄屏；无意外重叠、裁切、低对比文字或横向溢出。
