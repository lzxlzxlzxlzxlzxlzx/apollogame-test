# game-theft《潜取》立项卡

> 工作名；正式命名可在 S1 人门调整，不影响合同与能力计划。

## 一句话

一个持续升温的多物品偷窃 QTE：玩家在暴露值涨满前反复命中时机、逐件获取目标库存，并在“再拿一件”与立即撤退之间下注。

## 产品定位

- 形态：DokiWorld 场景之上的透明悬浮小游戏 App。
- 单局时长：目标 20–90 秒；由物品数、QTE 节奏和暴露参数共同决定。
- 玩家承诺：每次成功都会制造“已经赚到，要不要再贪一次”的明确风险。
- 宿主承诺：小游戏不直接写背包、关系、犯罪或 NPC 记忆；只返回可确定性重演的操作记录，宿主复算后提交世界效果。

## 已裁决方向

Owner 于 2026-09-28 选择 A 方案：建立统一偷窃会话结算，不保留“普通 d20 偷窃”和“妙手空空百分比偷窃”两套互斥规则。`steal` / `pickpocket` 是语义入口，QTE 是可配置结算方式。

## 核心循环

1. 宿主按期望顺序传入目标、候选物品、每件物品的最终 `dc`，以及本局唯一的暴露增长参数。
2. 游戏锁定数组中第一件尚未耗尽的物品；玩家不能自行重排或跳选。
3. 系统按确定性节奏产生 QTE。
4. 命中 QTE 后，以“DC 校准出的初始概率 + 当前物品累计成长”进行一次种子化偷取判定。
5. 判定未成功则累计下一次概率；QTE 失误则额外增加暴露。
6. 成功取得当前物品的一份/一个实例，概率成长对该物品清零；玩家可以继续，并自动进入调用方顺序中的下一件物品。
7. 玩家可随时撤退；暴露满则立即暴露；清空物品则完成。

## 语义边界

| verb | 语义 | 合法目标 |
|---|---|---|
| `steal` | 从场景、容器、货架或非贴身库存取走物品 | `world_object` / 容器 / NPC 托管库存 |
| `pickpocket` | 从角色随身库存中扒取物品 | NPC |

两者共享同一会话规则和 SDK，只由宿主决定目标类型、参数及最终犯罪后果。

## 成功标准

- 多个物品按调用方给定顺序真实进入会话；一次成功只取得当前目标的一份或一个唯一实例，玩家不能跳选或重排。
- 取得一件后会话不断，暴露不清零，玩家能继续偷或撤退。
- QTE 命中但偷取判定未中时不额外惩罚暴露，并明确展示概率成长。
- QTE 失误产生即时暴露惩罚；被动暴露始终按固定 tick 增长。
- 同输入、seed 和操作日志重演得到逐字段相同回执。
- 暴露后已经取得的战利品保留，并由宿主提交犯罪、关系和记忆后果。

## 非目标

- 不在小游戏中读取 DEX、妙手空空、烟雾弹、装备、关系、目击者或 NPC AI；宿主把所有成功因素折算进逐物品最终 `dc`，把所有暴露因素折算进单一暴露增长参数。
- 不直接修改 DokiWorld 背包或数据库。
- 不在 v1 做实时联网对抗、反作弊服务器输入流、潜行移动或 3D 场景导航。
- 不允许调用方传入预定结果或业务 seed；玩法调节只接受逐物品最终 `dc` 与整局暴露速度，随机种子由外部会话能力在开局时建立。
