# 《潜取》数值模型 v3

## 1. 给 DokiWorld 的唯一难度输入

正式调用只传 `difficulty: 0..100` 的安全整数。它是 DokiWorld 把属性、技能、守卫感知、环境、妙手空空、烟雾弹等业务因素折算后的**总难度**；小游戏不接收、也不解释这些业务字段。

| `difficulty` | 档案 id | 黑位数 | 非黑可翻位 | 被动暴露（bp/s） | 满暴露前的无失误时间 |
|---:|---|---:|---:|---:|---:|
| 0–19 | `forgiving` | 10 | 6 | 180 | 55.6 s |
| 20–39 | `easy` | 8 | 8 | 240 | 41.7 s |
| 40–59 | `standard` | 6 | 10 | 320 | 31.3 s |
| 60–79 | `hard` | 4 | 12 | 400 | 25.0 s |
| 80–100 | `expert` | 2 | 14 | 500 | 20.0 s |

边界规则：输入小于 0 钳为 0，大于 100 钳为 100；每档从自己的下界起生效（例如 20 是 `easy`，40 是 `standard`）。`difficulty` 不是概率，也不应直接把 D20 的 `dc` 原样塞进来；DokiWorld 应先做自己的业务折算，再交给这个 0–100 标尺。

这两个映射值是本游戏唯一消费的平衡数据：

```ts
type TheftDifficultyProfile = Readonly<{
  id: 'forgiving' | 'easy' | 'standard' | 'hard' | 'expert'
  blackSlotCount: number
  exposureRateBpPerSecond: number
}>
```

黑位多不代表物品少：黑位开局公开且确定为空，因而能缩小盲开范围。难度升高时黑位变少、可选门变多，同时被动暴露变快；两项必须成对调，不能只看暴露条速度。

## 2. 固定规则常数

- 总槽位 `S = 16`，风险上限 `L = 10,000 bp`。
- QTE 一圈为 120 tick / 2.0 s；玩家每次按下后，QTE 刻度锁住 30 tick / 0.5 s，而**被动暴露不会暂停**。
- 完美窗为理想点前后 6 tick；完美按压获得一把钥匙且加 `0 bp`，偏移按压最多加 `1,400 bp`。
- 一个已获得的钥匙可随时翻开一个非黑、未开门。所有门在翻开前等价；玩家没有从画面识别物品位置的额外信息。

## 3. 供策划复算的公式

令：

- `B` 为黑位数，`N = 16 - B` 为可翻位数；
- `I` 为本局物品数量；
- `p` 为玩家按压落在完美窗的比例（不是点击次数）；
- `r` 为每秒被动暴露；
- `c = 2.5 s` 为一次有意 QTE 尝试的规划时长（2 秒转盘 + 0.5 秒按压确认）；
- `m` 为一次非完美按压的平均瞬时风险。标定表先用保守中位估计 `m = 700 bp`。

在玩家每次都选择未开非黑门、门位随机的前提下：

```text
安全观察时间                 = L / r
取得至少一件所需钥匙（期望） = (N + 1) / (I + 1)
取得全部所需钥匙（期望）     = I × (N + 1) / (I + 1)
获得 K 把钥匙的尝试数（期望） = K / p
被动风险估计                 = r × c × K / p
偏移风险估计                 = m × (1 - p) × K / p
```

公式是用于档案比较的可解释估算，不替代种子枚举。实际实装要用固定种子全量/大样本重演，分别统计“至少一件”“全拿”“主动撤退”和“暴露”四种结果。

## 4. 80% 完美 QTE 的基准（3 件物品）

下表采用 `p = 0.80`、`m = 700 bp`，不计玩家看门和做撤退决定的额外时间。风险是期望值；接近或超过 10,000 意味着不该把“全拿”当成普通玩家的目标。

| 档案 | 至少一件：估计风险 | 全部 3 件：估计风险 | 体验结论 |
|---|---:|---:|---|
| `forgiving` | 1,290 bp | 3,870 bp | 新手可试探，也有余裕多拿 |
| `easy` | 2,080 bp | 6,240 bp | 多拿可行，但应开始考虑撤退 |
| `standard` | 3,240 bp | 9,690 bp | 单件稳定；全拿需要较好的节奏 |
| `hard` | 4,630 bp | 13,890 bp | 目标是偷到关键一件后收手 |
| `expert` | 6,520 bp | 19,550 bp | 高技术挑战；多件几乎必须依赖异常好的表现或外部降低难度 |

这符合设计目标：80% 完美的普通熟练玩家对**单件**仍有接近 D20 常见成功检定的可控机会；连续多拿会因搜索空间和时间双重放大而明显更难。DokiWorld 想奖励高级角色时，应降低 `difficulty` 档，而不是给小游戏额外“必定成功”分支。

## 5. 调参准则

- 想让一件关键物更容易拿到：优先降低 `difficulty`，它会同时增加公开黑位并降低被动暴露。
- 想让“见好就收”成为正确决策：使用 `standard` 或 `hard`，并放入 2–4 件物品；不要把一件物品单独设成高难度。
- 想让全清是高手目标：使用 `hard`/`expert` 且物品数不少于 3；不要提高单次 QTE 最大惩罚来伪造难度，那会把操作误差放大成不可读的随机挫败。
- 一局物品超过 5 件时，必须先做种子模拟再定档；`expert` 的可翻位为 14，物品数也不得超过 14。
- 调用方若有临时减益/增益，只重算并传递一个新的 `difficulty`；不要向小游戏传“烟雾弹”“妙手空空”“属性名”或逐物品 DC。

## 6. 标定后的维护门槛

表中数值是 v3 基线。修改 `blackSlotCount`、暴露速率、QTE 周期、完美窗或最大惩罚任一项时，必须重新生成本节第 4 表，并至少覆盖物品数 1、3、5 和完美率 60%、80%、95%。
