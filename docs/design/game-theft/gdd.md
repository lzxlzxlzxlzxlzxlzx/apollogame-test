# 《潜取》游戏设计文档 v0.2

## 1. 核心体验

玩家在持续上涨的暴露压力下操作一座双环转盘：内环 4 格、外环 12 格。部分位置开局即显示为封锁黑位，确定为空；其余位置保持未知。指针持续扫过中央表盘；只有命中金色完美扇区的 QTE 才会存入一次开门机会。玩家可在转盘继续运行时随时消耗机会翻开一扇门，可能取得财宝，也可能翻到空位。

这不是“每件物品各掷一次概率”的系统。物品没有独立难度；本局只有一个总难度，调用方给出总难度，游戏的数据表把它映射为被动暴露速度与黑位数量。

## 2. 状态机

| 状态 | 允许输入 | 规则 |
|---|---|---|
| `idle` | `start` | 用世界 `RandomSeed` 一次性生成槽位布局 |
| `qte` | `qte-press`、`reveal(slot)`、`withdraw` | 指针持续旋转；按压或超时按偏移追加风险。完美按压存入开门机会；有机会时可随时翻一个非黑、未翻位置 |
| `terminal` | 无 | `withdrew/exposed/cleared/aborted`，回执冻结 |

每 tick 固定顺序：被动暴露 → 满值终局 → 玩家输入 → QTE 周期推进/超时 → Signal。玩家不能在暴露于本 tick 满值后抢先撤退。

## 3. 双环与物品

- 槽位总数固定为 16：内环 4 格，外环 12 格；两环只有位置和视觉层级差异，没有概率差异。
- `items[]` 每个条目只占一个槽位；同一稳定 `entryId` 不得重复。
- 启动时按种子洗牌：先选出 `blackSlotCount` 个公开黑位，再把物品逐个放入剩余随机位置；其余非黑位是隐藏空位。
- 黑位开局可见、确定为空、不可翻；隐藏空位与物品在翻开前外观完全相同。
- 翻到物品即取得，不再进行第二次成功率抽取。
- 所有物品均取得后立即 `cleared`；空位无需全部翻完。

## 4. QTE 精准度

QTE 使用固定 tick，不读墙钟。一个周期声明 `qteCycleTicks`、理想点 `qteIdealTick`、完美半径 `qtePerfectRadiusTicks` 和最大瞬时惩罚 `qteMaxPenaltyBp`。

```text
offset = abs(pressTick - idealTick)

offset <= perfectRadius:
  penaltyBp = 0
否则:
  penaltyBp = floor(maxPenaltyBp * (offset - perfectRadius) / (maxOffset - perfectRadius))
```

- 完美 QTE 的瞬时暴露增量为 0，但被动暴露仍正常增长。
- 越偏离理想点，瞬时增量越大且单调不降。
- 超时按最大惩罚处理。
- 仅完美 QTE 会存入一次翻格权；偏移与超时不产生翻格权。未使用的权利可累计，翻格不会中断下一轮指针。
- 当前偷窃配置把周期结束设为 `reset-no-penalty`：玩家未点击时只让指针回到起点，不伪造成一次失误、不增加暴露；只有主动点击才产生成功或偏移判定。主动按压使用 `continue-from-press`；按压后 QTE 刻度以固定 30 tick（0.5 秒）锁住，结算反馈结束后从该按压相位继续转动、不回跳到起点。锁住的是 QTE，不是会话：被动暴露与顶端进度条在这 0.5 秒内仍持续累积。

## 5. 暴露与难度

被动暴露使用整数基点与固定 tick 余数累加：

```text
remainder += riskRateBpPerSecond
risk += floor(remainder / ticksPerSecond)
remainder %= ticksPerSecond
```

调用方只传一个 0–100 的总难度。游戏难度表负责输出：

- `blackSlotCount`：低难度黑位更多，高难度黑位更少；
- `riskRateBpPerSecond`：难度越高，被动暴露越快。

精确档位、边界钳制、80% QTE 基准和复算公式见 [`balance-model.md`](./balance-model.md)。

引擎能力只消费映射后的两个整数，不理解 DC、等级、烟雾弹、妙手空空、NPC 感知等 DokiWorld 领域概念。当前 5173 预览使用 `preview-unbalanced` 临时档，仅用于观察交互，不构成平衡承诺。

## 6. 终局

| 终局 | 已取得物品 | 说明 |
|---|---|---|
| `withdrew` | 保留 | 玩家主动安全收手 |
| `cleared` | 保留 | 所有物品均已翻得 |
| `exposed` | 保留 | 暴露达到上限；后果由 DokiWorld 处理 |
| `aborted` | 不提交 | 配置、种子或协议非法 |

小游戏不生成文案、建议、犯罪、关系或惩罚。它只回传过程与结果；DokiWorld 根据终局和取得清单处理世界状态。

## 7. UI

- 透明悬浮画框覆盖在 DokiWorld 场景上。
- 中央为独立黄铜表盘与透明指针；指针随 QTE 周期旋转，金色扇区与规则的 `qteIdealTick` 使用同一角度。完美命中后由世界种子抽取不同刻度，表盘旋转使金色扇区换向。旧菱形视觉不再使用。
- 内环 4 个大槽位、外环 12 个小槽位都嵌入同一座双环机械转盘；槽位状态叠加在 AI 绘制的铜制机关上。
- 顶部仅保留镶框暴露进度条，风险由绿色连续过渡到金、橙、红色；不显示标题、目标或难度文字。
- 所有槽位使用不透明圆形门牌：黑位与未知位为关闭门，翻开后使用专属圆形开启门牌，不以文字、勾号或半透明占位符表达。
- QTE 成功后显示可用开门机会；只有有机会时，合法隐藏位可点击，且可与持续 QTE 并行。
- 底部独立皮革托盘持续显示已经取得的物品，其下常驻“立即撤退”按钮。
- 透明悬浮画框、双环转盘、QTE 表盘/指针、未开门/封墙死门/开启门牌、战利品托盘和撤退按钮均走 `skinMap` 美术槽；动态文字由 LayoutNode 排版，不烘焙进图片。物品可选 `imageUrl` 由调用方传入，取得时从对应门位弹出并飞向战利品托盘；未提供时使用本游戏演示图。
- UI 仅投影世界状态并发送 `theft.qte.press`、`theft.reveal(slot)`、`theft.withdraw`；不得自行判定精准度或翻格结果。

## 8. 确定性与安全

- 同一规范化输入、seed 和输入日志必须产生完全相同的布局、风险、取得清单与回执。
- 规则随机只在开局布局时消费 `RandomSeed`；翻格不再随机。
- 快照保存完整布局与运行态，恢复后不得重新洗牌。
- 展示名与图片不进入规则 hash；回执只使用稳定 id。
- 确定性重演用于一致性和幂等，不等于防作弊；高价值经济仍需宿主签收输入或接受客户端信任边界。
