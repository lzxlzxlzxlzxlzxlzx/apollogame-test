# 战斗规则确认记录 v0.2

来源：用户本轮直接决定及随后两项边界回复。此文件记录已确认玩法，优先于v0.1中的推荐与待确认描述；不等于S2通过或阶段签核。

## 已确认规则

| 编号 | 规则 |
|---|---|
| CR01 | 大象、米诺菇拥有真正的冲锋技能：攻击目标为地面、距离大于配置阈值且CD就绪时可触发，大幅提高移动速度冲向目标造成伤害。共享模板，各自填写阈值、速度、伤害和CD。 |
| CR02 | 单体近战成功开始前摇后，目标拉开距离仍然命中；随后升空也不取消这次已经启动的攻击。下一次攻击重新判断合法目标。此规则不表示范围攻击会追踪已经离开范围的所有敌人。 |
| CR03 | 成功启动技能即开始CD；前摇或施法被打断不返还CD；启动失败不扣CD。 |
| CR04 | 只有冰冻、恐慌等硬控制可以打断技能。普通受伤、减速、仅禁止移动不作为打断来源；死亡仍需结束动作并清理。具体硬控制种类继续明确定义。 |
| CR05 | 飞行单位进入下降阶段时打开反击窗口，回升完成时关闭；窗口期间目标资格视作地面，可被仅对地单位索敌，也可受到地面范围伤害。 |
| CR06 | 地面攻击者选中窗口内目标后，如果尚未开始攻击，目标便恢复飞行，则重新选择合理目标；如果已经开始近战前摇，则完成本次命中后再重新选择。启动攻击时仍检查距离。 |
| CR07 | 中毒、燃烧、凋零可以同时存在；同一种状态不叠加伤害，重复施加刷新时间，强弱不同保留较强效果。强度与持续时间分别处理，具体持续伤害归属另定。 |
| CR08 | 渊灵术士在标记结束后固定落点，后续预警与激光雨不再追踪敌人，敌人可以离开范围躲避。 |
| CR09 | 自爆对友军造成半额伤害，适用于普通苦力怕与核能苦力怕；对敌倍率1、对友倍率0.5。自毁不是对友军伤害，不因减半而存活。 |
| CR10 | 被悚怖尸巫伤害过的敌人在死亡时转化，不要求由尸巫完成最后一击。一次死亡只转化一次；被多个尸巫伤害时，归最后伤害它的尸巫。尸巫先死亡不清除已经留下的转化标记：标记者之后死亡时仍发生转化，使用标记保存的来源与阵营快照完成归属。 |
| CR11 | 转化类型先判断节肢：节肢生物一律转为悚怖劫蛛。其余按最大生命分档：≤20转尸奴；>20且≤50转食尸鬼；>50转尸兽。不是按死亡时剩余生命判断。 |
| CR12 | 轻语灵本体与头部分别可被索敌，共享生命。只有头部减伤，本体不减伤。本体保持远距离，释放头部飞向敌人进行近战攻击。 |
| CR13 | 瓦吉特龙卷可以对空。 |
| CR14 | 监守者声波可以穿透。 |
| CR15 | 独眼巨人可以吞噬飞行单位，仍须满足距离及吞噬对象条件，不要求其先进入俯冲窗口。 |

转化档位以连续数值区间表达，避免生命值存在小数时20与21之间出现空档。若未来最大生命限定为整数，等价于用户给出的≤20、21—50、>50。

## 两个关键时序

**地面对空窗口**：飞行目标下降 → 视为地面 → 地面单位索敌 → 检查距离并启动前摇 → 目标升空 → 本次近战仍命中 → 下一次攻击前重新索敌。

若上述“启动前摇”尚未发生，目标已经升空，则不能开始这次仅对地攻击，立即重新选择合法目标。范围攻击在自身生效时判断区域内各目标当时的资格，不沿用单体近战的前摇承诺。

**尸巫转化**：尸巫A伤害目标 → 尸巫B随后伤害同一目标 → 其他友军击杀 → 只生成一个随从，归B → 节肢优先，否则依据最大生命选择类型。只有伤害事件更新转化标记，普通索敌或没有产生伤害的接触不等同于“伤害过”。“实际伤害”建议以正的生命损失为准，护盾等新增机制另行明确。

尸巫死亡不会撤销它已经造成的有效标记。标记必须保存来源身份及施加伤害时的阵营快照，不能因为来源实体已经销毁而改归最后击杀者、取消转化或寻找另一名尸巫。转化仍只发生一次。

## 程序验收增补

| 用例 | 预期 |
|---|---|
| 两种冲锋单位装配不同阈值、倍率和CD | 分别按自身参数启动，只有严格大于距离阈值才允许；真实加速移动并造成伤害 |
| 近战前摇后目标退远 | 本次单体近战命中，不因距离拉开落空 |
| 地面攻击已前摇，目标升空 | 本次命中；后续不再继续把常态飞行目标视为合法地面目标 |
| 地面单位已选敌、尚未开始攻击，目标升空 | 不启动攻击，不消耗该次CD，重新索敌 |
| 俯冲目标遭地面范围攻击 | 窗口内可命中；窗口外不能因先前在窗口内而继续命中 |
| 成功启动后硬控打断 | 未发生的效果取消，CD继续且不退款；已发生效果不撤销 |
| 重复强弱状态 | 同种不加算伤害，较弱新效果不覆盖较强效果，时长刷新；异种并存 |
| 术士标记结束后目标移动 | 落点固定，离开后可避开轰击 |
| 自爆同距离命中相同防御的敌友目标 | 友军使用0.5阵营倍率；防御结算顺序定稿前不强求最终HP损失总是恰好一半 |
| 尸巫伤害后由他人击杀 | 仍发生一次转化 |
| 多尸巫先后伤害 | 一次死亡只转化一次，归最后伤害它的尸巫 |
| 最后留下标记的尸巫先死亡，标记者之后死亡 | 仍转化一次；使用该尸巫留下的来源及阵营快照归属 |
| 节肢最大生命10/40/100 | 全部转为劫蛛，优先于生命分档 |
| 非节肢最大生命20/21/50/51 | 依次尸奴/食尸鬼/食尸鬼/尸兽；另验20.5属于食尸鬼 |
| 分别攻击轻语灵本体与头部 | 两者各自可选中，扣同一生命池；只有头部受击有减伤 |
| 龙卷/声波/吞噬 | 龙卷可命中空中，声波穿透多个敌人，合法小型飞行目标可被吞噬 |

上述是设计验收输入，尚未执行，不替代程序证据与独立复查。

## 仍未裁定的边界

- 多个阵营尸巫先后标记同一目标时，使用最后一次有效尸巫伤害保存的阵营快照；更具体的敌我变化规则留待对应玩法出现时补充。
- “尸巫伤害过”是否包括其随从、间接区域及持续状态伤害；首版建议仅尸巫自身来源的实际伤害，随从不自动继承标记能力。
- 轻语灵的同一范围攻击同时覆盖本体与头部时，是各算一次还是对共享生命只算一次；头部减伤具体倍率。
- 冲锋是只伤害锁定目标、伤害沿途目标还是终点范围攻击；途中目标升空/死亡如何收尾。
- 自爆友军倍率与护甲的先后顺序；范围伤害、处决与单体近战的前摇承诺是否有额外例外。
- 同状态刷新后的具体时长选择、持续伤害来源归属，以及各项技能正式数值。

这些问题单独保留，不阻止已确认规则进入S1设计；S2测试所用临时选择必须明确标注为fixture，不冒充用户已裁定。
