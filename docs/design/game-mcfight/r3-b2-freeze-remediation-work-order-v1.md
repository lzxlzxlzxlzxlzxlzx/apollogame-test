# R3-B2 冻结复查补救施工单

独立复查退回原因不是 B2 行为断言失败，而是原冻结包只含部分文件，不能安装或运行。请创建一个新的、不可变更的完整工程源快照，保留原失败包不动。

1. 在 `docs/design/game-mcfight/review/` 下创建新的带日期/序号目录，复制完整可运行工程源：根 `package.json`、锁文件、tsconfig、src、games、scripts、必要配置与 B2 文档/测试；排除 `node_modules`、缓存和构建产物。
2. 在新副本根目录安装锁定依赖，然后在**副本目录**运行 B2 定向 7 文件、`tsc --noEmit`、R3 审计；将命令、退出码、环境和结果写入 manifest。
3. manifest 明确副本的来源时间、文件清单/哈希方式、复查入口和六组撤修步骤。
4. 只有副本自身可运行，才交独立复查者重新执行完整清单。不得用共享目录测试结果替代。
