# R3-B4 能力预研与施工顺序 v1.0

日期：2026-09-17。B4 包含 14 个单位；本文件提前把它们归入共享能力，所有基础数值来自 [B4 旧版参数提取](r3-b4-legacy-parameter-extract-v1.json)。B4 不得在 B2/B3 未完成时开始实际装配，但其事实、接口边界和验收可提前准备。

## 2. 公共合同

### 击退

击退由同一次实际 Hitbox 命中产生，方向为来源到目标的归一化方向，力度由数据提供。击退不改变伤害来源或绕过目标资格；目标死亡时不保留无主移动效果。磁控机兵在**施放启动时**快照合法敌人数量，伤害为 `baseDamage + 敌数`，不得被同次结算中的死亡反写。

### 引信、自毁与爆炸

引信成功启动即开始 CD/锁定；硬控、目标失效或来源死亡按技能数据决定是否取消。爆炸在真实圆形几何内结算；苦力怕采用已裁定值：49 伤害、1.5 秒引信、60/24 半径、友军减半且自毁。核能苦力怕旧实现已核实为线性中心到边缘衰减：`damage = lerp(500, 100, distance / (200/24))`，引信10秒，爆炸后自毁。新版仍须补上辐照区的独立数据与生产链。

### 持续区域与多段范围

区域必须有独立实体、范围、段间隔、每段按目标一次命中、来源快照和生命周期。冰区/辐照区/冰雾不得通过直接重复扣血模拟。恐慌是硬控，必须走既有 Flow 取消语义；减速不是硬控。

### 声波、射线与穿透

监守者声波为可对空、可穿透的真实长条几何，采用 sonicDamage10、sonicRange220/24、sonicCooldown10秒、sonicSpeed300/24。穿透规则必须说明每目标一次、按首次交叠顺序结算，不能因持续接触重复命中。

## 5. 已冻结的旧版事实（2026-09-17 续）

本节只记录旧 Unity 工程可复核的行为；新版仍按既有 S2 规则统一状态、打断、伤害和目标资格，未证实的旧逻辑不自动继承。

### 食人妖

- 近战距离内，重击独立冷却可用时造成 27 伤害；否则普通近战造成 10 伤害。重击成功启动后进入 15 秒冷却；每次攻击的旧版通用攻击间隔为 0.85 秒。
- 旧版 `troll_immune_ranged` 会使 `Ranged` 与 `Beam` 两类伤害为 0；近战、爆炸、真实伤害不因该标记被拦截。新版应将此落实为**伤害类别过滤器**，不得用单位专属 if 分支。
- 其 `knockback_immune` 是单位固有标签。B4-D 必须同时验证重击独立 CD、远程/光束免疫，以及允许的其他伤害类别仍可命中。

### 女巫

- 若自身受伤且 200/24 范围内没有敌人，优先自疗 10，CD 2 秒。
- 若存在敌人，则在目标位置施放半径 48/24、伤害 6 的范围药水，CD 2 秒。旧版以固定随机流在“纯伤害／伤害+中毒／伤害+减速”三种药水包中等概率选择。
- 新版药水必须为独立落点区域或投射物命中区域，而不是直接改血；随机选择使用对局种子，状态仍遵从 S2 的刷新、不叠层与来源记录合同。

### 炽燃遗魂

- 初始为防御状态。防御时：近战伤害乘 0.1；远程与光束伤害为 0；其他类别继续进入正常伤害管线。
- 旧版在每次启动时由对局种子选择技能：地面目标在旋转、声波、骨弹三个候选中选择；飞行目标仅在声波、骨弹中选择。每次施放持续 2 秒；骨弹选中时解除防御，结束后恢复防御并进入 1 秒攻击冷却。
- 已提取的旧配置含旋转 2 段、每段 11 伤害、64/24 半径、1.5 秒间隔；近战 14。配置文件缺少骨弹和声波的部分参数，故不得擅自补数值；须在内容盘点中将其登记为待裁定参数。

### 已消歧的待提取项

- `食人妖远程防御来源过滤` 已完成：按伤害类别过滤，覆盖远程与光束。
- `炽燃遗魂防御掩码` 已完成：近战 10%，远程/光束 0，其他类别正常。
- `女巫攻击状态包` 已完成：三种等权候选，纯伤害／中毒／减速。
- `核能苦力怕辐照区` 与 `炽燃遗魂声波、骨弹的缺失旧参数` 仍未在旧配置中找到，保留为 owner 裁定项；B4 施工不得自行猜测数值。

## 6. B4-A / B4-C 旧版事实与新版裁定建议（2026-09-17）

### 磁控机兵

旧版在攻击成功启动时统计以自身为圆心、半径 100/24 内的存活敌人，伤害为 `2 + enemyCount`，随后对本次近战目标施加力度 20 的击退；攻击 CD 为 1.5 秒。B4-A 采用这一快照时点，且敌人数量不包含友军或已死亡单位。

### 链锤哥布林

旧配置为目标落点 80/24 半径、8 伤害和力度 10 的范围击退。B4-A 将其定义为一次真实圆形命中：每个合法敌人最多命中一次，伤害与击退共享同一个来源、接触和结算记录。

### 撼地龙

旧版怒吼每次启动持续 2 秒，并对所有非友军、非 Boss 的存活单位施加恐慌；其视觉冲击波半径来自 `roarRadius`。这与本项目“攻击应有明确几何范围”的规则不一致。

**新版裁定：**恐慌命中范围固定为配置中的 140/24 圆形，且只影响真实范围内、可受地面范围影响的合法敌人；Boss 免疫沿用为标签过滤。怒吼启动后 CD 为 10 秒，旧版额外 0–5 秒随机冷却不迁移，以保证数据可预测且可测。恐慌仍按 S2 硬控规则在下一次 Flow 决策取消未释放施法。

B4-C 公共探针必须分别覆盖：范围内非 Boss 被恐慌且取消未释放施法、范围外不受影响、Boss 不受影响、已释放命中不被回滚。

## 7. 旧版参数键不一致：炽燃遗魂（2026-09-17）

旧 Unity `RevenantAbility` 读取 `spinTickInterval`，但 `monster_config.json` 只有 `spinInterval=1.5`；旧加载器对缺键记录错误并返回 0。因此旧工程的旋转实际存在“间隔为 0”的缺陷，不能把其运行表现当作权威基线。

**新版裁定：**采用配置中明确给出的 `spinInterval=1.5 秒`，规范键名为 `pulseIntervalSeconds`，编译后为 `pulseIntervalTicks`。所有 B4 内容导入需运行“能力代码读取键 / 配置键”完整性校验；任意缺键为内容阻塞，不能以 0 代替。
