# MC Fight 冻结包发布门 v1.0

本门用于所有 R3 批次的独立复查包。过去 B2/B3 多次因副本缺文件而退回；自本文件起，程序自证通过不等于可交复查。

## 包含清单

冻结根必须包含 `index.html`、`package.json`、锁文件、tsconfig、Vite 配置、`src/`、`games/`、`scripts/`、运行和测试所需资源与基线 JSON、该批证据、测试、截图。`node_modules` 可以排除，但必须保留可由锁文件恢复的依赖声明。

## 在最终副本根目录执行

1. 使用锁文件安装依赖；若 Electron 下载受网络限制，可使用同锁文件的 `npm ci --ignore-scripts`，并在报告中注明。
2. 运行该批定向测试。
3. 运行 `games/game-mcfight` 全量回归。
4. 运行 `tsc --noEmit`。
5. 运行 `npm run build`。
6. 运行 R3 组合审计。

所有命令、退出码、测试数和环境说明必须写入冻结包 manifest；源清单至少提供 SHA-256 或同等可重现哈希。

## 独立复查前置

- 冻结包中必须含复查清单及每条撤修的目标文件、撤修动作和预期红灯。
- 可视化证据要复制入包，而不是只引用共享目录。
- 同一批新包使用新编号，旧退回包只读保留。
- 程序不得更新独立签核字段；只有独立复查 PASS 后由策划更新矩阵。
