- E2、E3补齐死亡后置、真实碰撞致死与非致死正常释放。E3继续验证前摇移动承诺、释放拍硬控、不补发与CD保留，并完成相关撤修。
- E3的136项基线及142项恢复集合包含s2-round2、flow和targeted-caster；s2-round2列明双实例三轮、追击改变、目标死亡、硬控、重复取消、来源死亡、重开隔离。Flow回归含两技能同一动作锁。
- E5补证两个技能独立CD、共享动作占用、不逐拍重启和三轮以上循环。新C1模板的宿主取消及移动挂点不在E5范围，需本批单独复查；它们不撤销此前原目标捕获能力合同的通过证据。

没有发现必须由本批新C1复查补足后才能关闭的原请求证据缺项。关闭限于已审配置与契约，不外推所有技能组合均无缺陷。
