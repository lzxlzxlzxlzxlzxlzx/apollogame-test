## 1. 技能如何复用

技能分为三个层次：**模板规定怎样执行；单位装配填写参数；单位实例保存当前状态。**

例如“单次扇形攻击”可以供挥剑、挥爪、尾扫使用。伤害、施法距离、扇形半径、角度、前摇、后摇、CD都由单位装配提供；每个单位再分别绑定自己的动作、特效和声音。不能因单位不同再写一份同样的攻击逻辑。

同一单位也可以两次装配同一模板，例如普通横扫和重型横扫，各有不同参数、表现和独立CD。共享模板不意味着共享剩余CD、目标或施法进度。

本版以 `$参数名` 表示需要填写的变量，不是程序语言表达式。内容制作时关键参数必须显式填写；缺值报错，不默认为0。复杂行为使用下文有限种类的组合，不接受任意脚本、任意条件表达式或按怪物名称分支。

## 2. 所有技能共同使用的规则

### 2.1 主动、触发与被动

- **主动技能**：由单位决策选择，例如普攻、激光、召唤。默认一个单位同一时间只能执行一个主动技能。
- **事件触发技能**：由明确事件启动，例如低血量变身、命中产生蝌蚪、击杀转化。必须声明次数限制、触发来源和是否打断当前主动技能。
- **被动修正**：例如远程免疫、穿甲、持续恢复，不占主动攻击槽；使用共享状态与效果规则。
- **移动策略**：追击、盘旋、蛇形穿梭属于行动策略；只有冲锋、跃击、俯冲这类有明确阶段的战斗位移作为技能执行。

每个独立被动/触发效果有自己的归属与计时。不能借“被动”让同一主动技能重叠施放。

### 2.2 技能执行阶段

默认顺序：**可用 → 前摇 → 生效 → 后摇 → 等待剩余CD → 可用**。CD可与前摇、生效和后摇同时推进，因此后摇结束时CD可能已结束。

| 阶段 | 规则提案 |
|---|---|
| 启动 | 验证目标、距离、状态、CD和动作占用；成功后记录一次施法编号和目标信息 |
| 前摇 | 播放准备动作，默认不伤害；可按技能类型显示预警 |
| 生效 | 在规定逻辑时间点产生命中、弹丸、位移或其他效果；多段技能有明确段数 |
| 后摇 | 本次技能已经完成主要效果，单位尚不能开始另一主动技能 |
| 结束 | 清除本次动作占用与临时状态；保留仍有效的独立弹丸或区域 |

用户已确认：CD从成功启动开始，未成功启动不扣CD；时间随战斗时钟推进，不因无目标、恐惧或当前忙碌而停走。全局暂停时停止推进。

前摇允许为0；但重复自动主动技能必须有正的完整动作时长或正CD，禁止同一逻辑时刻无限释放。开场是否可用由 `$initialCooldown` 明确控制，不自动等同于正常CD。

### 2.3 目标与距离

技能分别声明**选择谁、瞄准哪里、最终能伤害谁**。单位可以持有追击目标，具体技能也可以选择不同目标。候选目标的共同要求是阵营正确、存活、可被选中；特殊条件再由技能添加。

| 参数 | 含义 |
|---|---|
| `$castRange` | 启动技能允许的距离；建议统一测量“逻辑施法锚点到目标碰撞体最近点”的距离 |
| `$minCastRange` | 最小启动距离；没有限制时明确填0 |
| `$targetMask` | 可选目标：地面、飞行、自身等有限集合 |
| `$hitMask` | 实际可命中的空地状态，独立于选敌规则 |
| `$teamFilter` | 敌方、友方、自身或指定组合；不使用含糊的“所有目标” |
| `$lockMode` | 锁定实体、锁定地面点、持续跟随实体三选一 |
| `$aimMode` | 启动时固定方向，或生效时朝锁定实体瞄准；持续追踪另设最大转向速度 |

用户已确认：单体近战成功开始前摇后，目标仅因移动离开距离仍然命中，不再次以距离判定落空；死亡等失效不等于距离变化。用户进一步确认：已开始前摇后目标升空也继续命中，本次结束后再重新索敌。尚未启动攻击时，目标恢复飞行且不再合法，必须重新选择合理目标。锁点技能在原位置继续完成。持续追踪技能目标失效时停止后续伤害并收尾，不自动转向另一敌人。

用户已确认：飞行单位从进入下降阶段到回升完成之间，目标资格视作地面，因此可被仅对地单位选中，也可受到地面范围伤害；回升完成恢复飞行资格。需要常态对空的技能必须显式声明。旧版单位的对空差异以新版装配表逐项裁定。

### 2.4 伤害与效果变量

伤害来源只能选一种模式，不同时填写两套可能互相覆盖的值：

| 模式 | 可配置变量 | 计算含义 |
|---|---|---|
| 固定基础伤害 | `$damage` | 使用技能装配值 |
| 单位攻击派生 | `$attackScale`、`$flatBonus` | 单位攻击力×倍率，再加固定值 |
| 目标最大生命派生 | `$baseDamage`、`$targetMaxHpRatio` | 固定值加目标最大生命的一定比例 |

首版优先使用固定基础伤害，便于区分不同技能；需要攻击成长或百分比伤害的技能再显式选另外两种。上述公式是有限模式，不允许在配置中自由编写公式。

伤害进入统一结算管线：命中资格 → 免疫/防御修正 → 护甲规则 → 扣血 → 伤害/击杀事件。护甲具体公式未在本版冻结。每次施法记录施法者、技能装配与施法编号；每段命中再记录段号和受击者。

首版建议在启动时快照攻击方数值，命中时读取受击方生命、防御与状态。百分比范围伤害分别使用每个实际受击者的最大生命，不用主目标的生命替其他敌人计算伤害。

附加效果以有限效果表组合：伤害、治疗、施加/移除状态、击退、创建单位、创建区域、形态切换、符合条件时处决。每项效果明确触发于“有效接触”还是“实际造成正伤害”；默认命中附加状态在有效接触后判定自身免疫，不依赖扣血必须大于0。友军、自身与无伤害技能同样遵循明确目标过滤。

### 2.5 打断与死亡

默认规则提案：死亡强制停止当前技能，清除跟随施法者的光束、预警、反击窗口和临时姿态；已发射弹丸、已落地独立区域按各自寿命继续，保留原归属。只有冰冻、恐慌等明确归类为硬控制的效果可以打断；普通受伤、减速、仅禁足不打断。死亡属于强制终止。硬控制清单和位移中断落点细节仍待补齐，不给普通技能隐含硬控免疫。

前摇被打断后不产生未发生的效果，已发生的伤害不撤销；CD默认不返还。连续攻击被打断后取消剩余段数。冲锋/跃击/俯冲中断必须回到合法位置或合法高度，再清理动作状态，不能瞬移穿越障碍、永久悬空或残留对空窗口。

## 3. 通用技能装配字段

| 分组 | 变量/配置 | 约束 |
|---|---|---|
| 身份 | 技能模板、单位内装配名称 | 一个单位内装配名称唯一 |
| 时序 | `$windup`、`$recovery`、`$cooldown`、`$initialCooldown` | 单位秒，均非负；持续与连击模板另有时间参数 |
| 距离与目标 | castRange、minCastRange、targetMask、hitMask、teamFilter、lockMode、aimMode | 使用统一定义，不能各单位自行解释距离 |
| 伤害 | 伤害模式及其必需参数、伤害类别 | 不用单位“近战/远程”标签代替技能伤害类别 |
| 附加效果 | 状态种类/持续/强度，击退距离，治疗量等 | 状态叠加与免疫由共享定义控制 |
| 命中频率 | 每段一次、每次施法一次或显式接触间隔 | 必须选定，防止每帧重复扣血 |
| 行动 | 执行期间是否移动、是否转向、打断策略 | 默认锁定普通移动，持续跟踪仅允许规定转向 |
| 表现 | 动作标识、表现绑定引用、逻辑挂点 | 具体素材属于单位表现配置，不放在共享模板里 |

距离使用新版统一世界单位，角度统一用度，比例用0到1；显示层负责换算。变更攻速等修正默认只影响后续施法的时间快照，不在一次动作中途突然重排命中时间；动态CD修正作为后续单独规则。

## 4. 技能模板目录

以下每个模板都继承上述共同规则。参数表中的伤害、距离、时间均为变量；段数、形状和目标方式属于模板允许范围内的配置，不是任意修改模板逻辑。

### SK01 单体近战

**过程**：进入攻击距离 → 前摇 → 对锁定目标结算一次攻击 → 后摇。成功启动前摇后不因目标拉开距离而落空；已前摇后目标升空仍命中；尚未启动时按当前空地资格筛选。死亡等其他失效边界另行处理。

**专用变量**：`$hitReach`（动作与武器触及范围，用于表现对齐，不在前摇后作为距离脱锁条件）、伤害参数、附加状态、`$knockbackDistance`。hitReach与castRange分别填写，使用相同距离度量。

**复用**：卫道士、普通近战单位、监守者近战、食人妖普通攻击和重击、磁控机兵攻击。重击可以是同一模板的第二次装配，使用更长CD和更高伤害。

**验收**：不同单位同模板造成不同伤害；前摇期间敌人仅拉开距离仍扣血；每次攻击只命中一次。

### SK02 单次范围攻击

**过程**：前摇 → 在明确原点和方向生成一次命中区域 → 后摇。可以瞄准地面点、锁定目标位置或以自身为中心。

**专用变量**：`$shape`（圆、扇形、胶囊线段、固定组合形状）、`$radius`、`$angle`、`$length`、`$halfWidth`、`$originOffset`及伤害效果；只填所选形状要求的参数。十字符文为两条相交区域的固定并集，同一次施法对重叠目标只结算一次。

**复用**：擎天龙与撼地斯拉践踏、链锤哥布林横扫、末影傀儡猛击/符文、独眼巨人重击、暝煌龙甩尾/践踏。

**验收**：伤害形状与预警相同；交叠区域不多次命中；对空过滤不因范围攻击失效。

### SK03 分段连击

**过程**：前摇 → 依次执行有限段攻击 → 后摇；每段可以是单体或SK02支持的范围攻击。整个连击占用一次主动技能，不是反复重新决策。

**专用变量**：`$segments`列表，每段填写相对生效时间、命中形状/单体、伤害、方向偏移与效果；`$followBetweenHits`决定段间能否按规定速度跟进。段序时间递增，不能同时使用另一套“段数×间隔”来定义同一个连击。

**复用**：炽燃狂魂双斩、霜冻巨兽双爪、骸骨斩首者三连击、瓦吉特双扫、徘徊者双横砍、遗弃者啃咬。

**验收**：第三段可使用不同伤害和形状；第二段前打断则后续段全部取消；失去单体目标不自动转打其他人。

### SK04 持续区域攻击

**过程**：前摇 → 在施法者身边或前方重复产生范围攻击 → 后摇。范围持续跟随施法者的逻辑锚点，是否转向由参数决定。

**专用变量**：形状参数、`$tickCount`、`$firstTickDelay`、`$tickInterval`、每段伤害与状态。持续时间由首段延迟和段数、间隔推导，不再额外填写另一份可能冲突的总时长。每段对每敌人最多一次。

**复用**：喷火甲虫火焰、寒冬狼冰雾、霜冻巨兽冰雾、渊灵祭司法术、旋转攻击、雪怪首领狂暴、遗弃者周身声波、深潜者法师近身甩动。

**验收**：相同模板可配圆形旋转和扇形吐息；完整命中次数严格等于tickCount；死亡/打断不会留下继续伤害。

### SK05 投射攻击

**过程**：前摇 → 从逻辑发射点生成弹丸 → 后摇；弹丸独立飞行，按碰撞命中。目标可通过躲避使弹丸落空。

**专用变量**：`$projectileSpeed`、`$maxTravel`、`$projectileRadius`、`$flightMode`（直线/追踪）、追踪时`$turnRate`、`$pierceCount`、`$spreadAngle`、命中效果包。穿透计数表示最多命中多少个不同目标，必须为正整数；不填“无限”，通过足够的明确上限配置。

**复用**：骷髅箭、普通远程攻击、毒液、冰球、水弹、羽毛、导弹、骨弹、直线穿透龙卷和弧形声波的飞行载体。

**命中效果包**：单体伤害，或命中点范围伤害，二者默认互斥，避免直接目标额外多吃一遍伤害。可以附加状态、区域生成或召唤；需要两种伤害都发生时显式列出。

**验收**：高速弹使用连续路径检测，不穿过薄目标；穿透不重复命中同一敌人；来源死亡后仍能正确记账；追踪目标失效后按既定方向飞到行程结束。

### SK06 弹丸齐射

**过程**：前摇 → 按顺序发射多枚SK05弹丸 → 后摇，再等轮间CD。

**专用变量**：`$shotCount`、`$shotInterval`、`$spreadPattern`（同向/对称扇形/有限随机偏移）、`$spreadAngle`、每枚弹丸配置、`$aimPerShot`。轮内间隔与技能CD分开；同一次齐射共用一次施法编号。

**复用**：烈焰人三连火球、铜羽泽鹗双羽、徘徊者三连导弹、先驱者导弹群、炽燃遗魂骨弹。

**验收**：一轮数量正确且至少重复三轮；打断停止未发射的弹，已发射的弹继续；不同单位同时齐射互不串目标。

### SK07 持续光束

**过程**：前摇/预警 → 沿逻辑线段持续结算伤害 → 后摇。引导期间默认不能移动，可按最大转向速度跟随锁定目标。

**专用变量**：`$beamLength`、`$beamHalfWidth`、`$tickCount`、`$firstTickDelay`、`$tickInterval`、`$turnRate`、`$beamHitMode`（沿线所有合法敌人/仅锁定目标）、伤害模式。单体模式也必须满足光束相交，不能隔着画面范围扣血。

**复用**：撼地斯拉激光、徘徊者死亡射线、先驱者死亡射线。瞻远者射线若确定为会飞行的攻击则使用SK05，不仅因名称含“射线”就使用本模板。

**验收**：判定长度与画面长度一致；百分比伤害分别按每个受击者计算；打断后立即停止伤害并清理光束。

### SK08 标记后连续轰击

**过程**：标记目标 → 等待预警 → 按次数轰击标记位置 → 后摇。

**专用变量**：`$markDuration`、`$warningDuration`、`$trackingUntil`（标记结束/预警结束/全程）、`$tickCount`、`$tickInterval`、范围形状与每段效果。跟踪结束时保存最终落点，之后敌人可以离开该区域躲避。

**复用**：渊灵术士激光雨；可作为其他预警型连续轰击的模板。

**用户已确认**：术士跟踪到标记结束，之后固定落点，预警及轰击不再追踪目标，使敌人可以躲避。

**验收**：标记、预警、生效三段在画面上可区分；落点冻结后不追人；移动到圈外可避开后续段。

### SK09 冲锋攻击

**过程**：准备 → 沿确定方向/终点冲锋 → 结束攻击 → 后摇。冲锋期间接管普通移动。

**专用变量**：`$travelDistance`或`$destinationMode`、`$speed`、`$collisionWidth`、`$damageMode`（沿途一次/终点范围/两者）、两套效果参数、`$stopOnObstacle`。沿途命中每个敌人一次，终点伤害是否允许再次伤害沿途已命中者必须显式声明。

**复用**：骸骨斩首者冲锋、先驱者冲撞；大象/米诺菇已确认装配真实冲锋：仅当攻击目标距离大于配置阈值、目标属于地面且CD就绪时启动，大幅提高移动速度冲向目标并造成伤害。阈值、速度倍率、伤害和CD均由装配填写；沿途或接触目标时的具体命中模式待定。

**验收**：有真实位移和路径命中；不穿越禁止通行区；中断后位置合法并释放移动占用。

### SK10 跃击

**过程**：起跳准备 → 朝记录落点跳跃 → 落地范围攻击 → 恢复。

**专用变量**：`$leapDuration`、`$arcHeight`、`$maxLeapDistance`、落地形状和效果、`$landingPolicy`（原点附近最近合法落点）。起跳时锁定落点，不在飞行中随目标瞬移；仅视觉升高不自动获得无敌或飞行免伤。

**复用**：珊瑚傀儡、珊瑚巨兽、暝煌龙；遗弃者的接近跳跃使用无落地伤害的装配。

**验收**：两种珊瑚单位仅参数不同；敌人可离开落点躲避；落地与冲击视觉在同一逻辑时点发生。

### SK11 俯冲近战

**过程**：飞行接近 → 下降 → 近战命中 → 回升 → 恢复，完整过程占用动作槽。

**专用变量**：接近/下降/回升的速度或时长、命中距离及伤害、`$counterWindowOpenPhase`与`$counterWindowClosePhase`、`$returnDistance`。同一段运动不同时用速度和时长作为互相矛盾的权威数据。

**用户已确认**：进入下降阶段打开窗口，回升完成关闭；窗口期间目标资格视为地面，接受地面索敌和地面范围伤害。普通近战启动仍检查距离，启动后遵守已确认的距离保命中规则。尚未启动攻击便升空时，地面攻击者重新索敌。已开始前摇后的单体近战继续命中，之后再重新索敌。

**复用**：飞行娜迦毒性俯冲、恼鬼近战、沙漠蛛蜂蛰击、瞻远者近身爪击；具体单位是否使用全套俯冲轨迹待动作设计确认。

**验收**：窗口外不得新启动仅对地攻击；窗口内可被地面索敌和范围伤害。窗口内已经成功开始前摇的单体近战，在目标升空后仍完成本次命中；尚未开始攻击便升空则重新索敌。地面范围伤害按每次生效时资格筛选。中断、死亡、目标丢失后按约定收尾，不残留窗口或高度状态。

### SK12 蓄爆自毁

**过程**：合法敌人进入触发范围 → 启动引信并预警 → 爆炸结算 → 自身死亡。

**专用变量**：`$triggerRange`、`$fuseDuration`、`$blastRadius`、`$centerDamage`、`$edgeDamage`、`$falloffMode`（无衰减/线性）、`$allyDamageScale`、`$statusOnExplosion`、`$moveWhileFusing`。

无衰减时只填damage；线性模式填写中心/边缘值，两种伤害模式不能并存。衰减建议按爆心到目标碰撞体最近点的距离计算。自毁作为爆炸后的明确效果，不靠把自己列为受击目标来间接实现。

**复用**：苦力怕、核能苦力怕。两种自爆均对友军造成半额伤害，allyDamageScale=0.5，对敌为1；引爆者按自毁流程死亡。初版结算建议先算距离衰减，再乘阵营倍率，再经过受击者防御，具体顺序仍属提案。

**验收**：只爆炸一次；引信结束前死亡默认不爆；无敌不会阻止技能约定的自毁；友伤符合装配。

### SK13 恐吓怒吼

**过程**：准备 → 给范围内符合条件的敌人施加恐惧 → 恢复。没有伤害也能完整执行。

**专用变量**：`$radius`或明确的全场范围模式、`$fearDuration`、`$excludedTraits`。是否排除首领是目标过滤配置，不在技能中识别特定单位。

**复用**：撼地龙怒吼。初版保留排除首领的意图，是否全场仍待裁定。

**验收**：首领过滤、范围边缘、恐惧到期恢复均正确；恐惧能否中断其他技能遵循共享控制规则。

### SK14 治疗

**过程**：选择自身或允许的友军 → 准备 → 恢复生命 → 后摇，不超过最大生命。

**专用变量**：`$healAmount`或最大生命比例模式、`$healTarget`、是否可在满血启动。默认满血不可选。

**复用**：女巫自疗；吸血攻击在SK01有效伤害后附加治疗效果，不重新启动一个独立主动技能。

**验收**：不溢出最大生命、不复活死者；空放被拒绝时不消耗CD。

### SK15 召唤

**过程**：准备 → 按生成规则找到合法位置 → 生成指定数量单位 → 恢复。

**专用变量**：`$summonPool`、`$weights`、`$count`、`$spawnRadius`、`$maxAliveOwned`、`$lifetime`（永久至死亡或明确时长）、`$onOwnerDeath`、`$placementFailurePolicy`。随机结果使用战斗种子。

每只召唤物引用自身单位定义，自动装配其技能、阵营和归属；不在召唤技能里重复手填另一套生命/攻击。初版建议达到上限时不启动，部分位置失败则只生成成功部分，已启动的CD照常保留。

**复用**：唤魔者恼鬼、尸巫随机随从、跨座兽命中生成蝌蚪、击杀转化；后两者是事件触发的生成效果。

**验收**：新单位能独立攻击和死亡；有上限与归属；数量、寿命和主人死亡处理一致。

### SK16 持续地面区域

**过程**：在指定位置创建区域 → 按周期影响区域内单位 → 到期销毁。它通常是其他技能产生的效果，不单独抢占主动槽。

**专用变量**：`$radius`、`$duration`、`$firstTickDelay`、`$tickInterval`、周期伤害/状态、`$overlapPolicy`、空地与阵营过滤。建议作用时刻为firstTickDelay+n×interval且严格早于duration，到期先移除；须明确是否创建即命中。

**复用**：熔岩、冰区、污染区。不同来源的区域默认分别存在，持续状态是否叠加由状态规则决定，不能因同图标就合并伤害。

**验收**：能重复伤害、按时消失、保留正确来源；飞行目标不会误中仅地面区域。

### SK17 环绕接触区域

**过程**：创建若干环绕施法者的攻击区域 → 按轨道移动并产生接触效果 → 到期移除。

**专用变量**：`$count`、`$orbitRadius`、`$angularSpeed`、`$hitRadius`、`$duration`、`$contactInterval`、`$hitSharingScope`（单个区域/本次技能的全部区域）、`$maxActiveCasts`。

**复用**：远古遗魂沙暴。初版建议同一次沙暴多个龙卷共享“每敌人接触CD”，只允许存在一次沙暴；不影响其他技能使用。

**验收**：多个龙卷同时接触不会超额叠伤；跟随正确主人；主人死亡默认全部消失。

### SK18 分布式轰击

**过程**：准备 → 按空间分布生成多个预警点 → 各点延迟落下并产生范围效果 → 结束。

**专用变量**：`$pattern`（逐环/随机散点）、环数/环距或散点数量/半径、`$waveInterval`、`$fallDelay`、单点形状与伤害、`$dedupeScope`（单点/单波/整次施法）。空间点和时间序列由同一配置生成。

**复用**：瓦吉特石碑、远古遗魂石碑、暝煌龙陨石、先驱者手雷散布。陨石落点可附加SK16熔岩；周期陨石由独立被动时钟触发，不能被普通攻击忙碌状态冻结。

**验收**：逐环确实错时落下；预警先于伤害；去重符合配置；随机种子相同则落点相同。

### SK19 防御姿态循环

**过程**：进入防御姿态 → 维持 → 离开姿态 → 执行规定攻击序列 → 再决策是否重复。

**专用变量**：`$stanceDuration`、`$defenseProfile`、进入/离开时间、有限的后续技能序列、循环启动条件。子技能自身仍使用SK02等模板；整个循环只有一个调度所有者，不与单位普通决策同时启动子技能。

**复用**：紫水晶巨蟹缩地→破土→横扫。炽燃遗魂使用防御状态作为常驻被动，并在骨弹技能期间临时解除；无需强迫套用巨蟹的循环。

**验收**：姿态结束恢复正确受伤规则；死亡不保留免伤；循环退出后单位可以继续走位。

### SK20 条件处决

**过程**：检查目标条件 → 近身准备 → 命中时再次检查 → 处决 → 较长恢复。

**专用变量**：`$maxTargetMaxHp`或明确体型条件、`$allowedTargetTraits`、`$executionImmunityProfile`、恢复时间。条件不满足时此技能不可选，由单位选择其他技能，不能在模板里自动换成重击。

**复用**：独眼巨人吞噬。初版以目标最大生命阈值保留原意；用户已确认可吞噬飞行单位，不要求其进入地面窗口；仍须满足吞噬距离与其他条件。

**验收**：阈值边界正确；受免疫约束；输出统一击杀事件，不伪造成巨大普通伤害。

### SK21 形态切换

**过程**：生命阈值或明确事件满足 → 按切换规则结束/中断当前动作 → 播放转换 → 替换形态配置。

**专用变量**：`$triggerHpRatio`、`$targetForm`、`$oncePerBattle`、`$transitionDuration`、生命继承、旧技能CD继承、新技能初始CD。首版建议保留当前生命比例，新技能按自身initialCooldown起算，避免切形态重置所有CD获益。

**复用**：诡异蚊鬼低血量转飞行远程。目标形态引用单位的另一份形态装配，不创建新的独立身份，保留归属、伤害统计和选中关系。

**验收**：一次性切换不重复；空地、速度、技能和表现同时生效；控制与死亡中断不形成半转换状态。

### SK22 身体接触攻击

**过程**：行动策略更新逻辑身体形状 → 检测接触 → CD许可时产生接触伤害。

**专用变量**：`$bodyShapeRef`、`$contactInterval`、`$hitSharingScope`（整只单位/每敌人）、伤害和空地过滤。身体几何独立于图片，不给每个体节复制一套血量和主动技能。

**复用**：地面娜迦。初版按原意采用整只单位共享CD，一次只选择一个合法接触目标；只有头部可被选中受伤。身体长度随血比变化、低血加速由移动/形态参数描述。

**验收**：第二次及第三次接触可再次伤害；多个体节同帧不重复伤害；体节不阻挡原设计允许穿过的弹丸。

### SK23 分离攻击部位

**过程**：部署附属攻击部位 → 部位跟随/接近目标 → 通过已装配攻击技能输出 → 满足条件后回收。

**专用变量**：`$partDefinition`、`$maxPartDistance`、`$partMoveSpeed`、`$headDamageReceivedScale`、共享生命规则、回收条件。头部与本体分别可被索敌，但共享一个生命池；只有头部减伤，本体不享受该减伤。头部受到的有效伤害只扣共享血池一次。本体保持远距离，释放头部飞向敌人，由头部进行近战。范围攻击同时覆盖两部位时的去重方式待确认。

**复用**：轻语灵头部。附属部位拥有明确逻辑坐标、受击形状和攻击锚点，不能仅靠视觉特效在远处偷偷结算伤害。

**验收**：头部与本体共享生命且不重复扣血；超出距离可回收；主体死亡同步清理部位。

### SK24 骑乘组合

**过程**：部署时生成坐骑和骑手 → 绑定位置 → 各自独立战斗 → 坐骑死亡则解除绑定。

**专用变量**：`$riderDefinition`、`$mountAnchor`、`$dismountPolicy`、部署/人口计数规则。两者独立生命、技能、CD和目标；骑手位置由坐骑接管，不同时执行普通移动。

**复用**：国王蜘蛛与骷髅德鲁伊。它是部署与单位关系模板，不是在战斗中反复消耗CD的主动技能。

**验收**：坐骑死后骑手仍可移动与射击；骑手先死亡不会使坐骑消失；一组死亡不会解绑其他组。

## 5. 可复用被动与事件修饰

| 编号 | 规则 | 变量 | 代表 |
|---|---|---|---|
| M01 | 命中附加状态 | 状态、持续、强度、触发条件 | 中毒、燃烧、凋零、减速、冰冻 |
| M02 | 针对特征附加效果 | 目标特征集合、效果 | 蛛蜂命中节肢后禁足并落地，仍可攻击 |
| M03 | 周围敌人数增强伤害 | 统计半径、每敌增量、增益上限 | 磁控机兵；以命中时合法周边敌人计数 |
| M04 | 久未攻击的强化首击 | 等待时长、强化倍率或强化技能引用 | 不再用于大象、米诺菇；两者已改为距离触发、独立CD的SK09真实冲锋。此修饰暂作为未装配候选 |
| M05 | 周期生命恢复 | 每次恢复量、间隔 | 遗弃者、先驱者；与主动忙碌无关 |
| M06 | 击杀后效果 | 来源范围、效果、触发间隔、次数上限 | 先驱者回血、尸巫转化见已确认规则补充；禁止召唤转化事件自我递归 |
| M07 | 达到生命阈值触发一次 | 阈值比例、技能引用、每战次数 | 舐脑魔废料桶、诡异蚊鬼变身 |
| M08 | 防御与免疫 | 伤害类别掩码、倍率/免疫、状态免疫 | 食人妖、炽燃遗魂、火焰免疫、远程格挡 |
| M09 | 攻击穿甲 | 适用技能、穿甲模式/比例 | 铜羽泽鹗；只改护甲环节，不绕过无敌 |
| M10 | 周期触发技能 | 间隔、开场延迟、技能引用、并存上限 | 暝煌龙陨石；来源死亡停止新触发 |
| M11 | 针对目标类别的伤害修正 | 目标类别、倍率、适用技能 | 尸巫对空增伤；只改变指定技能，不改该单位全部输出 |

事件必须区分技能命中、实际伤害、状态伤害与击杀。任何连锁触发均保留原始来源，且每个事件每条触发规则最多处理一次；上限用于防止无限召唤与重复响应，不由表现帧决定。

通用校验补充：伤害、治疗、半径、长度非负；实际启用的飞行速度、重复间隔必须为正；段数与数量为正整数；比例在0到1内；权重非负且总和大于0；血量阈值模式、伤害模式与运动计时方式只选一种。内嵌技能和效果引用不得形成递归环；合法的战斗循环必须通过完成后回到决策阶段表达。

## 6. 单位如何决定使用哪个技能

初版采用**条件过滤＋优先级＋可选循环**，暂不为每个单位写独立评分算法。

1. 若正在执行主动技能，继续执行，不重新选招；明确允许打断的事件除外。
2. 根据当前状态、可选目标、技能CD和距离筛出可用技能。
3. 优先处理一次性危机触发，再处理装配中更高优先级的技能。
4. 普通技能按固定优先级、轮换序列或合法候选随机三种策略之一选择；随机使用战斗种子。
5. 没有可用技能时，向某个已选可用目标的合理施法位置移动，或执行配置的等待/盘旋策略。无法命中的目标不能让单位一直卡在无效站位。

策略也必须有参数：近远切换距离、优先级、循环顺序、阶段成功计数、随机权重、无技能时动作。技能自身只负责合法性与执行，不负责识别“现在我是哪个怪物”。

计数循环默认在一次技能完成后前进一步，被打断不计完成；多技能轮转在当前项暂时无目标时允许等待/接近，但不能越过未明确允许跳过的步骤。定时武器切换先提出切换请求，当前主动技能收尾后再应用，避免中途更换弹丸配置。

## 8. 动画、特效与判定

模板声明“准备、命中、持续、结束、被打断”等动作事件；单位表现绑定决定使用哪段动画、哪张图集及哪个音效。逻辑阶段决定命中时间，美术将动作接触点对齐到该时间，不能由动画播放回调反向决定伤害。

范围、预警与特效共用同一几何来源。圆形特效的主要有效轮廓对应radius；光束对应length与halfWidth；扇形角度变化必须使用支持该角度的表现方案，不能仅缩放图片假装准确。超出素材允许范围时报不适配，换素材不自动改战斗参数。

## 9. S2验证与待确认事项

先延续现有阶段/重复冷却/俯冲/打断验证，再用本版模板挑代表单位做可执行性验证。以下是追加设计目标，不宣称现有引擎都已支持。

| 验证组 | 验收目标 |
|---|---|
| 参数化复用 | 两单位同模板、不同伤害/范围/动作；改其中一项只影响对应单位 |
| 连续施法 | 两实例错时、不同目标、至少三轮，CD持续推进且不串信号 |
| 几何与表现 | 单体、圆、扇形、光束的边界与动画接触一致 |
| 生命周期 | 前摇、持续、位移各阶段被打断与死亡，效果与占用均正确清理 |
| 独立产物 | 弹丸、召唤、区域保留正确归属，并按约定到期或清除 |
| 多部件 | 俯冲窗口、娜迦体节、头部共享血量、骑手脱离各有实际行为证据 |
| 配置拒绝 | 缺必需参数、非法时间、重复装配名、无动作绑定及循环依赖均明确报错 |

## 已确认效果补充

持续状态：中毒、燃烧、凋零可并存；同种刷新时间不叠伤，保留较强效果。

尸巫转化使用“自身伤害标记→受标记者死亡→一次生成”的事件链；非击杀触发，不要求尸巫补刀。最后伤害它的尸巫取得唯一转化归属。节肢优先转劫蛛；其他最大生命≤20转尸奴，>20且≤50转食尸鬼，>50转尸兽。标记来源、死亡时去重、召唤归属都需独立记录。相关未定边界见确认记录。

SK05瓦吉特龙卷hitMask包含地面和飞行；监守者声波采用穿透命中，具体宽度和行程填参数。SK20独眼巨人可选飞行目标。
