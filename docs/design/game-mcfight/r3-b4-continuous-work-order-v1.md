# R3-B4 连续施工单 v1.0

本施工单在 B2/B3 冻结独立复查并行期间准备；B4 程序施工必须以公共能力和真实生产链收口，不得为单位写专属战斗分支。先阅读 `r3-b4-capability-preflight-v1.md` 与 `r3-b4-legacy-parameter-extract-v1.json`。

## 批次与顺序

1. **B4-A：击退与敌数快照**：磁控机兵、链锤哥布林。完成同源伤害/击退、启动敌数快照和多目标去重。
2. **B4-B：引信、自毁、爆炸、持续区域**：苦力怕、核能苦力怕、女巫。完成引信取消、自毁、友军倍率、线性衰减、治疗与落点区域。
3. **B4-C：多段范围、恐慌、光束/穿透**：撼地龙、撼地斯拉、监守者、炽燃狂魂、炽燃遗魂。完成硬控打断、每目标一次穿透、多段区域、防御伤害掩码与有序循环。
4. **B4-D：条件选择、重击、冰区**：洞穴蜈蚣、食人妖、霜冻巨兽、雪怪首领。完成毒刷新、伤害类别免疫、优先级与地面过滤。

## 共同交付门

每一组都要先有公共探针，再装配单位；每个单位须有真实生产身份场景、双实例三轮、硬控/死亡清理、来源记录及可视化关键场景。B4 14单位全部通过后才允许把 R3 从44/84更新至58/84，随后创建可构建冻结包并独立复查。

## 未裁定参数

核能苦力怕辐照区，炽燃遗魂声波/骨弹缺失参数，霜冻巨兽冰冻时长，雪怪冰区过滤，仍须以既有策划文档或 owner 裁定为准；不得猜测数值。
