## B5 公共能力门

1. 固定落点区域必须使用启动快照，目标移动后不跟踪。
2. 持续区域、召唤、部位实体均保存来源与生命周期；来源死亡后的保留/清理由模板数据明示。
3. 部位/共享生命与骑乘均须真实多实体，禁止镜像 HP 或单位 ID 分支。
4. 先完成固定落点、区域、召唤上限、共享生命四个公共探针，再装配 14 个单位。

## 已从旧 Ability 代码补充的行为事实

- **舐脑魔**：仅在生命低于30且尚未投桶时，对启动时目标位置施放一次桶伤害10/48/24并生成30秒、5 DPS污染区；其他情况下，飞行目标或距离大于100/24时使用4伤害中毒投射物，近身使用5伤害中毒近战。
- **唤魔者**：召唤优先于尖牙，旧版每15秒以对局随机流在来源附近30–60旧单位半径内生成2只恼鬼；尖牙近距为自身64/24圆形，远距为目标落点24/24圆形，伤害6、尖牙CD3秒。新版召唤位置和数量均须固定为启动快照与数据配置。
- **轻语灵**：旧版头部攻击的生成点是目标附近的随机位置，随后以100旧单位/秒向目标靠近并发射5伤害、60/24射程投射物；主体在头部活动时获得半伤。新版不采用随机位置直接写单位状态，必须以头部子实体和共享生命池实现。
- **悚怖尸巫**：每10秒召唤一次，旧版从4种召唤物均匀随机选择；常规攻击对飞行目标12伤害、地面目标6伤害，投射物速度240/24。新版召唤种类、上限与来源死亡后的留存均须配置化，并与既有“最后实际伤害尸巫拥有一次死亡转化”规则共存。
- **末影傀儡**：旧版私有三段循环为近战、以自身为圆心的72/24范围攻击、以及长240/24/半宽12/24/末端48/24的前向复合区域；基础伤害为10至16之间的对局种子随机值，成功启动后才前进，CD2秒并有1秒锁定。新版将其归入既有 `SkillCycle` 与复合几何能力，禁止重新写私有循环。
- **紫水晶巨蟹**：旧版顺序为5秒缩地（完全免伤）→2秒破土准备→48/24破土16伤害→3秒横扫准备→20/24横扫16伤害；缩地期间伤害拦截而不是删除生命。新版必须将该掩码、阶段清理和来源死亡取消做成通用 Flow 状态门。
