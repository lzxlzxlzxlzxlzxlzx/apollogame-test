## 首批结论

接受局部能力证据：实例化名字可隔离Caster触发；本地Timer/SelfRule可以错时执行单次动作；Hitbox可按当前Status过滤目标。

保留三项边界：同名信号广播、aggro每拍换Relation、空间标签本拍缓存。已知正向组合存在，不因反例直接宣布需要新增引擎能力。74绿包含反例成立，不是74项游戏验收通过。

## 目标与顺序

本轮只闭合最小技能执行链，不扩大单位数量或制作正式商店。分A/B两步，A的证据成立后再做B；某一步遇到真实表达缺口时提交失败证据，不绕过。

### A：两个同种单位，各自连续完成三次技能

实验状态：Ready→Windup→Active→Recovery→Ready。Cooldown是独立技能计时，不作为强制阻止其他技能的单位状态。

实验配置：前摇2 tick、Active 1 tick、后摇2 tick；开始一次施放时冷却重置为8 tick。两单位初始冷却分别0和3，产生错时启动。每单位同时最多一项主动行动；只有无动作锁且该技能冷却结束才可再施放。

状态的进入/转换/效果生效拍必须先列成逐拍表，再写断言。Flow新状态onEnter下一拍生效等差异必须显式计入；不能只检查运行足够多拍后最终等于某值。准备阶段若无法按该契约表达，报告精确差异，不暗改预期。

实验技能启动时锁定目标实体，施放期间aggro重选不覆盖本次锁定；在Active入口产生一次效果。基础场景目标静止、生命足够，不混入路径问题。每次运行轨迹含单位、技能、施放序号、阶段、冷却、锁定目标和效果次数。

验收：每单位至少3个完整周期；每周期效果恰好1次；两实例状态/冷却/目标不串；共享模板不被改写；不每拍反复重启前摇。

增加失败路径实验：

- 前摇中锁定目标死亡：取消本次，不换目标补打；保留已经开始的冷却。
- 前摇中收到实验打断信号：取消效果、清动作锁，保留冷却。
- 自身死亡：不再产生新的技能效果，清除所属临时执行实例；重新创建一局后无残留。

死亡/打断是受控测试输入，可通过伤害或声明的输入信号在指定tick注入；禁止由测试直接把技能阶段改成Recovery/Ready来伪装清理。生命周期必须由既有生产系统执行，不新增测试专用system冒充引擎能力。

### B：真实接触链中的俯冲窗口

使用同一技能模板实例化两只飞行单位，错时执行，加入地面攻击者和友方对照目标。最小移动可为2D逻辑位移，不要求3D飞行动画或最终美术。

窗口：下降开始打开，回升完成关闭，期间目标资格视作地面。必须显式列出下降、攻击、回升与窗口的逐拍对应，不简单等同于通用Active/Recovery。持续时间为可观察证据可拉长，但必须列出fixture参数及逐拍表。

必须走真实位移→重叠检测→Trigger→Hitbox→扣血，不手工注入Trigger，不由测试直接翻转Status/Tag开启关闭窗口。开闭由技能阶段和现有能力消费数据产生。若现有能力不能表达，保留最小失败用例并提候选缺口。

最少证明：A开窗时B未开窗；窗口内真实接触可伤害；普通敌对攻击不伤友方；关窗后不能新启动仅对地攻击，地面范围攻击不能命中恢复飞行的目标；窗口内已经成功开始前摇的单体近战，则关窗后仍完成本次命中。另验已选敌但尚未启动攻击时关窗，立即重新选择合理目标。主场景额外加入正常地面敌人，不能把“地面攻击只能打有WINDOW的单位”误当完整对空规则。

记录窗口、查询、接触和命中的生效顺序；当前目标不合法时是否立即重选或下一拍重选可以报告为实验实现差异，但命中不能借旧缓存绕过本拍规则。

打断分两种实验：前摇打断不打开窗口；窗口中打断取消飞行单位的后续攻击，并经历明确的恢复收尾后关闭窗口。具体时长是fixture，不代表最终控制设计。死亡不应留下活跃攻击或可选中的残留单位。
