# MC Fight：剩余56个单位的素材绑定清单 v1.0

日期：2026-09-16。该清单连接R3内容身份与S6正式表现制作。现有旧Unity图片可在R3作为可识别静态立绘接入；动作、攻击特效、死亡表现和声音的正式验收在S6进行。素材永远不决定命中范围或伤害，逻辑几何才是唯一判定来源。

## 1. 当前可用素材

剩余56个单位均已盘点到旧版 `idle.png`。其中54个同时有单张 `attack.png` 候选；`stradpole` 和 `vex` 没有攻击图。56个单位均没有可直接使用的死亡图。本批的图片路径均为：

`Assets/Sprites/Monsters/<unit-id>/idle.png`

`Assets/Sprites/Monsters/<unit-id>/attack.png`

除下表注明的例外外，攻击图的性质是“单姿态候选”，可用于商店详情、战场待机/攻击状态切换和动作制作参考，不能当作完整攻击动画。

## 3. 表现绑定合同

每项绑定必须记录：`unitId`、`skillLoadoutId`、`phase`、`assetId`、锚点、默认朝向、镜像策略、逻辑几何引用、接触关键点和允许的视觉偏差。

- 逻辑命中时点由Flow决定，动画只对齐，不能由渲染回调触发伤害。
- 攻击特效的轮廓须覆盖逻辑形状的主要边界；装饰光效可超出，但必须可区分。
- 单姿态攻击图的可用范围是待机/攻击切换和制作参考。只有获得准备、接触、恢复三个关键段后，才可标为动作通过。
- `stradpole` 与 `vex` 的攻击动作必须新制；所有56个单位的死亡表现均需制作或采用明确的统一死亡方案。

## 4. 分期

R3期间：把全部 `idle.png` 作为可识别的单位主体立绘接入商店和战场，并登记未绑定表现槽。

S6期间：按本清单完成攻击动作、投射物/范围特效、命中反馈、死亡表现和声音；再用攻击范围叠加预览验证锚点、朝向、接触时点与逻辑几何一致。
