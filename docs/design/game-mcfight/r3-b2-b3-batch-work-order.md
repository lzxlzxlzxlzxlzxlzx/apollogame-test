# MC Fight R3-B2+B3 批量程序施工单 v1.0

日期：2026-09-16。前置状态：B1四个标准投射物单位已程序自证；B2的 `Hitbox.onHitStatus`、状态刷新、来源快照与OverTime公共能力已程序自证；S3当前程序门通过，尚待独立复查；S4不因旧门结果自动继承通过。本单允许程序连续完成B2和B3的内容施工，最后再集中执行全量回归与独立复查。

## 1. 目标与完成口径

本批完成16个单位的实际战斗装配：B2的8个状态/扇形/齐射单位，和B3的8个冲锋、俯冲、飞行近战与形态单位。若全部身份场景通过，程序自证计数由28/84提升至44/84；独立复查通过前不得把这一数字记为R3正式通过。

公共能力已验证不等于单位身份通过。每个单位必须经过真实 Flow → 移动 → 接触 → Hitbox → 伤害/状态 → 清理链路，完成自己的三轮、双实例和取消场景。

## 3. B3：冲锋、俯冲、飞行近战和形态（8个）

### 3.1 已裁定的统一机制

- **冲锋 SK09**：仅地面目标、距离至少4世界单位、技能CD就绪时启动；速度为基础移速3倍；首次真实接触造成一次伤害；成功启动即扣CD，硬控或死亡取消未发生命中且不返还CD。
- **飞行近战/俯冲 SK11**：下降阶段开始时开启地面资格窗口，回升完成关闭。已开始前摇的目标快照仍在本次命中时兑现；未开始前摇则下一次索敌重选。窗口中地面近战仍要满足攻击距离。
- **随机选择**：同一时刻多个技能合法时，使用现有seeded PRNG从合法候选均匀选择；选择、CD、阶段和随机状态均为单位实例私有。
- **非硬控的特殊减益**：沙漠蛛蜂的“蛰晕”只限制移动并使飞行节肢落地，目标仍可攻击，因此它不是Flow硬控，不取消正在进行的施放。
