## 原始要求与实查

基线 `s4-playable-vertical-slice.md` §5：完整碰撞圆位于己方矩形区域；圆相交拒绝、外切接受；失败保持拖前位置且不挤开其他单位；可撤回待命栏，battle不可拖。

查阅 `docs/playbooks/movement-pathfinding.md`、`docs/playbooks/pick-list.md` 和 `src/assembly/capability-registry.ts`，注册的自由拖放入口为 `t2-drag-place`。其describe说明“缺省自由落点”；`src/skills/tier2/drag-place.ts` 的free分支直接 `t.x = drag.tx; t.y = drag.ty`，没有自由矩形/完整Shape/占位拒绝字段。

- hex分支会吸附格子并与占据者换位，与本轮禁吸附/禁挤开的规则冲突。
- `t2-bounds-clamp` 是夹取/反弹，不是恢复拖前位置。
- `t2-collision-resolve` 是位移分离，不是拒绝这次拖放。
- 先写非法Transform再在UI/adapter改回会形成第二份部署规则，也不是同一事务的生产能力校验。
- `drop-zone`现有售出路径绕过Draggable.onlyFlag；本轮若使用该路径还需显式阶段约束，不能沿用“任何阶段可卖”的旧合同。
