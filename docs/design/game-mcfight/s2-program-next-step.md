1. 目标捕获与失效取消：开始时捕获动态实体身份，追击重选不能覆盖；原目标死亡按当前实验契约取消，不换人补打。

3. 真实俯冲：实际位移、阶段开闭、空间查询、目标选择与伤害链路一起验证，不能由测试逐拍翻转状态伪装完成。

## 必须区别的三种目标判定

| 时点/攻击类型 | 已确认规则 |
|---|---|
| 选敌与启动检查 | 俯冲下降开始至回升完成视作地面；地面单位已选中但未攻击，目标就升空，则拒绝本次启动、重选且不扣CD |
| 已开始前摇的单体近战 | 锁定原目标，不因其拉开距离或恢复飞行取消本次命中；完成后再判断下一次目标 |
| 地面范围攻击 | 每次生效按当前空间与空地资格判断；不继承单体近战的前摇保命中例外 |

因此“目标失效”不能是一个不分场景的统一布尔判断：目标移动/升空与目标死亡不是同一种失效。捕获与检查接口必须能够表达启动资格和执行期间的不同检查策略，不能把捕获后每拍检查地面标签写死为取消条件。

前摇承诺只允许本次攻击继续，不允许后续普攻沿用旧资格，也不意味着关闭全局空地过滤。多段技能每段的承诺边界未全部定稿，不凭单次近战规则自行扩展为整套连击永久追踪。
