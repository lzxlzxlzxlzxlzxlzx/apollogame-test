## 验证顺序

1. 以既有独立复核为基线，保留 B 已通过的边界画面和验收记录，不重复扩展已修复的 R1—R3。
2. 复查双技能选择样例：距离、资格、独立冷却、动作占用及连续多轮；逻辑与默认 UI 已独立复查通过。
3. 绑定两套挥砍动作和一个俯冲样例，检查阶段、挂点、朝向和逻辑范围。几何占位不算动作适配通过。
4. 验证同模板不同单位参数与不同表现；再覆盖弹丸/光束、多段技能、固定落点轰击、持续区域和召唤归属。
5. 尸巫、共享生命部位、骑乘、蛇身等复杂组合各用最小代表验证。未定边界提前写清实验选择，不能默认为用户已批准。

范围伤害与单体近战分开验收：前者每次生效按当前几何和目标资格筛选；后者成功前摇后的目标不因离远或升空而取消本次。施法目标死亡的取消仍按现有明确标注的实验契约测试，正式死亡细则保持可追踪。

## 素材现在需要确定什么

现在先定“素材如何参与技能”，并准备少量代表素材；不要求先制作完整84种单位全部动画。

| 现在需定义 | 内容 |
|---|---|
| 视觉方向 | 战场视角、单位朝向方式、精灵或其他表现形式、统一尺寸标尺；尚未确认的作为候选方案 |
| 单位技能表现绑定 | 某单位的某项技能使用哪个动作、预警、攻击特效、命中特效和音效；缺项明确标记 |
| 动作阶段 | 前摇准备、生效接触、持续、后摇、打断和死亡分别对应哪些帧/片段 |
| 坐标与挂点 | 脚底、身体中心、发射点、近战起点、镜像和旋转方式；逻辑坐标由战斗计算，图片负责对齐 |
| 几何适配 | 圆半径、扇角、光束长度/宽度来自技能参数；透明留白和装饰光晕不算有效攻击范围 |
| 适配限制 | 动画允许的速度、尺寸、角度区间；超过限制换素材或表现方案，不靠任意拉伸掩盖 |

正式材质、音效、所有方向帧、全部皮肤可以后续制作，但最低限度的表现合同应在S2验证，而不是战斗完成后才考虑。

## 最小视觉验证包

| 样例 | 最少素材 | 验证目的 |
|---|---|---|
| 两个单位共用挥击 | 两套不同单位动作；共享命中形状预览 | 同模板、不同伤害/范围/动画，时间与几何一致 |
| 地面与俯冲单位 | 地面攻击动作；飞行下降/命中/回升的可辨识表现 | 窗口与真实位置吻合，升空前后两种重选结果可观察 |
| 持续光束 | 发射点、光束本体、命中反馈 | 长度/宽度/转向与伤害同源，打断清理 |
| 标记轰击 | 追踪标记、固定预警圈、落地命中 | 标记结束固定落点，敌人确实能够躲避 |

第一轮可以使用现有精灵加程序化位移、缩放或简单测试动作。几何占位适合验证伤害和流程，但不能据此认定正式动画品质、可读性和素材适配已通过。动作绑定验证至少包含真实的可区分动作素材。

## AI素材制作流程

先列缺口，再按已确认风格生成：单位参考图 → 外观一致性确认 → 指定动作或关键姿态 → 图集/帧序与透明边缘整理 → 挂点和阶段绑定 → 引擎内逐帧验收。

AI适合补单位原画、图标、攻击姿态、特效图案与素材候选。生成图不自动等于可用动画，连续帧仍需检查比例、朝向、武器位置、锚点和轮廓一致性；透明背景也需验证。光束、范围预警等几何明确的表现优先考虑由渲染能力按逻辑参数绘制，避免为每种半径生成图片。

每批素材任务应写清单位/技能、用途、视角与朝向、参考外观、动作阶段、画布规格、透明背景要求、锚点、适用尺寸及验收方式。先做小样验证，确认后批量扩展。本轮未开始AI生成，不预设最终美术风格。
