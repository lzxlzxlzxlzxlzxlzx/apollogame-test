# REQ-B4-REVENANT-01：炽燃遗魂缺失参数裁定单

旧 Unity 配置缺失声波和骨弹参数，不能复原为有效运行数值。以下是与旧 UI 文案、2 秒施法时长、旧代码结构一致的**推荐新版参数包**，等待 owner 采用或修改。

| 技能 | 推荐参数 | 理由 |
|---|---|---|
| 旋转 | 2 段×11，64/24，1.5 秒间隔 | 旧配置已确认。 |
| 声波 | 4 段×4，圆形64/24，每0.5秒一段，附 Burn；对空；2秒施法 | 旧 UI 明示4次/4伤害/64px；旧代码为自身圆形并附Burn。 |
| 骨弹 | 4 枚×6，0.5秒一枚，射程160/24，速度300/24；对空；2秒施法 | 旧 UI 明示6伤害；单位原攻击范围160，旧代码投射物速度300。 |

共同规则：地面目标从旋转、声波、骨弹中 seeded 等权选择；飞行目标只从声波、骨弹中选择；骨弹施法期间关闭防御，结束后恢复；成功启动后1秒 CD；失败/取消不推进随机流。所有多段/投射物使用来源与目标启动快照。

owner 可直接回复“采用推荐参数包”，或逐项替换任何数值/形状。未裁定前，B4 不可将炽燃遗魂标为通过。
