## 3. 正式规则合同

### 3.1 状态效果

实现可由任何伤害命中配置的状态载荷，状态实例按目标实体和状态种类隔离。采用旧版明确值作为R3兼容基线：

| 状态 | 持续 | 效果 |
|---|---:|---|
| 燃烧 `burn` | 10秒 | 每秒1点真伤；火焰免疫目标不获得状态。 |
| 凋零 `wither` | 4秒 | 每秒3点真伤。 |
| 减速 `slow` | 5秒 | 移速乘0.7；攻击间隔除0.7。 |

- 同一种状态不叠加伤害或减速层数；再次命中刷新剩余时间，强度不同取较强效果。
- 燃烧、凋零和中毒可以同时存在。状态伤害必须保留原命中来源和实际HP回执；来源死亡后已有状态遵守既有来源快照规则。
- 冰冻、恐慌等硬控不属于本批新增状态，但状态系统不能破坏它们对Flow打断的现有合同。

### 3.2 标准投射物的状态载荷

在B1的投射物上新增可选 `onHitStatus[]` 配置。命中伤害和状态附加使用同一真实 `Hitbox` 结算；投射物未命中、被提前清理或目标不合法时不得附加状态。

- 流浪者：标准箭矢命中附带 `slow`。
- 鸡蛇：攻击间隔0.4秒的标准远程弹，命中附带 `wither`。
- 观测者：标准远程弹，命中附带 `burn`。
- 凋零骷髅：近战命中附带 `wither`。

伤害、射程、体型和基础攻击间隔均读取该单位 `effectiveAttributes`；空间字段继续除以24。除鸡蛇明确的0.4秒间隔外，任何与旧配置冲突的特有数值必须登记为阻塞，不得填默认值。

### 3.3 持续扇形攻击

实现一个数据驱动的扇形引导技能：启动后锁定本次方向；每个配置的间隔产生一次扇形真实几何命中；每个目标在不同段可分别受击，同一段不能重复受击。引导结束、硬控、死亡或来源销毁后，区域与表现事件必须清理。

- 喷火甲虫：扇形喷火，命中附带 `burn`。
- 寒冬狼：扇形冰雾，命中附带 `slow`。
- 扇形角度、半径、段数、段间隔、每段伤害必须从各自旧配置 `breathTicks`、`breathInterval`、`breathRange`、`breathAngle`、`breathDamage` 读取并转换；缺任一项则该单位保持待定，不用0替补。
- 两者复用同一个模板，差异只能来自配置和表现引用。

### 3.4 齐射与穿甲

**烈焰人**：成功启动后发射配置数量的火球；每枚弹是独立实体，有自己的方向、命中与清理。轮内间隔、齐射数量、齐射CD、伤害、射程和随机散布都来自旧配置；随机必须使用已有seeded PRNG。每枚命中附带 `burn`。

**铜羽泽鹗**：一次成功启动产生两枚独立羽毛，射程100px/24、每枚伤害1、速度350px/24秒、CD1秒。两枚都应用M09：目标护甲和韧性按0结算，但仍保留其他伤害资格和无敌规则。它是飞行远程单位，可攻击地面和飞行目标。

## 4. 必须测试

### 公共能力

- 同类状态刷新、不同DOT共存、强弱取高、燃烧免疫和状态来源快照。
- 状态伤害的实际HP回执、目标死亡清理、来源死亡后既有DOT完成，以及双实例不串来源。
- 投射物命中才附加状态；友军、未命中、失效或销毁弹均不附加。
- 扇形内部/外部边界、每段一次命中、多段重复命中、方向锁定、硬控/死亡中断清理。
- 齐射每枚独立移动、各自单次命中、散布seed可重复；两枚铜羽均忽略护甲/韧性。
- 新系统与Flow、aggro、motion、overlap、trigger、hitbox、resource、death、cleanup、B1投射物共装，审计必须 `cycles=0`、`unknown=0`。

### 身份场景

八个单位各有一个点名ID的三轮场景。除基本真实攻击、双实例隔离、硬控/死亡清理外，必须验证本单位在第2节列出的标志性效果。铜羽泽鹗额外覆盖对空；喷火甲虫与寒冬狼额外覆盖扇形边界目标。
