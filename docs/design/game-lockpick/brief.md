# `game-lockpick`《机关锁》立项简报

## 一句话玩法

玩家拖动 3–5 枚三档机关滑钮，通过不泄露答案的颜色与声音反馈逐步试探；全部滑钮归位即开锁，只有玩家确认“放弃”才失败。

## 产品定位

- 类型：独立、短局、无时限的逻辑试探小游戏。
- 宿主：DokiWorld App；世界判定、奖励与后果均由宿主处理。
- 首版难度：`easy | normal | hard`，分别对应 3 / 4 / 5 枚滑钮。
- 输入：仅难度枚举；答案、次数、倒计时、奖励、角色属性均不由宿主传入。
- 输出：仅 `success | failure`。

## 不可变规则

1. 每枚滑钮只有左 / 中 / 右三个稳定位置。
2. 每次有效移动后立即重算“位置正确的滑钮数量”。
3. 玩家只能看见整体指示器的颜色变化并听见对应声音；不显示正确数量，不标记具体哪枚正确。
4. 不限制操作次数，不设置倒计时，不因错误尝试失败。
5. 全部正确立即成功；只有玩家主动点击并确认放弃才失败。
6. 关闭页面、宿主卸载或连接中断不伪造 `failure` 结果。

## 首版边界

包含：三档难度、机关盘、离散滑钮、总体反馈、成功开锁演出、放弃确认、SDK 输入输出、包内资产闭包与调用说明。

不包含：真实锁芯模拟、撬锁针耐久、操作次数、限时、技能加成、道具消耗、奖励生成、永久进度、排行榜、宿主剧情后果。
