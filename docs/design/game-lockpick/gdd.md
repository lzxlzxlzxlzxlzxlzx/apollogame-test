# `game-lockpick`《机关锁》GDD v1

## 1. 核心循环

`读取难度 → 生成隐藏组合 → 玩家调节任一滑钮 → 即时整体反馈 → 继续试探 → 全对开锁 / 主动放弃`

本玩法没有“错误惩罚”与资源消耗。乐趣来自用整体反馈反推各滑钮位置，而非拼手速。

## 2. 难度表

| 输入 | 滑钮数 | 组合空间 | 其他差异 |
|---|---:|---:|---|
| `easy` | 3 | 27 | 无 |
| `normal` | 4 | 81 | 无 |
| `hard` | 5 | 243 | 无 |

难度只改变滑钮数量；不得暗加时间、次数、假反馈、不同档位数或操作惩罚。

## 3. 会话状态

| 状态 | 可接收操作 | 离开条件 |
|---|---|---|
| `ready` | `start` | 合法配置并生成目标后进入 `playing` |
| `playing` | `set(slot,value)`、`give-up` | 全对进入 `success`；确认放弃进入 `failure` |
| `success` | 无 | 开锁演出后向宿主完成一次 |
| `failure` | 无 | 放弃演出后向宿主完成一次 |

终局不可逆；终局后的重复输入必须被拒绝且不得二次完成 SDK 会话。

## 4. 组合规则

- 槽位编号为 `0..slotCount-1`。
- 每个值为 `0 | 1 | 2`，分别表示左 / 中 / 右。
- 初始显示值统一为中间 `1`。
- 隐藏目标允许重复值，但不得与“全部居中”的初始状态完全相同，避免开局无操作即成功。
- 目标只存在于模拟状态和快照中，严禁进入 LayoutNode、DOM 属性、日志文案、可见调试面板或 SDK 输出。
- 每次合法位置变化后计算：`matchCount = current[i] === target[i]` 的总数。
- `matchCount === slotCount` 时，在同一次提交中锁定成功，不等待额外“确认开锁”。

## 5. 反馈规则

反馈是整体线索，不泄露单槽答案：

- 中央指示器按 `matchCount / slotCount` 映射为由冷暗到暖亮的离散色阶。
- 每次有效移动均播放一次反馈音；音高 / 和谐度按当前档位变化。
- 数量未变化时颜色可不变，但仍要播放当前档位的确认音，让玩家知道输入已生效。
- 成功使用独立的金色常亮、机械解锁声与开锁演出。
- 不显示数字、百分比、“对了几枚”、单槽绿灯或文字答案。
- 为避免仅靠色觉，色阶还应同时改变亮度与脉冲强度；这仍是同一个整体指示器，不新增答案文本。

## 6. 输入与操作

- 鼠标 / 触控：拖拽滑钮，松手后吸附到最近的左 / 中 / 右档。
- 键盘：聚焦滑钮后方向键左右切换；Tab 可遍历所有滑钮及放弃按钮。
- 单次拖动只提交最终吸附值，不按中间像素连续计步。
- 动画期间不得锁死其他滑钮的状态刷新；输入是否允许并发由表现控制器串行化，但规则提交必须原子化。
- “放弃”必须二次确认，防止误触；只有确认按钮发出 `give-up`。

## 7. 画面结构

- 逻辑画布：1440×900，等比缩放，需同时验收 810×506 嵌入视口。
- 中央：金属 / 木质机关盘，3–5 条等距滑轨与可拖动滑钮。
- 上方：游戏名与一句简短说明“调节机关，观察光色与声音”。
- 中心或机关盘上沿：唯一总体反馈灯。
- 右下：清晰的“放弃”按钮；点击后以 Modal 二次确认。
- 成功：锁舌快速退开、盘面泛光、粒子与解锁声；约 0.8–1.2 秒后 `complete(success)`。
- 失败：盘面熄暗并短促回锁；约 0.5–0.8 秒后 `complete(failure)`。

UI 全部使用 LayoutNode；游戏屏不得手写 React、自由 DOM/CSS。首选 `apolloOnyx` house 主题。玩法状态只由模拟层提供，UI 只发闭集 Signal。

## 8. 确定性与种子

- 正式宿主业务输入仍只有 `difficulty`。
- SDK 的 `runId + instanceId` 属协议会话元数据，不是业务参数；适配层用引擎 `fnv1a32` 派生 32 位 run seed，再写入 `RandomSeed`。
- 独立验收由测试直接注入 seed；同难度、同 seed、同操作序列必须得到同目标、同反馈与同结局。
- 禁止 `Math.random`、墙钟参与规则与目标生成。

## 9. 音频

全部走 `SynthAudioPort` + `SfxSpec`，由具名 Signal 触发：

- `lockpick.adjust`：机械滑钮吸附声。
- `lockpick.feedback.0..N`：当前正确度档位音。
- `lockpick.unlock`：成功解锁声。
- `lockpick.give-up`：主动放弃 / 回锁声。
- `ui.confirm` / `ui.cancel`：确认框反馈。

静音时必须完全可通过颜色、亮度和动画操作；音频不得驱动规则。

## 10. 终局定义

- 成功：全部位置正确，由游戏自动判定。
- 失败：玩家点击“放弃”，并在确认框再次确认。
- 非结局：错误位置、任意次数尝试、页面关闭、iframe 卸载、SDK 断线、浏览器刷新。
