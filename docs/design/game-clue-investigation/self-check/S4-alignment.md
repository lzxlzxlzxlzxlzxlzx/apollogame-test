## 玩家视角复核八问

1. 核心信息：`0/2` 独立置顶、左下三项清单随收录变字；证物标题在弹卡顶部。灰盒场景本身不如原型可读，这是 S6 资产欠项，未算成已过视觉 1:1。
2. 操作确认：茶杯悬停有名称/金框，按下有亮度变化；鼠标及隔离触屏点击后进入档案条。证物点击则进入特写，同卡收录并更新 0/2。证据为 `S4-01c/01d`、`S4-02/03/04`、`S4-12` 截图和浏览器断言。
3. 结果明示：2/2 后不是只改数字，而是出现“调查完成”居中卡；取消有独立取消屏，不把它误称失败。见 `S4-05`、`S4-08`。
4. 数值差异：本局唯一主要数值为必需线索 0→1→2，进度条与计数同变，2/2 的独立完成卡明显强于 1/2；没有伤害/代价值需要另分级。
5. 阶段：标题、清单、特写、收录、完成/取消屏各有文案；这是无倒计时、无回合制的单场景调查，不能伪造“剩余时间”。
6. 新手键义：屏上“查看记录/退出调查/继续调查/收录证物/重开”是文字按钮；世界热点鼠标悬停显示“调查：物名”，键盘焦点有同名标签。初始灰盒身份在未悬停前仍弱，裁决去向：S6 换正式场景/PNG 后复验首次发现性，不用 S4 假标签改定稿构图。
7. 世界动作是否可达：七个调查 Action 均有世界热点及键盘镜像；记录开/合、退出、关闭、收录、完成/取消后的重开由真实浏览器逐条点过。`ui-inventory.mjs` 的传统 `games/<slug>/theme.ts` 抽词表入口不识别数据卡带，显式报缺 theme，不能把此脚本当 PASS；此处以五份 GD 剧本 + 14 图真浏览器路径 + manifest 的 `focusTargets`/LayoutNode 动作对照证明。
8. 归属与时效：本局没有对手席位；“必需线索”是玩家本次调查的 0/2，左下清单每项即时随收录变化；当前特写物名与选中 Resource 同步，完成/取消重开后回 0/2，未残留上一局卡片。浏览器重开再点窗锁、GD 第 05 剧本都覆盖此点。
