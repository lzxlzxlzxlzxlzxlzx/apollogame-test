# game111 · 核心循环与心流（策划）

> **本文回答一件事**：白天种菜、夜里打妖怪，凭什么是**一个游戏**而不是两个。

---

## 0. 一句话

> **你种的每一样东西，都会在今晚回来找你。**

这句话立住，整个设计就立住了。它把种田从「攒资源」变成了**排今晚的阵容**——
只不过那个阵容是来打你的。

**由此得到的核心张力，是一个玩家自己拧的旋钮**：

```
        种得多  ←──────────────→  种得少
        收成多                      收成少
        今晚来得多、来得凶          今晚清静
        打赢了回报也大              没什么可赚
```

**注意这不是惩罚种田。** 打赢的妖怪本身就是最好的材料与伙伴，
所以「多种」= 高风险高回报，是一个**赌注刻度**，不是一个陷阱。
玩家每天早上都在决定：**今晚我想过得多惊险。**

---

## 1. 判据：怎么知道它没做成两个游戏

**判据（写死，任何时候都能拿来验）**：

> **把夜战整段拿掉，白天的决策是否还一样做？**
> 如果一样 —— 那就是两个游戏，只是共用一个存档。

现在逐条验（白天的七个决策，每一个在夜里都有还账）：

| 白天做的决定 | 夜里怎么还 |
|---|---|
| **种什么** | 决定今晚来的是哪几派、什么味 |
| **种多少** | 决定今晚的压力刻度 |
| **收不收** | 收 → 变资源；不收 → **升阶**，明晚它更强 |
| **先收哪一格** | **最后收的那格凝聚出今晚的头目**（最后一捆） |
| **怎么收**（贪 / 敬） | 决定长出来的是**善妖还是恶妖** |
| **种不种葱蒜** | 葱蒜不产出，但**是防线**（辛派=工具派） |
| **跟镇上谁聊天** | 拿到**名字与传闻** = 夜里呼名的弹药 |

**七条全部有还账，且都在同一块有限的地上互相挤。** 判据通过。

> **「地是有限的」是这个设计的地基。** 种防守就少种收成，种收成就多来敌人，
> 想拿情报就得花白天的时间去镇上。**所有取舍共用同一个池子**，这才叫一个游戏。

## 2. 一天的心流曲线

心流的关键不是「有紧张」，是**紧张有形状**。一天要走完一条完整的弓。

```
张力
 ▲
 │                                    ██ 夜战
 │                              ▁▁▂▃▅█
 │                        ▁▂▃▅██  黄昏·预告
 │         ▁▁▂▂▃▃▃▃▃▅▅▅▅▅
 │   ▁▁▂▂▂▂  下午·劳作（节奏）
 │ ▁▂  上午·规划（动脑）
 │▁  清晨·看结果（放松）
 └──────────────────────────────────────▶ 时间
                                        └ 深夜·结算（释放）
```

| 时段 | 玩家在干嘛 | 心理 | 设计要点 |
|---|---|---|---|
| **清晨** | 看昨晚战果、田的状态 | 放松 · 有所得 | 先给糖，再提要求 |
| **上午** | 规划：今天种什么、为今晚排什么阵 | **认知投入**（最烧脑的一段） | 信息要全摆出来，别藏 |
| **下午** | 劳作：种、浇、收 | **节奏感 · 确定性满足** | 手感要顺，这是种田游戏的爽点本体 |
| **黄昏** | ⭐**预告**：田里开始有动静，能看出今晚会来什么 | 紧张上升 + **还来得及补救** | 见 §2.1，这是全局最关键的一段 |
| **夜** | 战斗 | 紧张顶点 | 回合制，让白天的知识真的能用上 |
| **深夜** | 结算、掉落、**学到新名字** | 释放 · 成长 | 收获里必须有**知识**，不只有材料 |

### 2.1 黄昏这一段，是整个设计的枢纽

**为什么不能没有它**：如果白天的决策要等到夜战结束才知道对错，
反馈延迟太长 → 玩家学不会 → 心流断掉。

**黄昏要做三件事**：

1. **显形**：田里该成精的地块开始晃动、发光、出声。**玩家能看出今晚来什么派、大概多少。**
2. **最后一次决策**：还来得及抢收一格（少一个敌人，但打断「最后一捆」的布置）、
   还来得及在门口挂一串蒜。
3. **确认或懊悔**：「我今天种对了」或者「我贪了，今晚要吃苦头」——
   **这个情绪必须在开打之前就发生。**

> 黄昏 = 把整天的决策**摊在桌面上让你看一眼**。
> 它让白天不是盲下注，而是一场你看着牌面收手的赌。

## 3. 夜战为什么必须是回合制（推荐 · 附理由）

**推荐：白天带时钟（忙）· 夜里回合制（静）。**

| | 白天 | 夜里 |
|---|---|---|
| 时间 | **实时 + 天光倒计时** | **回合制** |
| 压力来源 | 「来不及」 | 「打错了」 |
| 手感 | 忙碌、连贯、有节奏 | 冷静、要想、一步定生死 |

**为什么夜里不能也是实时**：

- 这个游戏夜战的乐趣来自**八派六味的克制**和**呼名**——这些都要**想**。
- 实时会退化成割草，玩家只会乱砍，白天攒的那一整套知识**用不上**。
- **白天攒知识、夜里用知识**，是这个循环的主心骨。实时战斗会把主心骨抽掉。

**两段的对比本身也是心流设计**：白天越忙，夜里的安静越有分量。

> 工程上顺带一提：现有 111 已经是回合制（`t2-turn-order` + 意图收齐门），夜战天然对接。
> 但**这不是推荐回合制的理由**——理由在上面三条，工程只是恰好不吃亏。

## 4. 三层循环（RPG 的位置在这里）

owner 定调「种田是大背景，为 RPG 服务」。那么循环要分三层，**种田只在最内层**：

| 层 | 周期 | 玩家在追求什么 | 内容 |
|---|---|---|---|
| **微循环** | 一天 | **今晚活下来，并且赚到** | 种 → 黄昏预告 → 夜战 → 结算 |
| **中循环** | 一季 / 一片地 | **拿下这片地** | 开垦新田 · 遇到区域主人（果树精）· 与镇上的人建立关系 · 学会一整派的名字 |
| **宏循环** | 主线 | **为什么会这样 · 我在找什么** | 剧情 · 人物 · 世界的真相 |

**中循环是 RPG 与生存游戏的分界线。**
没有中循环，这就是个无限刷的生存游戏；有了中循环，每一片新土地都是一个**章节**。

**中循环的节点长这样**：
开一片新地 → 这片地有主人（一棵老果树精）→ 你得先在它眼皮底下活几夜 →
学会它的名字 / 或与它谈判 → 拿下这片地 → 新的作物、新的派系、新的邻居。

> **「种田为 RPG 服务」的具体含义**：种田是 RPG 的**输入端**——
> 你种什么决定今晚遇到什么、队里有谁、手上有什么牌。它不是并列的第二个玩法。

## 5. 三个必须防的失败模式

### ✗ 失败模式一：两个游戏

**症状**：白天和夜里互不相关，中间只传递资源。
**判据**：§1 那条。**每次加新系统都拿它验一遍。**
**防法**：任何白天的新机制，上线前必须答出「它夜里怎么还账」。答不出就不做。

### ✗ 失败模式二：单调最优解

**症状**：玩家发现「无脑种 X 最优」，之后每天一样。
**防法**：
- 八派六味成环，没有最强的一味（`sect-taxonomy.md` §3）。
- **今晚谁来**要有轮换/不确定性，让玩家不能一套种法吃到底。
- 善恶由种法决定 → 同一种作物，两种种法长出两种东西。

### ✗ 失败模式三：惩罚种田

**症状**：种得越多越难 → 玩家不敢种 → 核心玩法被自己劝退。
**这是最危险的一条**，因为它是「你种的都会回来找你」的直接副作用。
**防法**（三条一起上）：
1. **妖怪是最好的资源**——打赢的掉落优于直接收菜。多种 = 多赚。
2. **葱蒜（辛派）给玩家一个"我可以更稳"的选项**——想保守就保守，不强迫赌。
3. **压力有上限**——单夜来袭数设天花板，别让种满一屏变成灭顶。

## 6. 一天的具体走法（用来验手感）

给美术和程序看的具体样子，也用来自查上面每条是否真落地：

1. **清晨**。昨夜战果摊在桌上：三样材料，一个新名字（「原来那种萝卜叫这个」）。
   田里有两格昨晚被踩坏了。
2. **上午**。今天有六格空地。你想：昨晚来的是根派，我手里有辣椒（热）克不了根派…
   要不种两格苦瓜（苦，克辛）？再留一格葱当防线？
   镇上娜洛昨天提过一句"后山那棵桃树最近不太对"——**要不要花半天去问清楚？**
3. **下午**。种下去：三格苦瓜、两格白菜、一格葱。浇水。
   顺手把昨天熟的那片萝卜收了——**留最后一格不收**（我想让它成精，它的掉落我要）。
4. **黄昏**。⭐留的那格开始晃。周围地面泛红——**是热味的，不是我预期的**。
   门口那串蒜还来得及挂。抢收另一格来减压？还是赌一把？
5. **夜**。来了四只。三只杂兵，一只从你留的那格里爬出来——**二阶，通灵**。
   你用苦瓜的毒压住杂兵，对头目——**你知道它的名字（娜洛的邻居提过）**，
   喊出来，它僵住一回合。你赢了。
6. **深夜**。掉落：一枚它的种子（可以种！）、一份材料、
   **一条新传闻**（「它说它不是这片土的」）—— 明天有得聊了。

> 第 6 步那条传闻，就是**中循环**在微循环里探出来的头。RPG 是这样长出来的。

## 6.5 对标校正（2026-09-15 补·详见 `benchmarks.md`）

查过热度高的同类之后，有两条要回填进本文：

**① 缺一条回程车流。** Rune Factory 成功的核心不是「有两个玩法」，而是
**地牢的怪能带回农场干活**——两条车流是双向的。我们目前田→夜战的路很清楚
（种什么来什么），**夜战→田的路只有掉落材料，太弱**。
**建议补**：打服的妖怪留在田里干活（善妖浇水、驱虫、守夜），
这样「结交」就不只是剧情好感，而有实打实的农业产出。

**② 我们的因果是反向的，这是我们比 Dave the Diver 更难的地方。**
Dave 是正向因果（抓鱼→赚钱→更强），我们是反向（种菜→变敌人→打你）。
反向张力更大，但**更容易滑向「惩罚玩家」**，即 §5 失败模式三。
**必须靠「妖怪本身就是最好的资源」把它掰回正向**，这条从建议升级为**硬要求**。

**③ 最该盯的镜子是 Farmagia**（概念最近、Steam 45% 好评）。
它的死因之一是「farming 是 afterthought」——**种田那一半必须自己就好玩**，
不能指望「反正晚上有仗打」来兜底。Stardew 卖三千万，战斗还是可跳过的。

## 6.6 ⭐「偷菜」——动词留下，僵尸换掉（owner 2026-09-17 提案的评判）

**owner 提案**：白天是菜地，晚上防止僵尸来偷菜。

**策划判断：一半采纳。「偷菜」是好东西，「僵尸」不能用。**

### 为什么「偷菜」值得留下（这是一个真贡献）

1. **动机直观到不用解释。** 「它要拿走我的东西」比「它要杀我」更具体、更私人。
2. **⭐ 它顺手解决了 §7 第 3 条我一直没答好的问题——失败的代价是什么。**
   输了 = **损失**，不是死亡。种田游戏的失败本来就不该是死。
   痛（我的菜没了）但不致命（我还能重种），正是这个品类该有的代价。
3. **中文玩家有文化记忆。** QQ 农场偷菜是一代人的共同经验，零教学成本。
4. **让「守」有了具体目标。** 不是守一条抽象的线，是守**一格一格的菜**。

### 为什么「僵尸」必须换掉

1. **正面撞 Plants vs Zombies。** 该系列 **2022 年已超一亿套**（见来源）。
   「植物 vs 僵尸」这个组合已经被定义死了，任何人做都会被立刻对标，**而且必输**。
2. **⛔ 它是外来威胁，会杀死整个设计的核心张力。**
   `core-loop.md` §0 的那句「你种的每一样东西都会在今晚回来找你」直接作废；
   种得多不再等于今晚更险，**那个玩家自己拧的旋钮没了**，地的有限性也不再产生取舍。
3. **前面所有素材全部报废**：八派六味、呼名、善恶由种法定、最后一捆、《抱朴子》成精论
   ——**全部依赖「作物本身成精」**。僵尸一条都用不上。

### ✅ 折中方案：**来偷菜的，就是你自己种的菜**

> **它们成精了，跑了。天黑了又回来——**
> **因为它们要长大，而地里还有别的菜。**

这一句同时做到三件事：

| 保住了 | 怎么保住的 |
|---|---|
| 「偷菜」的直观与低压力代价 | 动机没变，还是来拿你的东西 |
| 「你种的东西变成敌人」的独特性 | 贼就是你自己没收的那畦 |
| **给了妖怪一个比杀你更好的动机** | 它们不是来杀你的，**它们是来吃的**——更符合菜妖的调性，也更有趣 |

**额外收益**：`sect-taxonomy.md` §4 的「放着不收会升阶」从一条抽象规则，
变成了一个**有画面的威胁**：那格菜跑了，今晚它带着同伙回来偷你剩下的。

### 一句话对比（这大概是 owner 提案背后的真诉求：要一句能说清的）

| 版本 | 一句话 | 问题 |
|---|---|---|
| 僵尸版 | 白天种菜，晚上打僵尸 | 好懂，但**这是 PvZ** |
| ✅ 推荐版 | **你没收的那畦菜，天黑自己跑了，还带着同伙回来偷你剩下的** | 一样好懂，**而且独一份** |

> 两句都是一句话能说清。**第二句没有比第一句更复杂，只是没有撞车。**
