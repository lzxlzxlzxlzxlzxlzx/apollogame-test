## 0. 这是个什么游戏

### 一句话

> **白天你在地里种菜，天黑了，你没收的那畦菜自己跑了，还带着同伙回来偷你剩下的。**

### 三句话

一座小镇边上的一块地。**白天**你种菜、收菜、去镇上跟人聊天打听事情。
**天黑**，地里没收干净的作物会成精跑掉，夜里回来偷你别的菜。
你得守住它们——而**守住的办法，白天就已经决定了**：你种了什么、种在哪、留了谁没收、
从镇上打听到了谁的名字。

### 它长什么样（form）

| 面 | 形态 |
|---|---|
| **视角** | 2D 俯视，一块格子田 |
| **白天** | 实时（带天光推进），你在田里走动、种、收、出门 |
| **夜里** | **回合制**。田格变成牌桌，一步一步结算 |
| **认东西靠什么** | **图标**。萝卜就画成萝卜，不写名字（`sect-taxonomy.md` §0） |
| **一局多长** | 一个「日夜」= 一轮。长线 RPG，不是 roguelite 单局 |

### 类型标签

> **种田 × 卡牌战棋 × 东方妖怪 RPG**

## 1. 一天是什么样的（先看这个，最直观）

这是理解整个游戏最快的方式。

**清晨。** 昨夜的战果摊在桌上：三样材料、一个新名字（「原来那种萝卜叫这个」）。
田里有两格昨晚被踩坏了。

**上午。** 今天有六格空地。你盘算：昨晚来的是根派，我手里的辣椒（热）克不了它们…
要不种两格苦瓜（苦，克辛）？再留一格葱当防线？
镇上娜洛昨天提过一句「后山那棵桃树最近不太对」——**要不要花半天去问清楚？**

**下午。** 种下去：三格苦瓜、两格白菜、一格葱。浇水。
顺手把昨天熟的那片萝卜收了——**但最后一格不收**。我想让它成精，它的掉落我要。

**黄昏。** ⭐ 留的那格开始晃。周围地面泛红——**是热味的，不是我预期的**。
门口那串蒜还来得及挂。抢收另一格减压？还是赌一把？

**夜。** 来了四只。三只杂兵，一只从你留的那格里爬出来——**二阶，通灵**。
你用苦瓜的毒压住杂兵；对头目，**你知道它的名字**（娜洛的邻居提过），
打出那张呼名卡，它僵住一回合。你赢了。

**深夜。** 掉落：一枚它的种子（可以种）、一份材料、
**一条新传闻**（「它说它不是这片土的」）—— 明天有得聊了。

## 2. 核心循环与核心张力

### 2.1 核心命题

> **你种的每一样东西，都会在今晚回来找你。**

所以种田不是攒资源，**是排今晚的阵容**——只不过那个阵容是来打你的。

### 2.2 核心张力（一个玩家自己拧的旋钮）

```
   种得多  ←──────────────→  种得少
   收成多                     收成少
   今晚来得多、来得凶         今晚清静
   打赢了回报也大             没什么可赚
```

**这不是惩罚种田。** 打赢的妖怪本身就是最好的材料与伙伴，
所以「多种」= 高风险高回报，是**赌注刻度**，不是陷阱。
玩家每天早上都在决定：**今晚我想过得多惊险。**

### 2.3 判据（写死·防「做成两个游戏」）

> **把夜战整段拿掉，白天的决策是否还一样做？**
> 一样 = 两个游戏共用一个存档。

白天七个决策，每一个夜里都有还账：

| 白天做的决定 | 夜里怎么还 |
|---|---|
| 种什么 | 决定今晚来哪几派、什么味 |
| 种多少 | 决定今晚的压力刻度 |
| 收不收 | 收 → 资源；不收 → **升阶**，明晚更强 |
| 先收哪一格 | **最后收的那格凝聚出今晚的头目** |
| 怎么收（贪 / 敬） | 决定长出来的是善妖还是恶妖 |
| 种不种葱蒜 | 葱蒜不产出，但**是防线** |
| 跟镇上谁聊天 | 拿到**名字与传闻** = 呼名卡 |

> **地是有限的。** 种防守就少种收成，种收成就多来敌人，想拿情报就得花白天的时间。
> **所有取舍共用同一个池子**，这才叫一个游戏。

### 2.4 心流曲线（一天走完一条弓）

```
清晨 放松 ▁ → 上午 动脑 ▂ → 下午 节奏 ▃▅ → 黄昏 ⭐紧张+可补救 ▇ → 夜 顶点 █ → 深夜 释放 ▃
```

**黄昏是枢纽。** 不能让白天的决策等到夜战结束才知道对错——反馈延迟太长，玩家学不会。
黄昏要做三件事：**显形**（看出今晚来什么）· **最后一次决策**（抢收 / 挂蒜）·
**确认或懊悔**（「我今天种对了」或「我贪了」）。**这个情绪必须在开打之前发生。**

## 3. 白天：种田就是出牌 🟡

> 🟡 **卡牌化方案等 owner 批**（`card-fusion.md`）。下面按推荐方案写。

### 3.1 核心融合

| 卡牌游戏 | 种田游戏 |
|---|---|
| 把**一张牌**打到**牌桌的一个位置** | 把**一颗种子**种到**田里的一格** |

**这是同一个动作。** 所以不需要「收成→转成卡→再打出」这一层。

> **种下去，就是出牌。你白天种的每一格，就是今晚的一张牌——而且它已经在牌桌上了，盖着。**

**这样做的好处**：种田实感不丢（种田不是获取卡牌的手段，种田就是出牌本身）；
「种在哪」第一次真的重要；不用抽卡；黄昏抢收 = **把一张已打出的牌收回来**。

### 3.2 三个牌库来源 = 白天的三件事

| 牌种 | 来源 | 在牌桌上是什么 |
|---|---|---|
| **场面牌** | 种地 | 你种下的作物，已在桌上，盖着 |
| **技能牌** | 去镇上打听 | ⭐ **名字与传闻**（见 §6.2） |
| **随从 / 遗物** | 打赢并收服妖怪 | 长线常驻战力 |

> 白天时间有限 → **「今天去种地、去镇上、还是去打」本身就是构筑决策。**

## 4. 夜里：牌桌结算 🟡

- **回合制**，不是实时。理由：夜战的乐趣来自**克制与呼名**，这些要**想**；
  实时会退化成割草，白天攒的知识用不上，主心骨被抽掉。
- 田格 = 牌位。妖怪按格推进，你的作物按格响应。
- **妖怪的目标是偷菜，不是杀你。** 失败 = **损失**（菜被偷走），不是死亡。
  痛但能重种 —— 这正是种田游戏该有的代价。

## 5. 妖怪体系

> 详见 `sect-taxonomy.md`。世界观根据：《抱朴子·内篇·登涉》
> 「**万物之老者，其精悉能假托人形**」——不是被诅咒，是**长老了**。

### 5.1 两根轴（不是一根）

| 轴 | 决定什么 | 玩家怎么感知 |
|---|---|---|
| **派系 = 长在哪个部位** | 形态 · 体型 · 行为 · 打法 | 看图标就知道 |
| **性味 = 寒热辛甘酸苦** | 属性 · 克制 | 中国人本来就懂 |

### 5.2 八派（各有一个招牌机制）

| 派 | 成员举例 | 招牌机制 |
|---|---|---|
| **根** | 萝卜 土豆 山药 藕 | 钻地伏击 · **拔出来时会叫** |
| **叶** | 白菜 韭菜 菠菜 | 成群 · **割了还长**，要断根 |
| **果** | 番茄 茄子 辣椒 黄瓜 | 会爆 · **打死它你也挨一下** |
| **瓜** | 南瓜 西瓜 冬瓜 葫芦 | 硬壳 · **要先破壳** |
| **豆** | 玉米 豌豆 豆角 花生 | **打碎一个变成好几个** |
| **辛** 🟡 | 葱 蒜 洋葱 姜 | ⭐ **工具派**：主要不是敌人，是玩家的武器。辛味不打伤害，**它打意志** |
| **菌** 🟡 | 蘑菇 木耳 香菇 | **孢子会传染你的田** |
| **果树** | 桃 梨 枣 柿 石榴 | ⭐ **天生高阶**：菜一年一茬修不了多久，**果树活几十年所以成精必是老怪**。桃木辟邪 |

### 5.3 六味成环（各克一 · 各被克一 · 没有最强的一味）

| 味 | 战斗属性 | 克 | 被克 |
|---|---|---|---|
| 寒 | 冰 · 减速 | 热 | 辛 |
| 热 | 火 · 灼烧 | 湿(菌) | 寒 |
| 辛 | 破防 · 驱散 · 现形 | 寒 · 一切护体 | 苦 |
| 甘 | 治疗 · 护盾 | —（辅助） | 酸 |
| 酸 | 腐蚀 · 削甲 | 甘 · 硬壳 | 热 |
| 苦 | 毒 · 虚弱 | 辛 | 甘 |

### 5.4 修为四阶（靠玩家行为爬，不靠历史）

| 阶 | 名 | 特征 | 对应 |
|---|---|---|---|
| 一 | 初成 | 还是菜的样子，会动 | 杂兵 |
| 二 | 通灵 | 生出眼、口、肢 | 精英 |
| 三 | 化形 | 半人形，**能说话 · 能谈判 · 能呼名** | 小 Boss · 可结交 |
| 四 | 成道 | 有名号，支配一方 | 主线 Boss |

**升阶条件**：**在地里放着不收 → 越放越高阶**（这是种田的核心取舍）· 果树派天生起点高 ·
连夜没被讨伐会自己爬 · 受过供善待也会升，但升成善的。

### 5.5 善恶由种法决定 🟡

| 你的做法 | 长出来 |
|---|---|
| 按时收 · 留种 · 不贪 · 配植得当 | **善妖**：可结交 · 可入队 · 会帮你守田 |
| 抢收 · 连根拔尽 · 放任荒废 | **恶妖**：主动来袭 · 破坏田地 |

### 5.6 首批名册

**39 种**，八派六味齐全，全是菜市场有、图标一眼可辨的。**不选生僻、不选浪漫。**

## 6. 三条成长线

### 6.1 田 —— 你的产出与阵地
开垦、配植（**三姐妹**：玉米豆南瓜种一起才共荣）、嫁接。

### 6.2 名字 —— 你的知识 ⭐
> **呼名机制**（《白泽图》体例：知其名则不能害）。

- 不知道名字 → 手里**没有**对付它的牌，只能硬打。
- 打听到名字 → 获得一张**呼名卡**。
- 打出去 → 它僵住 / 现形 / 不战而退。

**呼名卡有别的卡没有的性质：它是知识，不是资源。** 用掉不消失，但**只对特定那一只有效**。

> **这条线把白天的社交变成了战斗力**，也是这套设计里**唯一没有对标、独一份**的东西。

### 6.3 伙伴 —— 打服的妖怪
打服了就带回家，替你种地、守夜。**这是回程车流**（Rune Factory 验证过的关键）。

## 7. RPG 层：三层循环

| 层 | 周期 | 玩家在追求 | 内容 |
|---|---|---|---|
| **微循环** | 一天 | 今晚活下来并且赚到 | 种 → 黄昏预告 → 夜战 → 结算 |
| **中循环** | 一季 / 一片地 | **拿下这片地** | 开垦新田 · 遇到区域主人（老果树精）· 建立关系 · 学会一整派的名字 |
| **宏循环** | 主线 | **为什么会这样 · 我在找什么** | 剧情 · 人物 · 世界的真相 |

**中循环是 RPG 与生存游戏的分界线。** 没有它这就是个无限刷；有了它每片新地都是一个**章节**。

**中循环的节点**：开一片新地 → 这片地有主人（一棵老果树精）→ 先在它眼皮底下活几夜 →
学会它的名字 / 与它谈判 → 拿下这片地 → 新作物、新派系、新邻居。

> **「种田为 RPG 服务」的具体含义**：种田是 RPG 的**输入端**——
> 你种什么决定今晚遇到什么、队里有谁、手上有什么牌。**它不是并列的第二个玩法。**

## 8. 美术与界面铁律 🟢

1. **用图标认植物，不用名字。** 选型偏菜市场常见，不写名字也认得出。
2. **妖怪形态必须看得出本体是什么。** 萝卜妖再怎么变，还是能看出是萝卜。
   **这是玩家把白天的知识用到夜里的唯一通路。看不出本体 = 设计失败。**
3. **命名只发生在一处**：**你嫁接出来的东西**。因为古书上没有它，你得自己起名；
   而没有名字的东西别人无法呼名克制它——**它只属于你**。

> 2 和 3 合起来是一个很干净的分工：**常见蔬果不需要名字（图标够），
> 唯独你亲手造的那几个需要你起名**。命名于是从 UI 负担变成**仪式**。

## 9. 市场定位（为什么这个游戏有机会）

> 详见 `market-report.md`（22 款 Steam 实例）与 `benchmarks.md`。

### 9.1 ⭐ 我们瞄的缺口

**整个「种田 + 战斗」品类里，战斗始终是弱的那一半。** 多个独立来源同一指向：

- **Stardew Valley**（3000 万份）：战斗**可跳过**，很多人通关没怎么进矿洞。
- **Fields of Mistria**（2026 新标杆，压倒性好评）：评测原文**「战斗比其他系统欠开发」**。
- **Farmagia**（Steam **45%**）：评测原文**「战斗缺乏深度」**。

> **没有一款把战斗做深。这就是我们的位置。**
> 八派六味 + 呼名 + 回合制卡牌，全部是冲着「战斗要想」去的。

### 9.2 ⚠ 我们独有的风险

**我们的因果是反向的。** Dave the Diver 是正向（抓鱼→赚钱→更强），
我们是**反向**（种菜→变敌人→打你）。张力更大，但**极容易滑向惩罚玩家**。

**硬要求：妖怪必须是最好的资源来源**，靠回报把它掰回正向。

### 9.3 别撞的车

**Plants vs Zombies 系列 2022 年已超一亿套。** 「植物 vs 僵尸」这个组合已被定义死，
做了必被对标且必输。**所以敌人不能是外来的僵尸，必须是你自己种的菜。**

## 10. 已有代码资产在新方案里的位置

111 之前已经做完并推送了一套**「LLM 驱动的 NPC 活世界」**（可跑、可测、能接 DeepSeek）。
**方向转向后它没有废，但位置变了**：

| 原来 | 现在 |
|---|---|
| 它是**主线**（整个游戏就是看小镇自己活） | 它是**情报层**——镇上的人见过、记得、会告诉你**名字与传闻** |

**这是一次降级，但是一次有价值的降级**：§6.2 的呼名线需要一个「名字从哪来」的答案，
而**已经做好的记忆系统 / NPC 对话 / 好感度，产出物直接就是呼名卡**。一行不用重做。

> ⚠ **但 `framework.md` 与 `capability-plan.md` 仍是纯活世界口径且已过 Lead 审。**
> **策划案定稿后要一并重审重写**，在那之前不许按新方向改实现——半改 = 两份图纸打架。
