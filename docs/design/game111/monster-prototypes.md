## 0. 结论先行（三句话）

1. **《山海经》里几乎没有「植物妖怪」。** 它有的是**异木异草**——有功效的奇植物（食之不饥、佩之不迷），
   它们不会动、不打架、不成精。拿它当怪物图鉴会扑空。
2. **真正的植物精怪在别处**：《抱朴子》给成精的**理论根据**，《太平广记》草木部/精怪部给**故事库**，
   《聊斋》花妖给**善妖**那一半。三者合起来，原型够。
3. **但原型数量从来不是这个游戏的瓶颈。** 《山海经》真正能给的不是「50 个妖怪」，
   而是**一套四槽构词法**——而那四个槽，恰好就是一场战斗需要的全部字段。
   **它是生成器，不是词典。** 这才是它对本项目的价值。

## 1. 《山海经》里到底有什么

### 1.1 植物条目的真实形态

山海经写植物是这个句式（《南山经·招摇之山》）：

> 有草焉，其状如韭而青华，**其名曰祝余**，食之不饥。
> 有木焉，其状如穀而黑理，其华四照，**其名曰迷榖**，佩之不迷。

注意三件事：

- **它不是妖怪**，是一株长得奇怪、吃了有用的草木。
- 功效是**给人用的**（食之 / 佩之 / 服之），不是它的攻击手段。
- 全书这类条目量级在**几十条**，且多数只是「其木多某某」的物产清单，没有独立形象。

### 1.2 高置信的几条（仍需比对原文）

| 名 | 出处（约） | 记载功效 | 可直接当什么用 |
|---|---|---|---|
| 祝余 | 南山经·招摇之山 | 食之不饥 | 口粮类掉落 · 恢复体力 |
| 迷榖 | 南山经·招摇之山 | 佩之不迷 | 饰品 · 防「迷路/混乱」状态 |
| 沙棠 | 西山经·昆仑 | 食之使人不溺 | 防「溺水/淤陷」 |
| 帝休 | 中山经 | 服者不怒 | 防「暴怒/狂化」 |
| 丹木 | 西山经 | 其味如饴，食之不饥 | 高级口粮 |
| 文茎 | 西山经 | 可以已聋 | 解「沉默」 |
| 嘉荣 | 中山经 | 服之者不霆（不畏雷） | 抗雷属性 |
| 荀草 | 中山经 | 服之美人色 | 外观/魅力向道具 |
| 黄棘 | 西山经 | 服之不字（不孕） | ⚠ 语义敏感·游戏里不建议直用 |
| 蓇蓉 | 中山经 | 食之使人无子 | ⚠ 同上 |
| 杜衡 | 西山经 | 可以走马（食之善走） | 加速 |
| 三珠树 / 不死树 / 建木 / 若木 / 寻木 | 海外经·大荒经 | 神树，无功效词 | **地标/世界树**，不是小怪 |

> ⚠ 上表是**检索起点不是定论**。进台账前逐条比对原文，尤其功效的动词（食之/服之/佩之
> 三者语义不同）与所属山名。**别把「大概记得」当史料**。

### 1.3 更值钱的：异兽条目的**四槽构词法**

山海经写怪兽的句式，抽掉内容只剩骨架：

```
其状如【A：已知动物】，而【B：部位变异】，其音如【C：声音】，
其名曰【D：名】，见则【E：预兆】／食之【F：功效】。
```

例：「其状如禺而白耳，伏行人走，其名曰狌狌，食之善走。」

**这六个槽，就是一只怪物在战斗系统里需要的全部字段**：

| 山海经的槽 | 游戏里是什么 |
|---|---|
| A 本体 | 哪种蔬菜（萝卜/南瓜/茄子…） |
| B 部位变异 | 外观变体 + 决定攻击方式（多首=多段攻击，人面=会说话） |
| C 声音 | 音效槽 + 出场提示 |
| D 名 | 图鉴 id（**见 §3 的「呼名」机制**） |
| E 预兆「见则…」 | **出场时的全场 buff/debuff** |
| F 功效「食之…」 | **击败后的掉落与料理效果** |

> 这就是我说「它是生成器不是词典」的意思。你要的不是抄 50 个名字，
> 是拿这套模板 × 你的蔬菜表，自己长出成百上千个变体——而且长出来的东西**天然带着战斗数值**，
> 因为 E 和 F 本来就是效果词。

## 2. 植物精怪真正在哪儿

### 2.1 《抱朴子·内篇·登涉》—— 成精的世界观根据

> 万物之老者，其精悉能假托人形，以眩惑人目而常试人。

**这一句是整个设定的地基。** 它说的是：任何东西活得够久都能成精。
于是「你地里的菜为什么会变妖怪」有了古典解释——**不是被诅咒，是长熟了、长老了**。

这条直接给出玩法钩子：**放着不收的菜会成精**。种田的「该不该现在收」从此有了取舍。

### 2.2 《白泽图》/《白泽精怪图》—— 名录 + **呼名机制**

古代精怪谱的核心逻辑是：**知道它叫什么，它就害不了你。**
这不是我编的机制，是这一类文献本身的体例（列出精怪名 + 遇见时呼其名）。

**这是本项目最大的一块金子**，理由见 §3。

### 2.3 《太平广记》草木部 / 精怪部 —— 真正的故事库

宋代类书，按类抄录唐前笔记小说。草木、精怪两部里有大量成精的树木花草（多为害人者）。
**这是「坏妖怪」那一半的主要来源**，且条目多、形象具体、有情节。

### 2.4 《聊斋志异》花妖 —— 「好妖怪」那一半

葛巾（牡丹）、香玉（白牡丹）、黄英（菊）等篇：花木成精化为女子，重情、能助人。
你要的「妖怪里有好的有坏的」，**善的那一半在这里，不在山海经**。

### 2.5 《酉阳杂俎·广动植》《搜神记》《述异记》

补充层：奇植物、木精、山中异物。量不大但形象生动。

## 3. 一条我建议你认真看的设计线：**呼名**

把 §2.2 的呼名机制接进来，这个游戏会突然变得和别的种田+战斗不一样：

- 每只蔬菜妖怪有**真名**（按 §1.3 的构词法生成）。
- **不知道名字**时只能硬打。
- **知道名字**时可以喊出来——直接压制 / 免疫它的预兆 / 让它不战而退。
- 名字从哪儿来？——**从白天来**：镇上的人见过、记得、会告诉你；你也可以自己观察归纳。

**这条线把这个游戏原本割裂的两半焊死了**：白天不再只是「攒资源」，白天是**情报**。
你和娜洛聊天、你记住谁说过什么，晚上真的能用。

> 这也正好接上 111 已经做好的东西：记忆系统、NPC 对话、好感度，全都不用重做，
> 只是它们的**产出物**从「称号」扩成了「名字」。

## 4. 那么，够不够？

**够。** 量化一下：

| 来源 | 能直接用的量级 | 用途 |
|---|---|---|
| 山海经 异木异草 | 几十条 | 道具/料理效果词表 |
| 山海经 异兽构词法 | **1 套模板 → 无限变体** | 小怪生成器 |
| 太平广记 草木/精怪 | 几十至上百条 | 恶妖 · 有名有姓的头目 |
| 聊斋 花妖 | 十余篇 | 善妖 · 可结交的妖 |
| 白泽图 体例 | 1 条核心机制 | 呼名玩法 |

**但真正的答案是**：一个种田+夜战游戏需要的不是「一本原型词典」，而是
**20–30 个精心设计、有名有姓、玩家记得住的头目** + **一台能生成无限小兵的机器**。
古籍给前者提供素材，给后者提供模板。**两样都有了。**

反过来说：如果只是照抄 50 个名字塞进表里，300 个也不够——玩家记不住的东西等于不存在。

## 5. 还没定的事（需要 owner 拍板）

1. **AI 活世界这条线怎么摆？** 111 目前已经做完的是「LLM 驱动的 NPC 活世界」，
   而新概念是「白天种菜 + 夜战」。两者的关系有三种可能，差别很大：
   - **A** 活世界是主线，种田/夜战是它的载体（§3 的呼名线走通就是这个）。
   - **B** 种田夜战是主线，NPC 只是村民（现有 AI 层降级为配角）。
   - **C** 两条线并行（**不推荐**：两个核心 = 没有核心）。
2. **善妖/恶妖怎么分**：是固定属性，还是取决于你怎么对待它（对应「妖怪也能结交」）？
3. **蔬菜成精的触发**：到期不收就成精（§2.1 那条钩子），还是入夜必然？前者让种田有取舍。
