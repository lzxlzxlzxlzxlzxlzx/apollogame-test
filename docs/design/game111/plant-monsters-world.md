# game111 · 世界植物妖怪总集（策划素材库）

> **定位**（owner 2026-09-15）：**种田是大背景，为 RPG 服务。**
> 所以本文不是「怪物图鉴」，是**按 RPG 需要的角色功能**重新编组的素材库：
> 谁能当敌人、谁能当伙伴、谁能当地标、谁能当剧情人物。
>
> **核查口径**：民俗条目按知识写出，**未逐条比对一手文献**。标 ⭐ = 高置信（流传广、来源明确）；
> 标 ⚠ = 需查证再用。进台账前该查的必须查。**不许把没核过的当史料。**

---

## 0. 最重要的一个发现（先看这个）

把全世界的植物妖怪铺开之后，它们**不是一堆散点，是清清楚楚的两大家族**，而且两家的行为逻辑完全相反：

### 家族一 · 树精（守地者）

> 德律阿得斯 · 木霊 · 列希 · 吉利督 · 木客 · 树精 · Tāne

- **绑在一个地方**，不移动。树死则它死。
- **本性不恶**，被冒犯才反击（砍它的树、闯它的林）。
- 古老、缓慢、话多、有规矩，可以谈判。

→ **在 RPG 里它们不是小怪，是「土地的主人」**：区域守关 Boss、地标、可结盟的势力、剧情给予者。

### 家族二 · 谷精（随收成而生的）

> 谷母 · 黑麦狼 · 正午女 · 玉米母亲 · 三姐妹 · 那利菓

- **随作物周期出现**：播种时不在，成熟/收割时现身。
- **绑在时间上**（正午、最后一捆、月圆），不绑在地点上。
- 会**赏也会罚**：敬它则丰收，慢待它则伤人。

→ **这一家才是你这个游戏的主干。** 全世界的农民早就想象过「庄稼到点会变成东西来找你」，
你不用从零发明这个设定——**它已经存在了几千年，而且每个大陆都有独立版本**。

> **策划上的意义**：你原来的想法是「蔬菜晚上变妖怪」。民俗给的版本更好——
> **不是所有菜都变，是「你怎么收」决定变什么**。见 §3 的三条机制。

## 1. 中国

### 1.1 世界观地基

| 条目 | 内容 | 怎么用 |
|---|---|---|
| ⭐《抱朴子·内篇·登涉》 | 「万物之老者，其精悉能假托人形」 | **成精的总法则**：不是诅咒，是长老了。给「为什么会变」一个古典解释 |
| ⭐《白泽图》体例 | 列精怪名 + 遇则呼其名 → 不能害 | **呼名机制**（见 §3.3），本项目最大的一块金子 |

### 1.2 异木异草（《山海经》）

**不是妖怪，是有功效的奇植物。**当效果词表用，别当怪物用。

| 名 | 记载功效 | RPG 用途 |
|---|---|---|
| ⭐祝余 | 食之不饥 | 口粮 · 回体力 |
| ⭐迷榖 | 佩之不迷 | 饰品 · 免疫「迷路/混乱」 |
| ⭐沙棠 | 食之使人不溺 | 免疫「淤陷/溺」 |
| ⚠帝休 | 服者不怒 | 免疫「狂化」 |
| ⚠丹木 | 味如饴，食之不饥 | 高级口粮 |
| ⚠文茎 | 可以已聋 | 解「沉默」 |
| ⚠嘉荣 | 服之不霆 | 抗雷 |
| ⚠杜衡 | 可以走马 | 加速 |
| ⭐建木/若木/扶桑/不死树/三珠树 | 神树，无功效词 | **世界地标**，不是怪 |

> 山海经**异兽**的六槽构词法（其状如A·而B·其音如C·其名曰D·见则E·食之F）
> 才是它最值钱的东西，详见 `monster-prototypes.md` §1.3。

### 1.3 成精的植物（真·妖怪）

| 名 | 出处 | 形象 | RPG 用途 |
|---|---|---|---|

## 6. 从素材里长出来的三条机制（策划建议）

这三条不是我发明的，都是民俗里现成的，**而且都直接可玩**。

### 6.1 「最后一捆」→ Boss 从哪来

欧洲收割习俗：谷精随镰刀步步后退，**最后没割的那一捆就是它的藏身处**。

→ **机制**：你一块地里最后收的那一格，会凝聚出当晚的妖怪。
**于是「先收哪一格」成了一个真决策**——你在决定今晚打什么。

### 6.2 「怎么收」→ 决定善恶

敬谷精（留一捆、扎成谷娃娃、留供）则来年丰收；贪尽则遭罚。

→ **机制**：**善恶不是妖怪的固定属性，是你种它收它的方式决定的。**
按时收、留种、不贪，长出善妖（可结交、可入队）；抢收、连根拔、荒废，长出恶妖。
这条同时回答了 owner 之前问的「善恶怎么分」。

### 6.3 「正午女」与「呼名」→ 对话即战斗

- 正午女在田里**向你提问**，答不上即受罚。
- 白泽图体例：**知其名则不能害**。

→ **机制**：夜战不是纯砍杀。你可以「喊名字」压制它，也可能被它**反问**。
名字与答案从**白天**来：镇上的人见过、记得、会告诉你。

> **这条把「种田」「夜战」「小镇里的人」三块焊成一个整体**，
> 而且 111 已经做好的记忆系统 / NPC 对话 / 好感度全部直接复用，产出物从「称号」扩成「名字与传闻」。

## 7. RPG 定位下，这批素材怎么分工

owner 定了「种田是大背景，为 RPG 服务」。那么：

| RPG 需要的 | 从哪家取 | 例 |
|---|---|---|
| **常规敌人**（量大、可生成） | 谷精家族 + 山海经六槽构词法 | 黑麦狼式的「作物兽」无限变体 |
| **区域 Boss / 土地主人** | 树精家族 | 列希 · 木霊 · 苹果树老人 · 库鲁皮拉 |
| **可结交 / 可入队的伙伴** | 聊斋花妖 + 吉利督 + 三姐妹 | 善妖线 |
| **师父 / 给予者 NPC** | 木客 · Aziza · 独脚鬼 | 交易与传授 |
| **世界地标 / 终局** | 建木 · 如意树 · Tāne Mahuta | 主线目的地 |
| **稀有捕获目标** | 人参娃娃 · 何首乌精 | 会逃的宝 |
| **剧情核心人物** | 玉米母亲 · 竹取 · 樹木子 | 牺牲 / 诞生 / 怨念三种来历 |

> **种田在 RPG 里的位置**：它不是主循环，是**主循环的输入端**——
> 你种什么决定你今晚遇到什么、你队伍里有谁、你手上有什么牌。
> 这样「种田」就不是一个并列的玩法，而是 RPG 的**资源与情报来源**，符合 owner 的定位。

## 8. 还缺什么 · 下一步

**够不够**：够。两大家族 + 六槽构词法 + 三条现成机制，足够撑起一个 RPG 的敌人体系与伙伴体系。
真正稀缺的不是原型，是**二三十个玩家记得住的、有名有姓的角色**——那要靠设计，不靠收集。

**要做的事**（策划阶段）：

1. **细读一轮《太平广记》草木部 + 精怪部**，把恶妖那一半做成条目表（现在这块最薄）。
2. **把 §1.2 的山海经条目逐条比对原文**（功效动词「食之/服之/佩之」三者语义不同，别混）。
3. **挑 20–30 个头目做角色卡**：名 · 来历 · 一句话性格 · 战斗招式 · 善恶转化条件。
4. **写蔬菜 × 六槽的生成表**，验证能不能长出足够多样的小兵。

**要 owner 拍板的**：

- §6.2 的「善恶由种法决定」是否采纳？它会显著改变种田的手感（从「效率」变成「态度」）。
- 主线讲什么？现在有三种来历母题可选：**牺牲**（玉米母亲）· **诞生**（竹取）· **怨念**（樹木子）。
