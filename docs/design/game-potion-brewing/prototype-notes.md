## 画布与布局

- 逻辑画布固定 **1440 × 900**；窗口采用单一比例 `min(viewportW/1440, viewportH/900)` 等比缩放并居中。`html/body/viewport/stage` 真透明、无桌面背景、无四角装饰与中心大仪式环，由 DokiWorld 宿主提供背景。F2 打开隐藏审阅侧栏时预留 360px 给控制区，控制区不遮挡目标界面。
- 安全区约为 `(36, 28)` 到 `(1404, 862)`。顶部标题位于 x=440–1090；配方卷轴位于 `(48,104)`，尺寸 `362 × 724`；材料架位于 `(1092,115)`，尺寸 `308 × 704`。
- 坩埚图片的显示盒中心为 `(760,500)`、外径约 `398px`，药液是约 `256×131px` 的独立椭圆层。投料命中区中心为 `(760,423)`、横/纵半径约 `123/53px`；搅拌棒尖始终处于同中心、半轴 `105/43px` 的固定椭圆轨道。其位置仅由一个角度确定，无自由 x/y 拖放。方向虚线提示也跟随锅口，不围着锅肚。
- 图层从后到前：宿主背景（不在本原型绘制）→ 左配方卷轴 / 右材料架 → 独立药液/气泡 → AI 生成的透明锅沿 → 无浅蓝圆宝石的搅拌棒 → 半透明水面覆层 → 前侧锅沿遮挡 → 状态提示/方向提示 → 拖拽影像 → 结果遮罩。棒身末端渐隐，水面压在末端上方，前侧锅沿再次遮住入水段，构成没入水中的错层。

## 状态与转换

```text
宿主指定唯一配方 ─有效输入→ bench-idle（直接进入）
bench-idle ─指向材料→ ingredient-hover/focus ─按下/移动→ ingredient-drag
ingredient-drag ─锅外放开→ ingredient-snapback → bench-idle
ingredient-drag/键盘确认坩埚 ─正确材料→ ingredient-correct → 下一步
ingredient-drag/键盘确认坩埚 ─错误材料或非 add 步提交→ ingredient-wrong → failure
bench-idle ─当前为 stir→ stir-ready（棒已在水中）─抓棒头或锅口内圈→ rod-held/stir-tracing
stir-ready ─短弧/抖动/未满圈→ stir-invalid → stir-ready
stir-ready ─正确有效圈→ stir-valid → 同步圈数或下一步
stir-ready ─明确反向有效圈或非 stir 步完整圈→ stir-wrong-direction → failure
最后一步正确提交 → success
bench-idle ─退出→ exit-confirm ─继续→ bench-idle
exit-confirm ─确认退出→ cancelled ─重新演示→ bench-idle
所有提交/终局演出 → disabled；演出后 success/failure 结果确认
```

上图覆盖当前所需的炼制与终局状态，旧 `recipe-select` 已废止。`cancelled` 是退出结果，绝不表达业务失败。结果与演出时立即锁定玩法输入；失败后玩法输入一直禁用，仅可操作结果出口。重置与 F2 宿主样例切换清除旧演出及异步回调（原型用递增 epoch 防旧链串到新局）。

## 输入与判定

- 鼠标和触控：从材料架拖动任一材料；指针落在锅口椭圆 `(760,423)`、半轴 `123/53px` 内才提交。锅身或锅外松开只触发回弹、不失败。单击材料只是选中；鼠标单击锅口内后才提交；键盘聚焦坩埚确认仍可提交。**选中材料只高亮材料卡，不给锅沿发光。**
- 键盘：`Tab` 可聚焦材料、坩埚和搅拌棒；材料上 `Enter` / `Space` 只选择并把焦点移到坩埚；再按 `Enter` / `Space` 提交。Q/E 旋转捷径已移除；方向按钮不显示。`Escape` 在炼制中打开退出确认，在退出确认中返回，终局后不重开。`F2` 只在原型中开关审阅侧栏。
- 圆周算法仅供本原型验证手感：棒从开局就在锅里，`rodAngle` 是棒位置唯一状态量，棒尖由 `(760+105cosθ, 423+43sinθ)` 每帧派生，绝不随指针自由偏离水面。抓住棒头、棒身或入水端均可拖；搅拌步骤还允许在锅口内圈按下接棒。指针相对锅心归一化后用 `atan2` 求角差，取 `[-π,π]` 的最短连续角差加到 `rodAngle`；从棒上抓取时不瞬移，锅口接棒时贴到按下角度。屏幕 y 向下，正累计为顺时针，负累计为逆时针。指针进入极近中心（归一化半径 `<0.16`）或单次异常跨越 `>129.6°` 时忽略该采样但不中断拖动；小于 `0.5°` 的细抖动不计数。累计绝对角度 `≥330°` 确认一有效圈并清零计数，反向运动自然抵消进度。松手不足一圈即忽略，棒停在当前位置，不跳回架上；下次拖动重新计算完整圈。
- 反方向只有达到 `330°` 才失败。短弧、抖动、指针偏离轨道、锅外材料释放或只点错材料都不失败。若当前不是 `stir` 却完成一圈，或不是 `add` 却提交材料，则是明确错误，立即失败。
- 达到配方指定圈数的瞬间先锁定步骤，再进入下一步；额外指针采样不会落到下一步。若一圈尚未达到目标，立即显示 `当前/目标` 圈数。材料 ID 与步骤数据比对；图形、数组位置和图片载入都不参与判定。

## 演出时序、色彩与反馈

| 事件 | 时长与先后 | 画面/文字 |
|---|---|---|
| 材料拾取 | 140ms ease-out | 材料卡抬起、阴影加深，跟手影像置顶 |
| 锅外回弹 | 280ms ease-out | 跟手影像回原位并淡出；本局继续 |
| 正确投入 | 药液局部闪亮、材料文字与步骤推进并行；步骤在约 280ms 推进，整体反馈约 600ms | 药液颜色与内部微光增强；锅沿、锅肚、锅脚不发光 |
| 有效搅拌圈 | 棒尖沿固定椭圆轨道实时转动；每圈约 160ms 确认，不阻断后续圈 | 方向箭头、有效圈数、药液旋涡加速与确认文字同步；多圈步骤每圈颜色都向下一阶段过渡，锅身不闪亮 |
| 咕噜气泡 | 清水近乎静止；首件材料后约 2.3s 周期，持续炼制时约 1.15s，手势中约 0.72s | 气泡由小变大、上浮并消散；搅拌时密度感增强 |
| 无效轨迹 | 松手即反馈，棒仍留在锅中当前位置 | 提示“还差一点就满一圈”，药液和步骤不变 |
| 成功 | 最后提交立即锁定；约 1250ms 演出后弹出结算 | 药液稳定增亮；结算页展示成品名和药剂瓶图片，无局内重开，向宿主交付 success |
| 失败 | 错误提交立即锁定；约 880ms 后弹出确认 | **只有药液**转浑浊紫色 `#615366`；锅身/锅沿不移动、不发光，结算只留一个小烟云，无局内重开，向宿主交付 failure |
| reduced-motion | 所有位移、旋转、闪烁与过渡时长压至近零 | 保留卷轴步骤更新、颜色、文字与结果；系统偏好和审阅开关均可触发 |

视觉仍是 **原型占位**：植物/果实/种荚/花瓣图形由 HTML 内联 SVG 绘制；卷轴、药液和气泡由 CSS 实现，背景不绘制且 alpha 透明。坩埚采用 AI 生成的 [`cauldron-three-quarter-v2.png`](ui-refs/cauldron-three-quarter-v2.png)：椭圆口中空、前侧锅肚和锅脚可见，药液在锅口后方独立着色。旧俯视图只留作历史比较，不再由原型消费。结算药剂瓶采用 AI 生成的 [`potion-bottle-v1.png`](ui-refs/potion-bottle-v1.png)，赤焰样例暂用 CSS 色相变化示意，不代表最终两种成品的正式图。两张图是本地原型参考，未登记 AssetIndex、未接生产游戏。原型保持静音；正式音效在 S5/S6 用引擎 `SfxSpec` / `SynthAudioPort` 再审，不从本文件拷贝声音实现。
