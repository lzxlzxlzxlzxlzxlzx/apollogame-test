# GAP-POTION-02 / G2 · 通用椭圆单角度手势

> 历史施工规格，**G2 已于 2026-10-13 按炼药项目范围交付并从公共池释放**；权威当前判词见 [G1–G4 独立复查](../review/G1-G4-scoped-release-2026-10-13.md)。以下保留原验收规格，正式游戏真手势另归 S4。

- 施工主体：Codex/root（Owner 特许本地领工锁）；输入与确定性共享面，只归主程。暂定能力名 `t2-angular-gesture`。
- 配置：椭圆中心和正半轴、初始角、握持命中容差、中心死区、单采样跳变上限、小抖动阈值、整圈阈值，均为有界数据。S1-P-06 验收基线：中心 `(760,423)`、半轴 `(105,43)`、330°、0.16、129.6°、0.5°；参数修改先与原型重对齐。
- 行为：tick 输入序列抓取/移动/释放，棒的位置状态只有角度，位置由角度投影；指针离轴仍沿轨道。角差跨 ±π 连续展开，屏幕 y 向下的正值为顺时针；中心死区、异常跳变与抖动忽略，反向运动抵消累计；松手不足一圈不提交也不失败。达到有效阈值发具名方向圈 Signal 后清本圈累计。G1 当前步骤达标时立即锁定，额外采样不得误落下一步。键盘 Q/E 由 `t2-keybind` 提交同一语义圈信号，不伪造轨迹。
- 确定性：不得以 DOM 事件时间、rAF、墙钟或自由 callback 作权威输入；输入坐标先逆投影与量化，归档/快照恢复同轨同方向同圈数。表现可插值但不反写 sim。
- 验收：真鼠标和触控抓棒/锅口接棒、跨 0°、反向抵消、短弧、死区、跳变、连续 2–3 圈、同拍锁定、键盘等价、快照/回放同轨、DebugTrace 拒收、独立锚点撤修验红。入水遮挡属后续 render 分层，不由手势能力画自由 Canvas。
