## 3. 这一轮真渲染抓到的（**只有看图才看得见的**）

> `docs/playbooks/self-check.md` 的立册理由就是这一段：机器门能证「值变了」，证不了「玩家看懂了吗」。

1. **两处读数被挤成 2–3 行**（`S4-play-1-start.png` 等）：`第 1 天` 竖排三行、`当前工具：锄地` 三行、`体力 20/20` 折行。这是 **D-9** 的视觉证据，也是**只有人眼能抓**的那类病——**四关门禁查不到"文字换行"**（记 D-16）；换皮后**更挤一档**（apolloToon 的字形与键体量和 `SHELL` 不同）。
2. **两套按钮并存 + 画布色块没有字**：`S3-render.png` 里画布上有 6 枚动作色块，与地块**近同色**、无文字标注 ⇒ 新玩家会把它们读成**土地**而不是按钮（D-13 的全新玩家视角理由）。DOM HUD 那 6 枚在下方纸色条上，是另一套。
3. **被拒操作屏上零反馈**（`S4-play-4-rejected.png`）：体力 2 时点锄地，唯一线索是 HUD 数字**没变**（2→2）。玩家会怀疑「是不是我没点到」。⇒ **新债 D-19**，归 S4（§2 #8）。
4. **终局标题的艺术字肉眼可见**（`S4-play-6-terminal.png`）：「通关！」的粗圆卡通字形与 `apolloToon` 默认 UI 字（`SHELL.fontUi` 的苹方/雅黑栈）**一眼可辨**——这是 `font:'cnround'` 真生效的**人眼证据**，与 §4 的 CDP 账本互为印证。
5. **底部纸色 HUD 条**：换皮后 HUD 从裸色变成纸底面板（`bg:'panel'`），`S3-render.png` 可见——这是 ②a 的修法在**画面上**的样子，也是「4 条硬红 ⇒ 0 条」的原因所在。

**★ 本轮最值钱的一条方法论（留档防回退）**：判断「艺术字是否真覆盖某个字」**不能用像素或宽度**——
(a) 汉字 advance 恒约 1em，宽度无判别力；
(b) 像素法会被**栈依赖回退**污染：只要字体栈里出现一个真字体族，Chrome 给汉字的**系统回退字体本身就会变**，于是未被覆盖的字也「看起来变了」（我实测两版都栽在这里：阴性对照 `龘` 的 diff 比被测字还大，且换成不存在的族名后**同一个字仍是同一个 diff**）。
唯一可靠仪器 = **CDP `CSS.getPlatformFontsForNode`**（浏览器自己的账本，答「这节点实际由哪个族画了几个字形」）。**且必须先强制布局 + 等两帧**，否则账本全空。探针两次都正确地**拒绝下结论**（exit 2）——守卫设计是有效的。

## 5. 好玩三问 + 节奏检查（主观但必须作答）

**1) 这局玩完，我想再来一把吗？为什么？**
想，但**不是**因为画面好看——是因为**一天循环闭合**：锄地→播种→浇水→收获→卖货→睡觉推进到第 2 天，每一步都在 HUD 上留下痕迹，玩家能看见自己的经营在累积。
**磨损它的是三条看得见的问题**：读数挤成竖排（D-9）让「我攒了多少」要费劲找；画布按钮像地块（D-13）让「我该点哪」要试；被拒时零反馈（D-19）让我怀疑手没点到。
⇒ 三条都不在「好玩」本身，而在**界面让人读懂自己干了什么**——这是 S4 的病，不是玩法不成立。

**2) 关键操作的反馈一眼看得见吗？**
**做的动作**：看得见。锄/播/浇/收都会让地块贴图当场变（δ 全轴那三轴投影），卖货/睡觉则 HUD 数值与「第 N 天」当场跳。**这一点是本作最扎实的部分。**
**被拒的动作**：**看不见**（D-19）。前置门不满足时体力 2→2、屏上无字——这是本轮唯一一处「我点了，世界没告诉我为什么没成」。

**3) 有没有让我困惑或等待的瞬间？在哪一步？**
- **困惑 ①**（`S4-play-4-rejected.png`）：体力 2 时点锄地，没反应也没提示 ⇒ 归 **D-19**（S4）。
- **困惑 ②**（`S3-render.png`）：屏上**两套按钮**，画布那 6 枚无字且与地块近同色 ⇒ 归 **D-13**（S4 真 HUD 一揽子）。
- **节奏检查（>1 秒「干等且无事可做」窗口）**：**未发现**。本作的一天由玩家动作「睡觉」推进（HUD 有「第 N 天」），作物生长不需要玩家挂机等；脚本化走查 174 步全部是「真按键 → 世界立即变化 → 断言」，没有一步是等待墙钟。
  **但如实记一条体感**：`S4-play-4-rejected.png` 那一步，玩家体感是「**没反应**」——它不是"等待"（没有进度条、没有倒计时），所以不属节奏窗口，而是**反馈缺失**（D-19）。这两件事不许混着记。
