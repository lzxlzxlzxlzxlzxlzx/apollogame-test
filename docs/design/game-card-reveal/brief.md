# `game-card-reveal`《星辉启封》立项简报

> 工作代号与中文名均可在 S1 结束前修改。本文只立项，不代表 S1 人门已签核。

## 一句话产品

DokiWorld 把已经抽出的卡牌及其卡面交给本 App；App 不参与抽取与概率判定，只播放一段可跳过、可恢复、具有 3D 卡包与逐卡揭示效果的抽卡演出，最后完整陈列本次结果。

## 产品定位

- 类型：短时、纯表现型、宿主驱动的抽卡结果展示 App。
- 宿主：DokiWorld。
- 规则归属：抽取概率、卡池、保底、库存、扣费、奖励发放均归宿主。
- App 归属：素材预载、演出编排、跳过、失焦恢复、逐卡展示、结果总览与完成回报。
- 首要质量目标：镜头、材质、灯光、倒影、运动曲线、声画同步与稀有度层级，而非增加玩法。

## 当前已确认的演出骨架

1. 开场闪光与能量聚合。
2. 多个卡包围成圆环旋转。
3. 聚焦其中一个卡包并推进至正面展示位。
4. 撕下封条并打开卡包。
5. 本次卡牌依次弹出、翻面并展示。
6. 最终列出本次全部卡牌。

## 不可变边界

1. App 不重新随机、不替宿主抽卡，也不改变卡牌顺序或稀有度。
2. 规则完成与表现完成分离；动画不能成为奖励是否发放的判定依据。
3. 跳过只跳过表现，不能丢牌、重复回报或改变结果。
4. 宿主卡面属于不可信外部表现输入，必须校验协议、协议版本、URL/资源来源、数量及降级行为。
5. 关闭、卸载、失焦或资源失败不得伪造一次成功演出完成。
6. 正式实现必须走引擎数据驱动能力；HTML/WebGL 原型只作 authoring-time 视觉与时序真相，不复制进运行时代码。

## 初步宿主边界（待 S1-P 总原型定稿后冻结）

宿主预计提供：

- 本次抽取的稳定运行标识；
- 有序卡牌数组；
- 每张卡的稳定业务 id；
- 卡面图片 URL 或宿主可解析资源引用；
- 稀有度闭集；
- 是否首次获得等纯表现标记。

App 预计回报：

- 演出已完成或被玩家跳过后的单次完成事件；
- 不回传概率、库存变化或奖励明细。

字段名、数量上限、URL 安全策略、输出 contract 与退出语义暂不在 S1 猜定，留待总原型定稿和最新版 DokiWorld SDK 实查后进入 S2。

## 阶段策略：逐段目击，不做黑箱大交付

本项目把 S1-P 原型拆为可独立回放的五段；每段先由 owner 真机目击、提出修改并明确冻结，才能开始下一段：

| 原型段 | 范围 | 主要裁决 |
|---|---|---|
| P1 | 单卡包正面展示、3D 转动、灯光、地面倒影 | 构图、镜头、卡包比例、旋转幅度、材质方向 |
| P2 | 多卡包圆环、旋转、停靠、聚焦 | 卡包数量、半径、速度、选中节奏、镜头推进 |
| P3 | 封条剥离、包体开启、裂缝发光 | 刚性飞带还是柔性卷曲、声音与动作同步 |
| P4 | 多张卡依次升起、翻面、稀有度演出 | 单卡停留、并行关系、普通/稀有层级 |
| P5 | 结果总览、跳过、完整串联 | 总时长、跳过落点、结果布局、完整体验 |

五段都冻结后才形成一份完整 `prototype.dc.html`，由 owner 给出 S1-P 定稿判词；此前不得进入 S2 capability plan 或正式玩法/UI/美术施工。

## 已知能力判断

- 现有 `Model3D`、`Pivot3D`、`Anim3D`、`Path3D`、`Camera3D`、`Reflector3D`、`Material3D`、`Light3D`、`Post3D`、`Vfx2D/Vfx3D` 足以承载主要演出。
- 真实柔性撕封依赖带骨骼或形变动画的 GLB 资产；刚性封条飞离可由现有能力直接表达。
- 普通 UI 卡面可消费宿主图片；跨域宿主图片作为 WebGL/PBR 纹理尚需在 S2 实查并决定是否补通用远程纹理桥。
- 当前不批准在游戏层自写 3D 关键帧解释器、远程纹理加载器或 DOM/CSS 演出系统。

## Owner 能力方向裁决

### CARD-REVEAL-MATERIAL-SLOTS（2026-10-09，已被后续方向替代）

owner 曾选择产品方案 B：补通用 `Model3D.materialSlots`。同日后续视觉裁决取消复杂软包装 GLB，改为透明舞台上的双面纸片卡包，因此本项目不再以该能力作为前置条件，也不得仅为本项目继续扩写 3D 模型材质槽。

新方向：卡包是高:宽约 `3:2` 的超薄双面表现件，正面图、背面图和封条图均为独立可替换图片槽；背景透明，不使用黑色场景、PBR 灯光或镜面倒影。若未来其他项目仍需要 `Model3D.materialSlots`，必须以新的跨游戏证据重新走缺口协议，不能沿用这条已被产品方向替代的裁决。

## 首版不包含

- 卡池、概率、保底、货币扣除、支付、库存写入；
- 角色养成或卡牌数值规则；
- 游戏内重新抽取；
- 多种完全不同的卡包结构；
- 由程序实时模拟纸张物理撕裂；
- 为追求效果绕过引擎建立游戏专属渲染器。
