# ScreenFx 彗星掠屏原型说明

> **历史原型，需求已取消（Owner，2026-10-12）**：本转场不再使用；下文的方案、待裁决项和能力映射均不构成现行待办。保留文件供设计溯源，不得直接接入主 App 或据此开发 `ScreenFxSequence`。若将来重启，须重新立项、原型定稿和能力裁决。

> 本文件只记录当时的 authoring-time 视觉探索。原型 Canvas 代码不得复制进生产游戏；原拟议的 `ScreenFxSequence` 路线已随需求取消，不再进入施工。

## 目标（R2：揭幕转场）

- 验证一个可跨游戏复用的彗星揭幕转场，而不是横穿屏幕的装饰性彗星，也不是只为《星辉启封》写的一次性动画。
- 明确演出语义：`黑屏/透明空白 → 彗星飞入 → 聚焦点爆炸 → 闪光遮挡切场 → 正常画面出现`。
- 默认输出真实透明背景；画面可叠放在 UI 或 play-field 上方。
- 视觉组成固定为五层：彗星头、发光飘带、尾随火星、冲击圆环、全屏闪光。
- 提供星辉金、秘能青、稀有紫三套颜色，用于验证“同一结构、只换预设参数”的产品方向。

## 画布与构图

- 逻辑画布：`1440×900`。
- 起点：画面左下外侧约 `(-190, 685)`。
- 终点/冲击点：画面中心偏上约 `(770, 390)`。
- 路径：三次贝塞尔曲线；彗星在冲击点消失，不再穿越并飞出屏幕。
- 正常画面使用三张卡牌的明确占位界面，只表达“转场后底层游戏画面已经出现”，不代表最终抽卡界面设计。
- 默认背景：alpha=0；棋盘格只用于审阅，不属于目标画面。

## 时间轴

总时长：`2.35s`。

| 时间 | 阶段 | 说明 |
|---|---|---|
| `0–0.26s` | 空白开场 | 黑幕或全透明空白，不显示正常画面 |
| `0.26–1.20s` | 彗星飞入 | 彗星头、双层飘带和火星并行移动，在冲击点停止 |
| `1.15–1.80s` | 命中爆发 | 径向碎光、双环和强闪同时遮挡画面切换 |
| `1.40–2.35s` | 揭幕 | 闪光衰减，正常游戏画面从底层显露并最终稳定 |

`prefers-reduced-motion` 下时间缩短至约 40%，但仍保留开始、冲击和结束三段可理解状态。

## 交互

- `重新播放`：从时间轴起点播放。
- `星辉金 / 秘能青 / 稀有紫`：切换闭集配色并立即重播。
- `开场：黑幕 / 开场：透明`：切换转场之前的覆盖方式；两者都在爆炸前隐藏正常画面。
- `透明底检查`：打开仅供审阅的棋盘格。
- `干净预览`：隐藏控制区和读数；按 `Esc` 返回。
- `Space`：任何状态下重新播放。
- 固定验收帧：追加 `?frame=1380&clean=1&palette=gold` 可无动画地渲染指定毫秒关键帧；`palette` 可取 `gold/cyan/violet`，`checker=1` 可显示透明棋盘格。该入口用于后续逐帧对齐，不属于最终玩家界面。

## 拟议生产能力映射

原型定稿后，首版 `ScreenFxSequence` 只申请以下闭集层类型：

1. `sprite`：彗星头或具名透明贴图；
2. `ribbon`：沿屏幕归一化路径生成的发光飘带；
3. `particles`：使用 texture key 的确定性粒子；
4. `ring`：冲击圆环；
5. `flash`：全屏或局部径向闪光。

游戏只提交 `specKey + trigger + nonce + layer`，不持有自由 Canvas、Shader 或逐帧逻辑。声音由同一演出 cue 触发独立 `SfxSpec`，不塞入 ScreenFx 数据中。

## 当前占位与正式美术

- 当前彗星头、飘带和粒子均由原型程序绘制，只用于确认运动和层次。
- 正式版本建议使用三张透明纹理：`comet-head`、`comet-ribbon-noise`、`spark`。
- 纹理可以由 AI 生成，但必须经资产管线登记为 texture key；AI 图片只负责形态和纹理，不负责动画时序。
