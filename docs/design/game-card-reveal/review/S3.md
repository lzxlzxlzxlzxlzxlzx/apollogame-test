## 独立复查结论（2026-10-10）

结论：**FAIL，退回修复；S4 仍锁定。**

- 独立复跑：游戏骨架 `4/4`、DokiWorld `19/19`、Doki scoped TypeScript 与游戏 ESLint 均通过。沙箱内 Node `realpath` 被系统 EPERM 拦截，改用获批的短生命周期只读进程复跑；未启动服务、未修改数据库。
- 撤修验红：内存态精确命中一次 `value.cards.length > 5`，取消 5 张上限后 `rejects invalid input 1` 准确转红；临时配置已删除，未污染正式源文件。
- 阻塞缺陷：`CompletionGate.complete()` 在调用宿主前把 `sent=true`，但宿主返回 `rejected` 或 Promise 超时/异常时不复位，导致保留的 P5 终态无法重试。`docs/integration.zh-CN.md` 又将错误行为写成“不再重复 complete”。这与 `docs/sdk/dokiworld-app/contracts-lifecycle.md §5/§6` 的“非 accepted 复位；rejected/timeout 保留终局并提示重试”直接冲突。
- 必修：把闸门改成 `idle / pending / accepted` 语义；pending 防并发重复，只有 accepted 永久锁定，rejected/异常回到可重试；增加 rejected、throw/timeout、pending 并发、accepted 后不重发测试；同步第 8 章故障表。修复后须重新提交 Review 单并停回复查。
