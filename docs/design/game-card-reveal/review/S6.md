## 原因、改动与定量结论

仅把 `queuedX` 恢复为 `1620+20i`；P4 终态标准首卡左界增至 1446.69687552942px，减少动态为 1490px。`p5-card-i` 原已引用同一个 `queuedX`，故 P5 从相同离屏姿态召回，不换实体。未动 P4/P5 时长、卡序、alpha、Visibility、销毁、引擎或渲染器。Doki 走查测试中固定 `1560` 的旧期望相应改为 `1620`，保留其顺序和终态断言。

新增 `games/game-card-reveal/s4-flow.test.ts` 六组点名回归：standard/reduced × N=1/3/5。逐张等待 `p4-fly-i.done`，读取世界中 Sprite `width/height` 与 Transform `scaleX/scaleY/rotation`，按旋转 AABB 计算 `left=x−(|cosθ|·w+|sinθ|·h)/2` 并断言 ≥1440；同时断言 visible=true、alpha=1，防隐藏式伪修。P5 开始时每张 Transform 与保存的 P4 完成姿态完全相等，实体 id 集合不变，最终回到 `finalLayout`。
