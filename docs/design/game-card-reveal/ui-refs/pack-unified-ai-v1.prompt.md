## Prompt 摘要

生成一张透明背景的双联包装资产页：左侧为同一卡包正面，右侧为背面；两面尺寸、外轮廓、封边与顶部密封口完全对应。整体使用深靛蓝、青绿与暖金的星月纹样，正面为抽象星/彗星徽记，背面为克制的配套几何纹样。要求正视、无透视、无重叠、无人物、无文字、无数字、无商标、无水印。顶部约一成高度表现自然薄箔热封帽与近水平浅弧密封线，禁止锯齿和已经撕开的状态；主图必须位于未来撕口下方。

## 使用约束

- 这是一套包装的正反两面，不是 A/B 两种皮肤。
- 程序消费时必须分别测量 front/back source rect，禁止把双联图整体压缩成一张包。
- P3 撕裂线须对齐纹理顶部密封口下沿，并继续使用互补的完整顶片/余包裁切。
- 原图保留在本目录；后续正式资产化需在 S5 按资产索引流程另行导入，本文件不等于生产资产台账。
