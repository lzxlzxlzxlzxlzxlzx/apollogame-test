## 拼接验证

`gal-ui-components-v1.dc.html` 是 1440×900 的 authoring-time 原型（不是正式游戏 DOM）：

- 设置页：面板框皮 + 真中文标签 + 可拖滑杆/数值 + 可切换开关 + 按钮；改值只影响原型内存。
- 存读档页：同一槽位皮重复 6 次/页、24 个演示槽、四页；缩略图和存档元数据独立覆盖。空槽在读取模式不可操作，选择、保存、再读取可走通演示链。
- 按钮的默认、悬停、按下与禁用状态由原型交互层提供，不作为静态图片烘焙。正式游戏仍必须使用 LayoutNode 闭集，不能复制 `.dc.html` 的自由 DOM/CSS/JS。

只读验收：短生命周期独立无头 Edge 打开本地 `file:` 原型，不启动服务；原型页面无脚本异常，存档位 2 演示保存后可在读取模式识别。最终六槽布局测得最后一槽底边 717px、底部操作区顶边 732px，无相交；浏览器已关闭。整套仍待 owner 真机目击与明确 S1-P 定稿。
