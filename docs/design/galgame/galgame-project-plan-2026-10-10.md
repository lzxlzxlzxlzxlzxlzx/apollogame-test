# GAL 引擎与 AI 创作产线：项目计划（2026-10-10）

> 项目现已注册；控制台单一真相是 `docs/projects/galgame-generation-engine/project-roadmap.json`。`project-roadmap-proposal.json` 仅为初次登记时的历史候选，**不要再次整份导入覆盖控制台现态**。本计划不替代每部游戏的 S1–S8、人门、需求池和 Git 记录。2026-10-11 增量：Owner 已批量选择 C2b、C5a、C5b、P1 均为 A（通用能力），详见 `requests.md` 四张独立票；控制台仍是旧 `planned` 实档，须由 Owner 按本机操作禁令同步，不由 agent 写持久化状态。

## 一、目标与架构判断

**接受一个项目、两条产品线。** GAL 引擎负责解释版本化纯数据包、确定性剧情、呈现、UI、存档与发行；AI 创作产线负责 Brief→角色/路线/剧情→素材候选→审核→组装。二者只通过 `GalPackage`、审核后的 `assetKey`、校验报告和验收记录连接。写作模型、图片模型和每部作品都不能生成或维护专属运行框架。

**回驳三种捷径：**（1）把定稿 `.dc.html` 的自由 DOM/CSS/JS 搬进运行时；（2）把“人工审核的静态包可玩”说成“AI 自动创作已完成”；（3）在未入库正式素材时用演示 CG 或整页截图掩盖缺口。现有代码已证明第一条运行时纵切可行，尚未证明完整模板、完整产线或桌面发行。

| G3 媒体与视觉 S5/S6 | 资产专职导入背景、表情立绘、CG、框皮并登记索引；引擎/表现侧接 BGM、语音、视频与闭集转场 | 非演示资产有 key、来源/许可/尺寸元数据；字体、颜色、纹样、遮挡和原型时序逐帧对齐，UI 审计与视觉评分过关 |

| P3 资产候选与装配 | 先本地库检索，AI 生图/视频/语音只作待审候选；资产专职审核入库。批准草稿+assetKey 由纯装配器生成包 | 未审核资源不能取得可发行 key；同输入装配字节稳定；schema、路线、locale、资源闭包全验 |

| R1 发行 | 发行专职验证 Web 自包含和 Electron/桌面安装包，不把平台差异写入剧本 | 离线启动、退出、存档路径、素材闭包、平台回归与可恢复失败处理有真机证据 |

## 五、风险与对其他 ZeroCraft 游戏的隔离

- GAL 源码与工单优先局限 `src/services/gal-*`、`src/skills/tier3/narrative-director*`、`docs/design/galgame/**`；`src/ui/**`、`games/game-i/**` 由 PUI 专职，`assets/**` 由资产专职，launcher/打包由发行专职。跨游戏共享修改必须先验 registry、playbook、现有消费者，再独立回归。
- 不把全库非 GAL 红灯归咎 GAL，也不越域清理他人工作树。局部门禁可作进度证据，但项目发行门要求全库 `tsc+vitest+build` 真绿。
- 控制台是**项目治理层**，GAL 首作仍须自己的 S1–S8 生产板和 Owner 原型人门；路线图里的 `review` 不能自动变 `done`。
- 每张里程碑的 `evidence` 引仓内真实文件，不放聊天断言。Owner 未审批的设计变更先改 `.dc.html` 并重新定稿，不做程序侧漂移追认。

## 六、控制台状态口径

控制台实档中 `ui-core-slice` 已由 Owner 批准为 `done/approved`；四项无需 Owner 的技术 Review（含 `profile-save-bridge`）已在 Owner 亲自合法保存后自动收束为 `done`。03C 仍为 `planned`，与独立 Review 不同步；`ui-settings-confirmations` 仍写 C1 待判，亦与 2026-10-10 Owner A 判词、05A 与 GAL-UI-04A 局部 Review 不同步。`replay-save-preview-auto` 与 `draft-review-contract` 仍是 `planned`，2026-10-11 新 A 判词只授权开工路线，不等于通过验收。此处只记录事实，不直接编辑控制台持久化文件。Owner 人门只能由 Owner 在专用接口批准/退回；Agent 不代签 `approved`，也不跳过 review。05A 的 Profile V2、PUI `Toggle.disabled` 和 GAL-UI-04A 四页部分结构均已局部独立复查 PASS，但不能把它们外推为完整设置页或项目级里程碑完成。
