# GAL 创作台计划

2026-10-16。依据可点击原型 `gal-authoring-flow.dc.html`，以及已定的模型调用方式：材料按目录存放，模型自己调用工具读取，只提交当前步候选。

《庄园出逃》的文稿、逐句和生图交给另一名 agent，沿用已有草稿和 `drafts/manor-escape/art-brief.md`。本计划只建通用创作台，不生成那部作品的正文或图片。

## 不在本计划里

- 不把 `.dc.html` 抄进游戏运行时，也不改冻结的 V2 玩法原型。
- 不实现把整包塞进上下文的 `WritingEnginePort`，也不再等待一个外部写作项目接口。`docs/design/galgame-creation-pipeline.md` 第 5、7、10 节里的该草图停止作为施工依据。
- 不把 P0–P4 已通过的草稿合同当成整条产线完成。
- 不代签项目控制台 Owner 人门，不把组装就绪标成可玩。

## 界面

创作台是工作室里的三栏，不是 1440×900 的玩法界面。

- 左栏是步骤。点哪一步，中栏只显示那一步的产物。
- 右栏两页：素材库，以及和这一步对话。
- 顶栏配置这一部作品使用的写作模型和生图模型，并提供「退回这一步」「通过这一步」。
- 锁定的步骤不能通过、退回或手改。
- 通过后，下一步如果还是锁定，就变成待通过。
- 手改或对话改掉一个已通过步骤时，该步回到待通过，它后面已经通过的步骤变成待重挂。
- 素材库跨步骤保留。上传的小说从简报重新走，不直接落在文稿步。

## 步骤

| 顺序 | 步骤 | 产物 | 已有合同 |
| --- | --- | --- | --- |
| 1 | 简报 | 受众、时长、路线数、红线 | `brief` |
| 2 | 角色 | 引用或新建，外型参考挂在角色上 | 角色仓库；还不是草稿种类 |
| 3 | 圣经 | 世界观、关系、外形文字摘要 | `bible`；地点不在这里定死 |
| 4 | 大纲 | 分歧、结局、地点列表 | `routes` |
| 5 | 剧情图 | 章节和选项 | `graph` |
| 6 | 节拍 | 背景、配乐、CG 需求 | `beats` |
| 7 | 对话文稿 | 把小说改成对白和旁白 | 尚无账本种类 |
| 8 | 逐句 | 说话人、表情、场景、CG | 尚无账本种类；通过后以逐句数据为准 |
| 9 | 生图 | 按角色参考出图，或按格式回传 | 候选目录，不是正式资源 |
| 10 | 资源确认 | 看过才给资源编号 | 立绘回写角色仓库；背景和 CG 留在作品 |
| 11 | 组装试玩 | 可运行包 | 批准的逐句加已确认资源；当前仍未就绪 |

## 角色

角色步决定造型。参考图在这一步上传，挂到该角色的仓库档案。文稿、逐句和生图只读这张图，不在后面重传。

名字和 `characters/<id>` 打开工作室已有的百科页 `?character=<id>`。已有档案内容不同或目录里有未登记文件时不覆盖。关系只写在起点角色上。没有参考图的角色用文字造型，并在通过这一步前写明。

## 模型

模型只产出当前步候选。通过和退回仍是人点的按钮。

模型不接收整包上下文。宿主提供目录和下面这组闭集工具：

- `read_step`：读某一步的当前产物。后步可读，同一次调用不可写。
- `read_material`：读素材库里的一份材料。
- `read_character`：读本作品关联的角色仓库档案。
- `read_spec`：读这一步的规格。
- `read_rules`：读创作规则。
- `submit_candidate`：只提交当前步候选。

宿主检查这一步要求读过的材料。缺读就拒绝候选。模型不能自己批准，不能改角色仓库文件，不能改用户上传的材料。对话历史只追加。已有审核规则不变：新批准版替换同种类的当前批准版，下游必须挂在当前上游上，否则待重挂。

## 生图回传

外部工具按该作品的生图说明交文件。解析器核对文件名、张数、尺寸和透明通道。对上了仍要人看过画面，才写入正式资源索引。

确认过的立绘登记回角色或对应时装，不覆盖已有海报和 Q 版。背景和 CG 留在这部作品。未确认的文件只留在候选目录，不放进 `characters/`，否则角色页会拒绝打开。

## 控制台里的创作产线

这些里程碑都挂在 `galgame-generation-engine` 的「创作产线」轨道，状态是计划，Owner 人门仍要本人签。

| 里程碑 | 证明什么 |
| --- | --- |
| `authoring-studio-shell` | 三栏能查看、手改、通过、退回，并让下游待重挂 |
| `authoring-material-library` | 素材跨步保留，小说从简报起步 |
| `authoring-character-step` | 角色步挂参考图并链到百科页，冲突不覆盖 |
| `script-draft-contract` | 文稿和逐句成为可审核草稿，模型不能自批 |
| `writing-engine-adapter` | 工具目录和当前步提交，不再做整包适配器 |
| `asset-generation-review` | 回传解析、人审、立绘回写、背景和 CG 留在作品 |
| `approved-package-assembler` | 只组装已批准逐句和已确认资源 |
| `generated-gal-pilot` | 用这套台子走完两部不同的作品 |
