## 确认窗口独立开关（owner 追加意见）

设置 →「确认窗口」分为两组，六项分别默认为开启：保存到空位、覆盖已有存档、读取存档、开始新游戏、返回标题、退出游戏。每项关闭后只跳过对应确认弹窗，操作本身仍照常执行；例如关闭普通保存不会关闭覆盖确认。重新开始仅在已有本次剧情进度时询问；退出在浏览器原型中只展示反馈，桌面版才由宿主真正退出。恢复默认会把六项重新打开。

原型内的六项只保留在当前页面内存。正式实现应把它们作为玩家偏好数据，不在每个按钮的 handler 里各写一套判断；接线前须实查现有设置、动作与存档能力能否表达，若有真实缺口再按 owner A/B 协议裁决。是否持久化及存储位置同样须按存档/平台手册核对。

关键演示链：**主页开始 → 对话三次推进 → 选项 → 分支台词 → 滚轮↑回到选项并重选 → 保存到第 2 槽并确认 → 切到读取并识别该槽 → 回想/CG 查看解锁态 → 设置调整控件 → 返回**。`dialogue`、`choiceList`、`portrait` 是正式实现的闭集控件候选；存档、画廊与设置以 `Panel`/`Button`/`Image` 等闭集组合为目标，不复制本稿 DOM/CSS/JS。

## 状态与时序

- 台词入场 240ms；选择钮入场 250ms，第二项再延迟 90ms；按钮悬停/按下约 160ms；提示浮层保留 2200ms；自动推进间隔 2700ms。当前演示不含逐字打字、转场动画和真实音频，相关设置控件只体现 UI 状态，不应据此判定功能已完成。
- 画面演示状态在内存中：存档 24 槽、当前分支路径、历史记录、已读和 CG/回想解锁。刷新页面重置，不使用 localStorage/数据库。
- 回滚按已访问台词路径退一节点；跨越选项则恢复选项并允许新选；新选覆盖该存档路径的未来节点。全局已读和图鉴解锁不回滚。
- 逻辑画布固定 1440×900，浏览器仅等比缩放，不改变原型锚点。正式桌面窗口的尺寸/全屏与持久化由程序宿主实现。
