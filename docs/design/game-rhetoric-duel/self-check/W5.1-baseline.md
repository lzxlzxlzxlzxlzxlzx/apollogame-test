## 阶段与截断复现

| 阶段 | 阶段预算 | 旧动画 | 截断点 |
|---|---:|---:|---|
| `deal-opening-hand` | 42 帧 ≈ 700ms | `420ms + handIndex×90ms` | 第 5 张总长 780ms，阶段约 700ms 即切走，尾段缺 80ms。 |
| `deal-new-cards` | 42 帧 ≈ 700ms | 同上，且 delay 按整手 index | 补牌若落在高 index 会重现截断；已有牌也由临时 index 计算身份。 |
| `card-lift` | 8 帧 ≈ 133ms | Canvas tween 18 帧 ≈ 300ms | tween 未过半即切换。 |
| `card-flight` | 11 帧 ≈ 183ms | 新挂 Canvas tween 18 帧 ≈ 300ms | 第二段从固定 `x=590` 重新挂载，再次被截断。 |

## 重复视觉与状态证据

- `play-slot-{1,3,5}-initial.png`：点击后先进入 `card-lift`。
- `play-slot-{1,3,5}-flight.png`：下一阶段 Canvas 继续画完整飞牌，同时 LayoutNode 另挂 `rhetoric-flight-icon`，形成双所有权。
- `deal-opening-{000,150,300,450,690}ms.png`：五条 CSS 动画均按整手 index 延迟，690ms 时第五张仍未完成。
- `deal-refill-{000,690}ms.png`：补牌仍沿用整手 index，而不是本次新牌 ordinal。
- `disabled-busy.png`：busy 期间牌面通过额外正文行显示禁用原因，继续挤压卡高。
- `reduced-motion.png`：能跳到确定性终态，但仍经过旧 `card-lift` 阶段命名。
- 当前目录没有“压力不足才能出牌”的规则；本轮不新增此规则。禁用态覆盖既有的 busy、交锋结束与专注不足三种表现。

## 基线结论

1. 截断来自表现阶段预算与动画时长不一致，不是 simulation 问题。
2. 跳点来自第二段固定坐标重挂，不是资产问题。
3. Canvas 飞牌和 LayoutNode 图标并存，必须收敛为单一 LayoutNode 完整卡所有权。
4. 修复只需调整 presentation cursor、纯几何/时序函数和 LayoutNode 投影；snapshot/hash、卡牌数值、敌人逻辑与 SDK 均应逐字保持。
