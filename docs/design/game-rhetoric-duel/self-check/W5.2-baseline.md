## 时间失败

- 开局五牌：450ms 单牌 + 4×60ms stagger = 690ms。
- 出牌飞行：300ms。
- 没有独立的抬起/确认阶段。
- 旧 deal phase 约 716.7ms、flight phase 约316.7ms，只满足“技术上不截断”，不满足真人识读节奏。

## 基线帧

- `deal-first.png`、`deal-middle.png`、`deal-last.png`：旧 690ms 发牌序列。
- `play-flight.png`、`impact.png`：旧实现没有独立 lift 阶段，证据只包含飞行与结果。
