### 撤修验红 4：移除共享 focus-visible 规则

- 锚点：`src/ui/components/server.ts` 中 `[data-apollo-btn]:not([disabled]):focus-visible{outline:3px solid var(--apollo-focus-ring);outline-offset:-3px}` 唯一命中 `1` 次。
- 撤修：只临时删除上述一行；保留基础 `outline:none`、hover、active、主题令牌和所有 Button 渲染逻辑。
- 静态焦点测试退出 `1`：21 项中准确 1 项失败，命中“共享交互样式只给非禁用 Button 的键盘 focus-visible 显示焦点环”，报告缺少指定 selector。
- 真浏览器 probe 退出 `1`：按钮仍是 `activeId=rhetoric-end-turn` 且 `focusVisible=true`，但计算样式变为 `outlineStyle=none`、`outlineOffset=0px`，准确命中 `primary button focus-visible threshold failed`。
- 恢复：逐字恢复唯一规则；定向测试 21/21、probe 均退出 `0`；随后全部 UI 组件、游戏、TypeScript、UI audit、align-count 再次全部退出 `0`。

### 边界复核

- selector 明确排除 `[disabled]`；禁用按钮不会显示可操作焦点环。
- 仅使用 `:focus-visible`，不存在 `[data-apollo-btn]:focus{outline:...}` 普通指针 focus 规则。
- 环色由 Button 渲染端消费现有主题 `text` 为 `--apollo-focus-ring`；普通键与 hero 键同口径，没有写死游戏颜色。
- LayoutNode 的 Button 契约没有新增自由 CSS、className、selector 或任意样式入口；游戏仍只声明闭集 Button 数据。
- 修复只在共享 Button render-only 表现面；没有改 Signal、动作映射、模拟规则、SDK、随机或 snapshot/hash。
- 最终源码核对：focus-visible 规则唯一命中 `1` 次；普通 `:focus` 规则命中 `0` 次；最终 `probe.json` 与截图均来自恢复态。
