## 一、市场判断（要点）

- **收集+养成是常青回报型品类**：猫收集垂类十年不衰（Neko Atsume 2014 至今出到 2 代；Cats & Soup 2025 Q2 美区峰值月流水 ~$70K·MAU ~52.5万——中体量但极耐久·来源 Sensor Tower Q2'25）。
- **「牌戏×收集」在业界最高层刚被验证**：Pokémon TCG Pocket（2024 末上线）以**收集优先、对战其次**的结构冲到行业顶部收入档——收集是价值层、玩法是留存骨架，这个结构与《世界猫牌馆》同构（截至我知识时点 2026-01 的判断·数量级不引伪精确数）。
- 对比备选：幸存者/动作类靠手感与性能（我们最薄面）；SLG 靠海量内容+长线运营（最重路径）；叙事靠文笔上限（可打但市场窄）。**收集+养成的「高水准」主要由美术一致性 × 收集深度 × 投放节奏构成——三者恰好都是数据与文生图可承载的**。

## 三、系列量产架构（回答 owner「可以做一个系列量产嘛」——可以，配方如下）

系列 = **固定收集养成壳 × 可替换玩法骨架 × 可替换收集主题**，量产单元是一张「系列配方」纯数据：

```
配方 = { 玩法骨架: 牌戏N选M(判型引擎重组),  收集主题: 猫/犬/妖怪/世界小吃…(文生图批产),
        风格包: style-pack id,  养成曲线+投放表: 数据表 }
```

1. **收集养成壳下沉为引擎共享层**（系列的发动机·做一次全系列吃）：图鉴/稀有度/获取投放/养成进度/集套成就——全部数据表语义。是否有真缺口按缺口裁决协议实查（先对 registry：resource/flag/craft-recipe/card-pile/collection 面·game-a 衣橱先例部分重组可用）；**真缺口届时摆 A/B 给 owner**。
2. **玩法骨架=现有能力重组**：首作的「世界传统牌戏」每一种都是判型引擎+牌桌 UI 的数据重组——这是首作选牌戏合集的根本理由（骨架零新引擎）。
3. **主题批产走既有美术线**：一个新主题 = 一个风格包 + 一套文生图台账（S6 账单制）——猫→犬→妖怪的边际成本主要是 prompt 与审图。
4. **量产的质量下限由生产线八阶段守住**（S3 点击门修复中·S4 验收剧本·S5 视觉复刻·S7 评分卡），上限靠首作打样：**首作把「业界高水准」的标尺定下来（评分卡 premium 线），系列按标尺复制**。

## 四、到「业界高水准」的差距清单（诚实面）

① 美术一致性：文生图批产的猫卡要过「同一画师感」关——风格包锚定+审图门是现有手段，够不够到业界线要首批实测；② juice/演出：收集开卡/升星的仪式感（Particles/tween/sheen 件在库·组装水平待打样）；③ 长线投放节奏：养成数值与投放表设计是 GD 硬活，sim 校准线（balance-sim 先例）可承接；④ **移动端**：收集养成主战场在手机——MOBILE-SHELL（WebView 壳）暂停中，转型确认即建议复活；⑤ 留存/存档云同步：local-store/SavePort 在库，云侧仅 Steam。

## 七、差异性（对标 Neko Atsume / Cats & Soup / TCG Pocket·owner 2026-08-26 问）

标杆猫游戏全是**放置观赏型**：猫是来了就摆着的收藏品，零交互零玩法，护城河=治愈美术。我们的结构性差异：

1. **猫是牌搭子，不是摆件**——收集到的每只猫是**能陪你打牌的角色**：性格=AI 行为树数据（game108「心情=AI·换心情改一个字段」先例），牌风各异（紧凶的暹罗/爱诈唬的橘猫/算牌的银渐层）。标杆的猫你只能看，我们的猫你能跟它玩、被它赢、教它变强。
2. **收集的不只是猫，是世界牌戏图鉴**——每只猫绑一种世界传统牌戏（花札猫/波斯 As-Nas 猫/埃及 Basra 猫…），集一只猫=解锁一种玩法+一段牌戏文化。市面没有「牌戏图鉴」型产品；这同时就是 S1 立项卡原设的搜索流量骨架（每个传统牌戏一个入口）。
3. **养成=养棋力不只养亲密度**——猫会变强：解锁新招式/口头禅/读牌习惯（全是 BT 权重与台词表数据）。标杆的养成是喂食升级换皮，我们的养成有博弈反馈。
4. **AI 时代的内容供给速度**——猫立绘+性格+台词+牌风四件套=文生图+数据表批产，赛季/地区扩展边际成本远低于 2014-2021 形态的标杆（它们靠美术手作·更新以年计）。对 TCG Pocket 一侧：不打 IP 收集牌（打不过），打「文化猎奇×猫普适」。

**差异性的风险与对冲**：牌戏对纯休闲收集用户是门槛（Neko Atsume 用户要零压力）——对冲=保留放置观赏层：不想打的**看猫打**（AI 对 AI·确定性引擎天然支持挂机演算），想打的亲自下场。两层用户都接住，标杆的基本盘不丢，差异层往上叠。

## 八、美术 gap（owner 2026-08-26 提·本定位最大单一风险·诚实拆解）

**gap 具体在四个面**：① 一致性——100+ 张猫卡要「同一画师感」，文生图批产的天然弱项；② 记忆点——AI 味/千猫一面，
标杆的猫每只是设计过的角色；③ 动态——标杆的猫会动（Cats & Soup 全程动画），S1 卡定的是静态卡零动画；
④ 上限——文生图天花板 vs 顶级商业插画。已有资产（style-packs 风格锚/art-review 人审门/S7 评分卡）守得住**下限与流程**，守不住**上限**。

**对冲策略（按启动顺序）**：
- **A 风格带躲开写实上限（先做）**：选文生图最稳的风格带——扁平贴纸/剪纸/版画风。Neko Atsume 本身就是极简风封神：
  收集品的高水准=风格统一+讨喜+辨识度，不等于精致写实。并把「世界牌戏的地域风格化」变成 feature：
  花札猫浮世绘风、埃及猫壁画风、波斯猫细密画风——**风格多样性是图鉴的卖点，同时降低单一风格内的一致性压力**
  （每地域一小批，批内一致比全库一致容易一个量级）。
- **D 立刻打样对表（与 A 同批）**：首批 20 张猫卡按 A 跑一轮 → S7 评分卡 + owner 亲眼对标杆——gap 多大用眼睛量，
  不空对空担心。打样成本=一套风格包+一轮台账，失败重打的代价极小。
- **C 程序化动态层（并行·全现成件）**：不做逐帧手 K——表情差分 4 态（game-c 头像 4 态产线口径现成）+
  程序化微动效（呼吸/眨眼/尾摆=tween/Particles/sheen 数据驱动）+ 猫打牌时的牌桌反应（出牌得意/输牌炸毛=差分切换）。
  静态卡+差分+微动效能逼近「活」，成本是标杆动画的零头。
- **B 头部资产人工介入（打样不达标再上）**：主视觉+头部 20 只招牌猫外包精修、长尾批产——二八开花小钱补上限。

**判据**：D 打样后 owner 对表说了算；A/C 不达标才升 B。美术 gap 由「担心」变成「一次打样的实测数」。
