# game-105《心动叠叠塔》v3 Standalone Release M1 GDD

> GD-105 · 2026-09-02 · 独立可玩版以 `standalone-release-freeze.md` 为最高优先级。Host Integration 是保留接缝的 M2，不是本版验收条件。

## 1. 产品目标

玩家与本地 AI 轮流玩一局真物理叠叠塔。抽塔和互动卡带来可见的共同事件；AI 对自己抽到的卡与倒塔惩罚卡会用本地模板回应。本版不依赖 Storyteller、网络或模型凭据，不回传外部结果，也不写任何长期记忆。

一局约 5--15 分钟。默认对手始终是 AI 角色，不支持热座双人作为默认模式。

## 2. 物理与信息边界

54 块积木为 18 层 x 3 块，相邻层旋转 90 度。固定种子布局的长/宽/高公差分别为 +/-0.7%、+/-1.5%、+/-1%；视觉尺寸和 Cannon 碰撞盒必须共用数据。

- 左键以积木长轴拖拽，松手释放 `Joint3D`；右键只旋转 `Camera3D.yaw/pitch`。
- 实际世界位置沿长轴离开原位 `BLOCK_LENGTH * 0.92` 才是完整离塔；抽出后拉回并松手前仍可回归塔体。
- 同回合第三块仍属塔体的积木出现超过 45 度失稳证据时，立即倒塔锁定；不等待全塔睡眠。
- 未倒塔时，连续 30 帧剩余塔体睡眠才结算回合；900 帧仍不稳定亦判持续性倒塌。
- 倒塔后禁止新操作，但 Cannon 必须继续自然步进。不得显示成功率、安全度、风险预测或 AI 风险评分。

完整离塔积木按“主动块优先、离塔时间、稳定 ID”排序结算。主动块为主卡，随后最多两块为余波卡；其余为逐项结算的 `余波 xN` 事实。离塔或真实散落的积木进入 `retired`，本局不可再选，睡眠后展示到战利品区。

## 3. 玩家、AI 与状态机

玩家和 AI 共用同一物理世界、抽离阈值、倒塌判定、可选积木判断和 `TowerActionExecutor`。AI 必须可见地环视、悬停、建立 `Joint3D`、渐进拖拽和释放；不得直写刚体、瞬移或拥有稳定特权。

```
boot -> player-ready -> player-pulling -> resolving -> player-interaction
     -> ai-observe -> ai-pulling -> resolving -> ai-response -> player-ready
     -> collapse-locked -> result-pending -> completed
```

AI 的选块只消费受限 `LocalAIObservation`：布局、已结算历史、离塔/退役事实、回合和已消费信号。不得读取 Transform、Cannon、速度、接触面或风险分。`careful`、`natural`、`thrill` 只改变确定性策略参数，均承担相同物理后果。

## 4. 互动与 AI 回复

玩家卡提供 1--140 字输入、快捷短句、提交、一次同频道未见换卡和跳过。输入仅留在当前运行会话；不传模型、不回传结果。完成主卡/余波卡按频道暂定值 `1/2/3/5` 增加本局 `heartDelta`，跳过为 0。

AI 成功离塔后，每张主卡/余波卡严格按以下流程处理：

```
真实物理事实 -> 固定卡牌/心动值结算 -> 显示“TA 抽到的卡”
-> 一次 dialogue 请求或模板降级 -> 显示一条回复 -> 下一张或玩家回合
```

AI 倒塔时，固定种子按 `seed + round + aiDraws` 从安全收尾卡池选一张：真心收尾、勇气承认、温柔约定、反向鼓励。它进入同一回复流程，完成不额外改变胜负或心动值；玩家只负责确认收尾。玩家倒塔仍可输入或跳过自己的收尾卡，且其原话不进入模型或结果。

本版每张 AI 卡只显示确定性本地模板，仍保证每卡一次、顺序可见、不会跳过。M2 如接入模型，必须保持“每卡最多一次、失败仅一次模板、本地规则先结算，模型不能修改积木、卡牌、心动值、回合、胜负或结果”的边界。

## 5. Storyteller 契约

独立可玩版不调用 Storyteller/Host。游戏不读取密钥、不选模型、不调用 `apps.launch()`，也不要求任何外部上下文。若 M2 恢复 Host Integration，Storyteller/Host 将是唯一能调用 `apps.launch()`、配置模型/密钥、提供角色与 Persona 上下文、提供 `dialogue.generateDialogue()`、消费完成结果的一方。

游戏使用 `@dokiworld/app-sdk@^3.0.0`，线协议暂锁定为 `protocolVersion: 2`，接收可选 `sessionId`、种子、角色显示名、Persona 显示名和关系快照。缺失字段使用本地默认值，不能阻止开局。

本版结算仅在游戏内展示赢家、回合、互动数与本局心动值。M2 可用 `doki.game.result/1` 回传最多 12 个白名单原子指标；不传玩家原话、聊天历史、原始物理轨迹或密钥，`memoryCandidate` 也只能是候选。

## 6. 本版完成与非目标

S4 完成的必要条件：玩家与 AI 能轮流真物理抽塔；AI 主卡、余波和 AI 惩罚卡都可见且恰好显示一次模板回复；无 Host、无网络和无模型凭据时整局可玩。

不在本版：游戏直接写长期记忆/关系、完整成人向或强制性惩罚卡池、AI 以 LLM 控制物理、风险预测、联机与热座双人。
