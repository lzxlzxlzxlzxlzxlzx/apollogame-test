## 玩家视角复核八问

1. 核心信息是“轮到谁抽、塔是否已稳定”。左上状态牌和底部提示同时表明玩家回合，AI 回合会显示 `TA 正在找一根/抽取`；权重足够，不需要玩家读内部数值。
2. 操作确认可见。抓取时提示会改为“塔还在回应你”，成功抽离进入互动卡，半抽则回到可操作状态；提交、跳过、换卡均立即刷新卡面或回合。
3. 倒塌时收尾卡明确写出当前失败方，并保留轮次、双方抽取、互动和连带事实；不是要求玩家从心动值差值推断。
4. 数值差异有层级。卡片频道和分值进入标题/账本，余波序号和溢出摘要与主卡区分；本版没有用预测风险条冒充反馈。
5. 当前阶段、回合和稳定性均在状态牌和行动提示中呈现；AI 逐卡时只显示当前卡与“下一张/轮到你了”，不会把已过期卡混在屏上。
6. 首次玩家可从“右键绕塔、左键沿积木长轴抽取、Esc 取消”的提示开始；“换一张（1）”和“这次跳过”说明了按钮后果。更完整的首次教学是后续体验项，不把它伪称已完成。
7. 动作词表已逐项核对并在上表列出；输入 signal 使用真实 `Input`，其余卡牌/收尾行为使用同名 `data-action`。重复换卡和重复收尾的不可点是规则拒绝，不是死键。
8. 归属与时效明确。`你`、`TA`、当前轮次和“TA 抽到的卡”均有文字归属；互动卡只显示当前队首，AI 回复须玩家点继续才推进，避免上一张内容冒充当前回合。

## 好玩三问

1. 会想再来一局。物理塔每次抽离后的形态不同，而颜色卡只在成功抽离后出现；玩家能从“先稳住、再选择”中获得真实的风险与节奏，而非读概率条。
2. 关键反馈可见。悬停显示积木颜色与分值，完整抽离出现主卡/余波，AI 行动在共享塔上可见，倒塌会锁定并显示中性收尾卡。当前版本不把倒塌预告成脚本结果。
3. 存在的等待点已记录。AI 观察、关节追赶和本地模板回复会产生短暂等待；页面提供进行中的可读状态，回复显示后必须由玩家点击继续。若真实物理长期未稳定，900 帧兜底进入终局，避免无穷等待。
