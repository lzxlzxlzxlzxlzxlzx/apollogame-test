## 完成定义

`game-105` 可由 Apollo 启动，且在无 Host、无网络、无模型凭据的环境中完成初始化。默认角色、默认头像和 AI 本地模板均由游戏内数据提供；保留的 Host/App 代码不得在默认启动、AI 回合、结算或重开中被调用。

AI 必须继续经共享 `TowerActionExecutor` 进行可见相机、悬停、`Joint3D` 拖拽和释放。真实物理、积木退休、实时倒塌、重开清理和本地模板路径不得因保留接缝回归。

## 程序验收

1. 无 Host 的 Apollo 启动、重开和退出均无控制台错误、网络请求或缺失能力阻塞。
2. AI 回合只使用本地观察、共享动作执行器和本地模板，不调用 dialogue、`apps.launch`、外部完成回传或读取密钥。
3. Host 接缝如保留，默认显式关闭；缺失/异常 adapter 必须与不存在 adapter 的本地模板结果一致。
4. 类型检查、S3 专项、构建、Chrome 渲染/点击探针、当前 S3 gate 均对同一指纹通过。
5. 程序在 `s3-program-evidence.md` 如实记录本版范围、命令、结果和未覆盖项；不得沿用 Host M1 自证。
