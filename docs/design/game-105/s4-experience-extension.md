# game-105 S4：Host Interaction 体验增量施工单

> GD-105 · 2026-09-02 · 本文件是 `s4-local-ai-m1.md` 的组成部分。独立可玩版不调用 LLM、宿主会话或外部回传；它们留给 M2。

## 1. 信息与交互状态

AI 主卡、余波和惩罚卡必须复用既有互动卡区，并分别呈现：`TA 抽到的卡`、频道/题目/序号、本地回应、`继续`。本版不显示等待模型或技术模式。

玩家倒塔的输入、快捷短句、提交/跳过和本局清理规则保持不变。AI 惩罚卡没有玩家输入框，玩家只能在回复完成后确认继续。余波仍逐项显示；超过三张时维持 `余波 xN` 事实提示。

## 2. 结构冻结

陪玩状态区、本局账本、操作提示、互动卡、余波提示、收尾卡及其按钮层级沿用 S5 签核结构。Host 接入只可改变状态内容与可见性，不得以新增悬浮窗、全局 DOM 覆盖或挤压画布的方式改变布局。

## 3. 文案与安全

模板回应限制为 1--2 句、最多 80 字；不得捏造玩家输入、承诺永久记忆、索取敏感信息或评价失败。M2 如接入模型，也必须保持这些内容边界。

## 4. GD 验收重点

1. AI 主卡和余波逐张可见，回复期间不跳过也不提前换回玩家。
2. AI 倒塔的惩罚卡只出现、请求和完成一次。
3. 重复物理信号、重开与 UI 重渲染均不造成重复文本、卡牌、心动值或回合推进。
4. 玩家原话不进入任何外部请求或游戏内结算。
5. 窄屏和标准屏均不出现卡牌越界、被场景遮挡、不可读文字或不可点击控件。
